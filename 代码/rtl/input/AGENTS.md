# 交互与板级岗位规则

负责人：硬件二。

## 主责范围

- 琴键、压力、编码器、光电、距离或MIDI输入候选实验。
- GPIO、SPI、I2C、UART、去抖、滤波和事件生成。
- NEO Dock原理图、时钟复位、CST约束和引脚表。
- DAC、供电、电平、逻辑分析仪和示波器测量。

## 写入范围

- `代码/rtl/input/`
- `代码/rtl/board/`
- `代码/constraints/`
- `代码/docs/hardware/`
- `代码/docs/pinout/`
- 对应的 `代码/tb/` 文件

## 约束

- 输出必须符合统一演奏事件接口。
- 任何5 V信号接入前必须确认电平转换。
- 改接线必须同步修改CST和引脚文档。
- 连续传感器数据必须给出更新率、抖动和延迟实测。
- 未经确认不占用HDMI、音频或其他复用引脚。
