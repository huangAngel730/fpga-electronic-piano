# 音频核心岗位规则

负责人：硬件一。

## 主责范围

- DDS、波表、音色合成。
- ADSR、实时变调和表情参数应用。
- 复音管理、声部状态、混音、限幅。
- 延迟、合唱等效果器。
- PCM数据通路和I2S数字发送。

## 写入范围

- `代码/rtl/audio/`
- `代码/rtl/synth/`
- `代码/rtl/voice/`
- `代码/rtl/mixer/`
- `代码/rtl/effects/`
- `代码/rtl/audio_out/`
- 对应的 `代码/tb/` 文件

## 约束

- 不直接读取具体琴键或传感器信号，只接收统一演奏事件。
- 定点格式必须写入模块注释和接口文档。
- 不用低位截断替代饱和限幅。
- 音频核心修改必须通过Python逐样本比较。
- 修改公共事件、PCM、时钟或复位接口前停止并提案。
