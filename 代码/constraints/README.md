### 【重要】它不是本工程的约束文件

该文件描述的是**官方综合例程**的引脚分配，包含大量本项目用不到的外设
（DDR3、HDMI、以太网、摄像头）。它里面还有 `INS_LOC` 语句把

**禁止**把它直接作为本工程的 CST 交给综合工具，否则会引入大量
不存在的端口并报错。

正确用法：**作为接线和引脚核对的依据**。新建 `electronic_piano.cst`
时，从本文件中摘取本项目实际用到的引脚。

## `audio_timing.sdc`

### 时钟

```
create_clock -name sys_clk -period 20.000 [get_ports sys_clk]
```

板载晶振 **50 MHz**（2026-09-12 确认），周期 20.000 ns。

### 两个关键结论

**1. 不倍频到音频标准频率**

50 MHz 无法精确倍频到 98.304 MHz。Gowin rPLL 的 IDIV/FBDIV 为整数，
在 IDIV≤64、FBDIV≤128 范围内最接近的是 `IDIV=59, FBDIV=116`
→ 98.305085 MHz，误差 **+11.03 ppm**，精度反而不如 50 MHz 直接分频
（**+0.096 ppm**），且多消耗一个 PLL 和 BUFG。故选择不倍频。

**2. BCLK 不能用整数分频产生**

```
50 MHz / 3.072 MHz = 16.276042    ← 不是整数
```

| 整数分频 | 实际 BCLK | 误差 | 音高后果 |
|---|---|---|---|
| ÷16 | 3.125000 MHz | +17253 ppm | **偏高约 0.29 半音** |
| ÷17 | 2.941176 MHz | −42586 ppm | 偏低约 0.75 半音 |

±0.29 半音的走音**人耳可直接察觉**，因此整数分频方案不可用。
BCLK 必须用与 `sample_tick` 相同的相位累加结构产生：

```
step = round(2^32 × 3.072e6 / 50e6) = 263882791 (0x0FBA8827)
实际 BCLK = 3.072000004 MHz，误差 +0.0013 ppm
```

LRCLK 由同一累加器加 6 位计数器产生，天然保证 64:1 整数关系。

### 抖动

相位累加产生的 `sample_tick` 与 BCLK 周期不均匀，存在 ±1 个
sys_clk 周期（**20 ns**）的抖动。

- 对 `sample_tick`：它是"处理节拍"而非 DAC 时钟，抖动只改变算完的时刻，
  不改变数值结果，可接受。
- 对 BCLK：抖动会直接调制 I2S 输出采样时刻。**需在音频验收时评估
  THD+N**。若指标不达标，备选方案是用 PLL 产生 98.304 MHz 后
  整数 32 分频，可获得无抖动 BCLK。
