# 算法模型与验证岗位规则

负责人：M1 音频算法、验证与竞赛交付负责人。岗位定义见 `代码/docs/角色分工.md`。

## 主责范围

- Python 黄金参考模型。
- 波表、频率控制字和测试向量生成。
- RTL 自动仿真、逐样本比较和回归测试。
- 音频分析（波形、频谱、包络、延迟）与验证记录。
- 竞赛报告和答辩材料中的算法与验证部分。

## 写入范围

- `代码/model/`
- `代码/docs/test/`
- 可新增 `代码/tb/` 测试，不直接修改功能 RTL

## 与 M2 的边界

- 构建、综合、布局布线和烧录脚本位于 `代码/scripts/`，由 M2 负责；M1 提供需要被验证的模型与判定脚本，并复核构建脚本产出的码流可被测试用例覆盖。
- 串口、仪器控制和数据采集脚本由 M3 负责；M1 只定义需要采集的数据字段和容差。

## 约束

- 正式运行时软件不得替代 FPGA 生成音频。
- 测试必须自动返回成功或失败退出码。
- 所有容差、采样率、位宽和舍入规则必须显式记录。
- 构建失败、时序违例和关键警告不能被吞掉。
- 测试结果必须关联 Git 提交和工具版本。
- 软件任务积压时按 D010 由 M2 分担实现，但算法数学定义和最终验收仍由 M1 负责。
