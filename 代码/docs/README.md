# 项目文档索引

日常开工先看 `协作入口.md`，本文件用于按主题查找文档，不要求一次读完全部内容。

## 项目事实与架构

- `项目事实与范围.md`：已经冻结、阶段目标和尚未冻结的事项。
- `模块接口规范.md`：演奏事件、PCM、时钟复位和状态接口。
- `技术决策记录.md`：带编号的架构与流程决策。
- `资源预算与复音规划.md`：器件资源预算和复音规模规划。
- `抉择与并行开发顺序.md`：三条工作线和同步点。
- `板级硬件事实.md`：Tang Mega 60K 官方规格、外设、供电、电气安全和上板踩坑。

## 计划与状态

- `三人开工任务说明.md`：当前启动阶段三个人可以立即执行的任务和第一次集成线。
- `发给M1的开工通知.md`、`发给M2的开工通知.md`、`发给M3的开工通知.md`：可直接单独转发给每名成员及其 AI 的执行说明。
- `当前状态.md`：当前周次、已完成、进行中、阻塞和稳定版本。
- `任务看板.md`：任务编号、负责人、分支和验收条件。
- `八周排期与里程碑.md`：日期和阶段里程碑。
- `交付物与验收里程碑.md`：最终交付物清单。
- `风险登记表.md`：风险、影响和缓解措施。
- `每周同步记录.md`：周会结论和同步记录。

## 协作与交接

- `协作入口.md`：所有队员和 AI 的第一入口。
- `三人协作执行手册.md`：领任务、开发、复核和交付流程。
- `角色分工.md`：M1、M2、M3 的所有权和决策权。
- `Git协作规范.md`：分支、提交、PR 和冲突处理。
- `变更与决策流程.md`：公共接口与重大变更审批。
- `AI开工提示词.md`、`AI交接上下文.md`：跨工具、跨账号和跨周交接。
- `新队员上手指南.md`、`个人环境模板.md`：首次接入和个人环境记录。

## 验证与资源

- `测试验收标准.md`：L0 至 L7 验证等级。
- `验证记录.md`：全部 PASS/FAIL 证据的唯一索引。
- `板卡与仪器资源管理.md`、`资源使用记录.md`：实验室设备配额和实际占用。
- `开发环境.md`：Gowin 和开源仿真工具版本。
- `早期原型代码评审.md`：冻结八键原型的质量结论和迁移建议。
