# 团队与 AI 协作入口

更新时间：2026-09-10。

## 每次开工前必须阅读

按以下顺序阅读：

1. 根目录 `AGENTS.md`
2. `代码/AGENTS.md`
3. `代码/docs/项目事实与范围.md`
4. `代码/docs/模块接口规范.md`
5. `代码/docs/技术决策记录.md`
6. `代码/docs/当前状态.md`
7. `代码/docs/任务看板.md`
8. 与本人岗位对应的局部 `AGENTS.md`

## 三个岗位

| 角色 | 主要所有权 | 主要复核对象 |
|---|---|---|
| 硬件一 音频核心 | 复音管理、合成、包络、混音、效果、I2S 数字输出 | 软件模型和板级音频实测 |
| 硬件二 交互板级 | 交互输入、时钟复位、约束、接线、DAC及仪器验证 | 公共事件接口和音频输出接口 |
| 软件 验证自动化 | Python模型、仿真、构建、串口、音频分析、报告数据 | 所有模块的可重复验证 |

## AI 开工提示词

每位队员可将下面内容发给自己的 AI：

```text
先完整阅读根目录 AGENTS.md、代码/AGENTS.md 和代码/docs/协作入口.md 中列出的全部必读文件，再阅读本岗位目录中的 AGENTS.md。
只执行任务看板中分配给我的任务，只修改授权目录。
如果需要修改公共接口、时钟、复位、数据位宽、采样率、顶层端口或引脚，先停止并提交影响分析，不要直接修改。
完成后运行规定测试，并更新当前状态、任务看板和验证记录。
```
