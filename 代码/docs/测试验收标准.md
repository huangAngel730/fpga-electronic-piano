# 测试验收标准

## 验证等级

| 等级 | 含义 |
|---|---|
| L0 | 文档或静态检查完成 |
| L1 | lint和编译通过 |
| L2 | 自检仿真PASS |
| L3 | 与Python参考模型比较PASS |
| L4 | Gowin综合通过 |
| L5 | 布局布线和时序收敛 |
| L6 | 已下载到开发板并实测 |
| L7 | 整机连续运行和故障恢复通过 |

报告状态时必须给出等级，不得跨级描述。

## RTL模块最低测试

- 复位过程。
- 正常流程。
- 最大值、最小值和边界条件。
- 至少一个异常场景。
- 自动PASS或FAIL。

## 音频专项验收

- DDS频率误差满足定义阈值。
- ADSR各阶段时间和幅度满足容差。
- 混音不发生无说明回绕，削波计数有效。
- I2S的BCLK、LRCLK、数据相位、位宽和声道正确。
- 多声部Note On、Note Off和Release不丢失、不挂音。
- 正式音色有波形、频谱或算法结构证据。

## 板级专项验收

- 电源和I/O电压核对完成。
- 约束与接线表一致。
- JTAG识别和下载可重复。
- UART日志字段可被软件解析。
- 端到端延迟使用调试GPIO和模拟输出测量。

## 合并请求必须附带

- 变更摘要。
- 运行命令。
- PASS结果或报告路径。
- 当前验证等级。
- 尚未验证的硬件项目。
- 是否影响公共接口和约束。
