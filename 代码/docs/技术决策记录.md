## D008 三人岗位与所有权冻结

- 日期：2026-09-11
- 提议人：三人共同
- 状态：已冻结
- 问题：早期“音频核心、交互板级、软件验证”三分法把验证和交付责任分散，且 I2S 归属不清。
- 候选方案：按学科分工；按交付物分工；按数据流边界分工。
- 决策：采用 M1、M2、M3 三个岗位。M1 为音频算法、验证与竞赛交付负责人；M2 为 FPGA 技术与系统集成负责人并兼任技术与集成负责人；M3 为实体硬件、交互与上板验证负责人。FPGA 内的 DDS、波表、ADSR、复音、混音和数字效果算法按软件工作管理，归 M1。I2S 数字发送、时钟、CDC、顶层和约束归 M2。供电、电平、传感器、DAC、仪器测量归 M3。
- 依据：I2S 与约束本质是接口时序问题；算法验收需要单一责任人。
- 影响模块：全部；`代码/AGENTS.md`、`角色分工.md`、`协作入口.md`、各局部 `AGENTS.md` 的岗位名称与写入边界。
- 回退方案：若集成负荷过高，把 I2S 实现临时交回 M1，但约束和时序收敛仍由 M2 把关。

## D009 板卡与仪器资源分配

- 日期：2026-09-11
- 提议人：三人共同
- 状态：已冻结
- 问题：两套板卡和两台逻辑分析仪需要明确的编号、配对和配额，避免个人长期占用。
- 候选方案：完全自由使用；按人到固定编号；按周配额加共享池。
- 决策：BD-01 为稳定集成板，BD-02 为实验开发板，LA-01 默认配 BD-01，LA-02 默认配 BD-02。全部放在实验室，属于共享资源。两块板合计每周 40 小时配额：M1 六小时、M2 十四小时、M3 十小时、共同集成十小时。两台逻辑分析仪合计每周 40 小时配额：M1 四小时、M2 十四小时、M3 十二小时、共同集成十小时。配额是预约基准，未使用份额回到共享池。
- 依据：M2 承担集成和上板时序调试，板卡与分析仪需求最高；M1 以电脑端模型和验证为主。
- 影响模块：构建、上板验证和集成窗口安排。
- 回退方案：关键路径紧张时由三人同步会临时调整配额，并记录在资源使用记录中。

## D010 软件工作量分担规则

- 日期：2026-09-11
- 提议人：三人共同
- 状态：已冻结
- 问题：算法建模、验证脚本和上位机都算软件工作量，集中在一人会成为瓶颈。
- 决策：软件任务积压并影响关键路径时启动分担。M2 分担算法 RTL 的流水线、资源优化、FIFO、CDC、I2S 和构建工作；M3 分担按键、传感器、串口、仪器控制和数据采集软件。算法数学定义和最终验收始终由 M1 负责。
- 依据：保持算法验收单一责任人，同时释放实现带宽。
- 影响模块：任务看板的任务归属和复核关系。
- 回退方案：任务重新收回 M1 时需在任务看板注明原因和当前验证等级。

## D012 八周排期与两阶段范围

- 日期：2026-09-11
- 提议人：M1 起草，待三人共同确认
- 状态：提议
- 问题：作品提交截止 2026-11-03，扣除交付物准备与缓冲后核心开发窗口约五周；原任务看板只覆盖两周且无日期，无法判断进度。
- 候选方案：全范围冲刺；保底档加加分档的两阶段范围；削减音色数量换取声部规模。
- 决策：采用两阶段范围。保底档为 48 kHz、4 复音、两种音色、延迟效果、UART 状态输出、可复现码流与完整交付物，须在 W6 结束前整体可演示；加分档在保底档通过 S5 验收后启动。冻结日 2026-10-27，W8 为缓冲周，不作为开发周。
- 依据：保底档保证作品在任何情况下都完整可演示，加分档保留冲击规模的余地而不危及交付。
- 影响模块：全部任务的排期、任务看板的周次划分、报告与答辩的规模口径、资源预算与复音档位。
- 回退方案：若 W4 结束前 S3 单声部未通过，取消加分档，资源集中到保底档交付物。
- 待办：三人确认后改为已冻结，并补充各人周投入工时假设。

## D013 统一演奏事件接口 v0.1 冻结

- 日期：2026-09-11
- 提议人：M1 起草，待三人共同确认
- 状态：提议
- 问题：T001 需要冻结统一演奏事件接口，M1 的算法 RTL 与 M2 的顶层和 I2S 才能并行开工。原草案缺少时钟域边界、字段取值语义、事件 FIFO 约定和握手时序说明，且事件结构合计 50 位，与 FIFO 和 BRAM 的自然位宽不对齐。
- 候选方案：维持原草案直接冻结；补齐语义后冻结；只先冻结输入侧、暂缓 PCM 侧。
- 决策：采用补齐语义后冻结，冻结候选稿为 `模块接口规范.md` v0.2。待决项 Q1 至 Q8 逐项评审，未达成一致的按文档所列倾向值执行并在决策记录中标注为暂定。
- 依据：接口是并行开发的前置条件，语义缺失会在集成阶段集中暴露，返工成本远高于评审成本。
- 影响模块：输入模块、事件转换、音频核心、混音器、顶层、I2S 发送、公共测试桩与持续集成。
- 回退方案：若 Q1 或 Q7 分歧过大，先按暂定值实施并在 S3 前重新评审；仍不一致时退回由 M1 单侧实现，并在 W4 前完成适配。
- 待办：三人评审第七节并确认；确认后本决策改为已冻结，接口文档版本升级为 v1.0。
