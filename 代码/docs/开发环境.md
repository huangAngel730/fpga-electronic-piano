# Tang Mega 60K 开发环境

环境安装日期：2026-09-10。

## 目标硬件

- 开发板：Sipeed Tang Mega 60K + NEO Dock
- FPGA：`GW5AT-LV60PG484AC1/I0`
- Gowin 器件：`GW5AT-60B`
- 封装数据库：`PBGA484A`
- Device Version：`B`

## 已配置工具

- Gowin EDA Education `V1.9.11.03`
- Gowin Programmer `V1.9.12.02` build 2654
- Gowin USB Cable Driver V5
- OSS CAD Suite `20260909`
  - Icarus Verilog `14.0` development build
  - Verilator `5.053`
  - Yosys `0.68+206`
  - GTKWave

安装目录统一放在 `D:\Gowin`，避免占用空间不足的 C 盘。

## 中文路径兼容

Gowin Tcl 命令行无法可靠打开带中文字符的工程路径。已建立目录联接：

```text
D:\Gowin\workspace\embedded_fpga
    -> D:\17\上大学\计算机类专业\嵌赛FPGA
```

使用 Gowin GUI 或命令行构建时，应通过左侧纯英文路径打开工程。文件仍实际保存在原仓库中。

## 使用方法

在仓库根目录执行：

```powershell
. .\代码\scripts\enter_fpga_env.ps1
.\代码\scripts\check_fpga_env.ps1
```

第一条命令需要用点号调用，以便环境变量保留在当前 PowerShell 会话。
