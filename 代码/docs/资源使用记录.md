## 五 填写规则

1. 一条记录只对应一次连续使用，跨时段分开记录。
2. 时长以小时为单位，保留一位小数。
3. 任务号必须能在 `任务看板.md` 中找到，不允许写自定义编号。
4. 码流版本写提交前缀或标签，不允许写“最新版”。
5. 结果写实际达到的验证等级，例如 L2 或 L6，不允许只写“正常”。
6. 未登记的使用不参与下周配额，但需要在同步会上说明原因。
7. 板卡编号只允许写 BD-01 或 BD-02，分析仪只允许写 LA-01 或 LA-02。
