### 2.1 IDE 版本要求

官方明确要求：

- 教育版 IDE **≥ V1.9.11.03**
- 商业版 IDE **≥ V1.9.10.03**
- 烧录 Flash 固化推荐 `exFlash Erase,Program thru GAO-Bridge 5A`（≥V1.9.10.03）或 `exFlash Erase,Program thru GAO-Bridge Arora V`（≥V1.9.12）
- 官方推荐使用独立的 **Programmer 1.9.12 SP1**，兼容性更好

当前本地版本见 `开发环境.md`，已满足教育版要求。

### 2.2 下载失败的高频原因

官方 FAQ 明确指出：**IDE 中每一个器件参数都必须与下图一致**，型号 `GW5AT-LV60PG484AC1/I0`、封装 `PBG484A`、Device Version `B` 任一项选错，都会表现为"烧录后没反应或引脚现象不对"。

排查顺序：

```text
器件型号 / 封装 / Device Version
-> 引脚约束文件是否与实物一致
-> 代码与仿真波形是否正确
-> 用 GAO 工具做片上调试（见高云 SUG100）
```

| 乘法器（18×18） | **118** 个 |
| PLL | **8** 个 |
| 全局时钟 | 16 |
| 高速时钟 | 20 |
| 高速收发器 | 4 个，270Mbps ~ 8.8Gbps |
| PCIe 硬核 | 1 个，PCIe 2.0，仅 x1 可用（见下） |
| LVDS | 1.25 Gbps |
| DDR3 | 1100 Mbps |
| MIPI D-PHY（软核） | RX 最高 1.6Gbps，TX 最高 2.0Gbps，4 数据通道 + 1 时钟通道 |
| 硬核处理器 | 无 |
| ADC | 2 |
| I/O Bank 总数 | 11 |

### 3.1 对音频项目的直接约束

- **乘法器 118 个**是多音色复音数的主要瓶颈。每个声部若用 1 个 18×18 乘法器做包络或调制，理论上限约 118，但实际要与混音、效果器、控制逻辑共享，必须按 T016 实测确定保底复音档。
- **BSRAM 2124 Kbits** 决定波表容量。单周期 16 位样本、2048 点波表约需 32 Kbits，可容纳多个音色，但需与 FIFO、延迟效果器共享。
- **PLL 8 个**足够支撑 `sys_clk` 与音频输出时钟方案，T019 不必担心 PLL 数量不足。
- 本芯片**无硬核处理器**，所有控制逻辑必须用 RTL 实现，不能依赖软核方案。

### 3.2 PCIe 限制（与音频项目无关，但避免误用）

Wiki 注意事项明确：由于 `GW5AT-LV60` 与 `GW5AST-LV138` 的 SERDES 引脚排列不同，NEO Dock 底板最初为 138K 设计，`GW5AT-LV60` 的 1 号与 3 号通道互换，**PCIe 目前只能工作在 x1 模式**。此问题可能由高云软件更新修复。本项目不使用 PCIe。

### 4.1 对音频项目的直接价值

- **底板自带 Speaker 接口（2×3W）和 3.5mm 立体声耳机座**，T015 的音频链路对比应把这两条板载通路列为候选，与 PCM5102A 外接方案做实测对比（延迟、噪声、直流偏置）。
- **MIC ARRAY 接口支持 Sipeed 6+1 麦克风阵列**，是 T036 交互方案实测的候选之一，比自建传感器阵列省硬件工作量。
- **DVI RX 与 DVI TX 互相占用**，若后续要做显示，只能二选一。
- **PMOD、40P 排针、DVP 三者复用**，M3 做引脚规划时必须避免功能冲突，并在引脚表中记录复用关系。

## 五 供电与电气安全

### 5.1 三种供电方式

| 方式 | 要求 |
|---|---|
| 双 USB 5V | 同时连接 **USB-3.0** 和 **USB-DEBUG** 两个接口 |
| 12V DC | DC5521 规格；若用 USB-C 转 12V DC 配件，需连接**有 12V 输出能力的 PD 电源** |
| 3.7V 锂电池 | 电压必须 **≥ 3.6V**，连续放电能力 **≥ 600mA** |

### 5.2 官方明确的故障现象与处理

| 现象 | 原因与处理 |
|---|---|
| 上电后底板只亮 4 个指示灯，SOM 指示灯不亮 | 未开机。**PWR 按键（HDMI 接口旁）长按 2 秒**开启电源 |
| 底板 Battery-Indicator 指示灯闪烁 | 正常现象，通常是靠近 12V DC 连接器的那颗 LED；接 3.7V 锂电池时这些 LED 作为电量指示 |
| 长按 PWR 2 秒后底板指示灯全部熄灭又依次亮起 | **供电能力不足**。改用双 USB 5V、12V DC 或 ≥3.6V 锂电池供电 |
| 电源指示灯亮，但 Programmer 提示 No USB Cable Connection | 检查 USB 线是否接入标记为 **DEBUG-USB2** 的 USB-C 接口；避免使用机箱前面板 USB 和未独立供电的 USB HUB；确认已安装 FT2232 驱动（设备管理器出现 USB Serial Converter A/B） |
| IDE 找不到型号 GW5AT-LV60PG484A | IDE 版本过老，需升级到商业版 ≥1.9.10.03 或教育版 ≥1.9.11.03 |

**对本项目的意义**：T007 首次上板时，若出现"指示灯全灭又依次亮起"，应先怀疑供电，而不是先怀疑 RTL 或约束。这一条应写入 T007 的记录模板。

### 5.3 电气安全硬约束

- **GPIO 排针外部通信必须确保 IO 电压为 3.3V，过高电压会永久损坏 PCBA。**
- 接触 PCBA 前先释放手上静电，避免静电击中板卡。
- 完全断电后才能插拔。
- 上电过程中避免液体和金属触碰元件焊盘，防止短路烧毁。
- 连接 FPC 软排线时确保排线无偏移地完整插入，**通电前仔细核对两端连接器 1 号 PIN 方向**。
- 测试 PCIe 金手指时，主机端与板卡都必须关机或断电。

这些约束与根目录 `AGENTS.md` 的电气安全条款一致，M3 在 `rtl/input/` 和实物接线中必须遵守。

## 六 上手与烧录要点

### 6.1 首次连接检查顺序

```text
确认供电方式与能力
-> PWR 按键长按 2s 开机
-> USB 线接入 DEBUG-USB2 接口
-> 确认 Windows 设备管理器出现 FT2232（USB Serial Converter A/B）
-> Gowin Programmer 识别下载器
-> JTAG 扫描
-> 器件识别（确认 GW5AT-60B / PBG484A / Version B）
-> SRAM 下载 LED 示例
-> UART 或调试输出
-> 重复下载验证
```

### 6.2 Flash 固化

需要固化到 Flash 时：

1. 在 Programmer 中选择 `exFlash Erase,Program thru GAO-Bridge 5A`（或 Arora V，取决于版本）。
2. **检查拨码开关位置**，必须符合官方图中所示位置，否则无法正常固化。

第一轮上板只做 SRAM 下载，不烧写 Flash，符合 `发给M2的开工通知.md` 第四节的要求。
