# 风险登记表

更新时间：2026-09-12。排期见 `八周排期与里程碑.md`，阻塞上报流程见 `三人协作执行手册.md` 第九节。

## 一 登记规则

- 每条风险必须有触发条件、影响、应对和盯防人，缺项视为未登记。
- 触发条件成立当天更新状态，并写进每周同步记录。
- 状态只能使用：观察中、已触发、已解除、已发生。
- 风险已发生时不得删除条目，改状态并补记实际影响和处理结果。

## 三 升级规则

- 风险触发时，盯防人当天更新本表，并把状态改为已触发。
- 影响关键路径的风险由盯防人在每周同步上提出，必要时走 `变更与决策流程.md`。
- 涉及供电、电平或可能损坏硬件的风险，任何人可立即停止实验，事后补记。
