# Pro C 音频工程 A08 本地完成交付

本包仅覆盖本轮新完成的音频工程接合与离线实现，验证等级限定 L5。使用 Gowin 商业版 V1.9.12.04、GW5AST-LV138FPG676AC1/I0、C 步进，物理顶层 pro_audio_minimal_top。A08 原始工具退出 0，综合、布局布线、码流生成和当前约束下基本 STA 通过。

分析 122807 条路径、32060 个端点；Setup/Hold 违规端点均为 0。报告最差 Setup +2.823 ns、Hold 0.000 ns、Recovery +14.701 ns、Removal +0.351 ns；最小脉宽裕量 +6.961 ns。参考时钟 50 MHz，真实 PLL CLKOUT2 音频时钟 40 MHz。Hold 的 0.000 是工具报告精度下数值，不宣称额外正裕量。

当前码流：bitstream/pro_audio.fs，37262764 字节，SHA-256 55f102b1972deaff774844e125693648ceac1b982ac0d5567d223c3b9c2c21e5。

主要修复：R17 使用芯片复用 CPU/SSPI GPIO 的已支持选项；保持异步置位、同步释放的复位结构，只对两级同步器的 CLEAR 输入设置时序例外，下游复位和数据路径继续分析；保留更严格的 0.750 ns hold 不确定度。资源受限失败后恢复原受控执行器，在足够 RAM 准入后完成。八个尝试槽原始记录均保留，其中 A07 未创建子进程，实际 Gowin 调用 7 次，累计 1851.874 秒。

主要入口：COMPLETION.json 为自审、消费和未验项；SOURCE_CLOSURE.json 为 62 份 HDL、头文件、ROM、IP 与约束的身份；reports/ 为未改字节的实际报告；history/ 保留每次原始双流、退出码和失败；project/ 为实际采用的源码与 ROM。MANIFEST.json 覆盖除它自身以外的全部包内文件。ZIP 中保留原件字节，未对厂商文件或日志换行归一化。

需要重新构建时，在独立新目录解压，先核 MANIFEST；用同一商业版 gw_sh.exe 执行 rebuild.tcl。该入口用包内文件生成 REBUILD/pro_audio 工程；路径和选项已静态核对，此次没有再执行一轮迁移构建。不得覆盖旧 REBUILD 或旧失败。实际本次输入的绝对路径项目和配置另保存在 provenance/。
