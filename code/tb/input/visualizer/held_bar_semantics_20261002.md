# 按键时长上飘条候选语义（2026-10-02）

用户经主M2授权本可视化窗口实现新语义：去除底部琴键绘制，保持横向音高映射、原JUDGE_Y起始基线、8实时/8曲谱槽和原音频。公共音频事件、桥CDC、正式top/pkg/CST/SDC/接口规范不改。允许内部live/renderer/wrapper端口新增条尾坐标、held与丢弃计数，板级诊断模块仅修曲谱产生时间。

有效握手的非零NoteOn以source_id/channel/note_number身份开条。条头从400向0饱和上移，条尾初始410，held期间条尾固定；长按头部到0后仍保持身份。对应NoteOff或velocity0松键后，条尾/条头共同上移，条尾到0回收。CC64不延长物理按键时长图形。帧起点发布完整快照，边界同时事件进入下一帧。低槽优先分配，高槽覆盖低槽绘制。

重触发同身份结束旧held条，并优先新空槽；槽满而同身份重触发时原位重开，覆盖计数+1。其他槽满NoteOn丢弃新条，饱和丢弃计数+1，不驱动音频ready/复位。被丢弃身份的后续NoteOff不会停止其他条。reset/全局AllNotesOff/失步清除状态；失步保持粘滞提示直到reset。

下落需区分：诊断曲谱score_seq+120不跟随运行时间，新音符在晚期可能一入队已过期；tracker在命中帧后y=0意味着绘制顶部在判定线，并按窗口/时长释放，约0.1~0.5秒短停留可正常。无新视频可读，不声称已确认现场根因。诊断源改为同源50MHz计数估计显示帧、按固定节奏生成未来命中帧；无跨域直接读取current_frame。此时间源仅诊断，启动误差小于一帧，不宣称最终曲谱同步契约。

候选需held/release/长按跨屏/身份隔离/重触发/槽满/清音/复位/失步测试，renderer消隐/边界/去琴键和旧score时序；音频隔离联合仿真及新完整PnR/STA，不能沿用6ade4c旧结果。未复核不烧录。

新增同批反馈：tracker成功匹配未判定槽且NoteOn非零Velocity，输出一次内部hit脉冲和音高。仅下落模式积累该音高底边闪光，每音高独立倒计时默认6个完整帧（约100.8ms @59.524Hz），连续命中刷新、不同音高可并存；屏底核心5×4亮色、外晕9×8，屏边裁剪，不依赖键盘。错键/窗外/已判定重复/NoteOff/CC64不触发。清音/失步/复位/离开下落模式清除；额外internal hit/flash端口，不改公共事件或CDC。
