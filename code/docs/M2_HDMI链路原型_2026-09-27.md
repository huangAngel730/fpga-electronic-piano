## 硬件影响

仅独立码流：V22系统50MHz、AA13低有效复位（沿用项目已验1.5V上拉）；TMDS映射沿用本仓库官方全引脚表：D0 J14/H14、D1 J15/H15、D2 K17/J17、CLK G15/G16，3.3V Bank；AB16 pa_en恒1关闭音频功放。引脚为FPGA封装球位，不是底板排针编号。最终SDC显式定义50/125/25MHz关系，复位异步路径只针对复位端口；不将相关像素/串行时钟设为异步。最终I/O标准以IP推断及Gowin引脚报告核实，若不符立即停止，不自动改Bank电压。无MIDI输入，无音频合成，不影响正式音频工程源码。

## 试验过程和降级原因

1. 800×600/40MHz/200MHz原版同步复位：像素数据路径通过，但四个OSER10 RESET恢复余量−0.152ns。
2. 尝试`BUFG=CLK`被CT1014拒绝（驱动类型错误），撤回；改串行域复位后最差−0.424ns；按SUG1018 1.6E §2.7改合法`BUFG=SR`后仍落LW且最差−0.634ns，撤回。
3. 25.2MHz方案IDIV=5导致PFD10MHz，被PA2078拒绝（器件允许19～87.5MHz），未进入PnR，未使用。
4. 当前25MHz/125MHz配置通过时序门禁。刷新率偏离精确VGA标准，须实屏验证；若不能锁定，再按器件PFD/VCO范围设计精确像素时钟或重做较高模式的局部复位布线。不得直接改SDC频率冒充实际PLL频率。
