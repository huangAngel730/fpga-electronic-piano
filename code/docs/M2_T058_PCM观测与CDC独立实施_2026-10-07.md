## 实际实现与自审结果

新增pcm_frame_observer.sv及pcm_waveform_observer_bridge.sv：按已批准帧边界pre-NBA
signed24左右寄存，默认首seq0/模32回绕。32深度音频域完整80bit包队列+1稳定mailbox，
mailbox复用只读visual_mailbox_cdc WIDTH80，req/ack各双同步，包在目的采集/返回ACK前保持。
不是Gray双时钟RAM FIFO，不把多位PCM逐bit同步。目的无ready，每包sample_valid一拍。

观察branch共同rst_n=audio_rst_n&&display_rst_n，支路src/pixel分别reset_sync释放；
独立观察序号只跟audio_rst_n，display reset不改变音频或观察seq。source_done在目的
双同步，reset释放后只发一次stream_restart，随后再出sample_valid。队列和mailbox
满/目的clock停止只丢显示，观察仍每音频帧照常更新，无信号返回audio ready/request。
支路drop_count在观察branch reset清零，明确不是跨reset累计整机STAT；M3自己的seq/gap
统计保持既有合同。waveform_rst_n只给波形模块，不改变原视频/音频reset。
