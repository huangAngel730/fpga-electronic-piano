## P2 语义阻断与集成决定

M2 播放器在 COMMIT 换曲及读口故障后产生 `source_id=2` 的 `EVENT_ALL_NOTES_OFF`；`polyphonic_event_router` 将该事件送为 `SUSTAIN_CMD_PANIC`，当前 `sustain_controller` 的 PANIC 不筛 source，清全部 pedal/key/deferred 并释放 occupied 槽。故 source0 实时 MIDI 持音也会受影响；同沿 MIDI 优先仅延后 score 事件，不能使后续 PANIC 局部化。该冲突由现有 HDL 源码确认，而非 CodeGraph 索引或新的整机仿真。

**本阶段决定：保留现有全局 PANIC 合同，不把 source2 ALL_NOTES_OFF 当“仅曲谱清音”接入正式四声部顶层。**P2 仍为后置拓展；当前先完成 R04 真链功能、电气及基础上板路径。待基础出口具备后，M2 先写 score 局部清音的影响分析与接口方案，明确仅释放 source2、CC64/deferred、同 note 多身份、在途请求/取消/复位的行为，并按公共接口变更流程通知后实施；M1 对音频数学和连续音行为给判据，M3 只在许可后测实物。未定案前不得通过改变既有全局 PANIC 语义或隐去 source0 释放来“修”测试，也不反复重跑已签的 P2 独立 PCM 专项。
