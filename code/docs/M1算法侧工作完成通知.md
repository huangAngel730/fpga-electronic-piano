### T023 混音器（优先级最高）
**位置**: `code/model/mixer.py`

**算法规格**: `code/docs/test/T023_混音器与饱和限幅设计.md`

**RTL测试向量**: `code/model/generated/mixer/`
- `mixer_inputs.txt`: 1000组压力测试输入（满幅随机，4声部×24bit）
- `mixer_outputs.txt`: 期望输出
- `mixer_clipped.txt`: 削波标志

**D028冻结工作点**: 单声部峰值 2097152（8192 << 8）
- 4声部合成峰值：8388608（刚好触发削波）
- 余量：0 dB

**核心参数**:
- 累加器位宽: 至少32位（接口规范v1.2要求）
- 数学分析：26位足够（4复音），27位（8复音）
- 饱和限幅: 超出±8388607时限幅
- 严禁回绕

**验收**: 待M2实现T024 RTL后进行逐样本对比验证

**未验证项**: 
- RTL实现尚未完成（T024）
- RTL逐样本对比待M2提供仿真输出

### T010 声部管理
**位置**: `code/model/voice_manager.py`

**设计文档**: `code/docs/test/T010_声部管理策略.md`

**策略**: 最旧声部偷取（Oldest Voice Stealing）
- 新音符优先分配空闲声部
- 无空闲时，停止最早触发的声部
- 同音重复：重新触发

**Python参考**:
```python
class VoiceAllocator:
    def note_on(self, note_number) -> int:  # 返回分配的声部索引
    def note_off(self, note_number) -> int
    def all_notes_off()
```
