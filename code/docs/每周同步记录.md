更新时间：2026-09-11。流程见 `三人协作执行手册.md` 第八节，周次见 `八周排期与里程碑.md`，同步点定义见 `抉择与并行开发顺序.md`。

## 一 用途

本文件记录每周三方同步的结论，是项目过程的唯一轨迹。同步点 S1 至 S7 的三人验收结论必须写在这里；任务看板只有一格状态列，装不下结论本身。

规则：

- 每次同步后当天由当周主负责人追加一节。只允许追加，不允许改写或删除历史节。
- 结论必须写清确认的具体内容，禁止只写"已确认""没问题"这类无法追溯的说法。
- 遗留问题必须写编号和责任人；未分配责任人的问题不视为已登记。
- 缺席或未达成一致的项，写明分歧点与下次评审时间，不得默认通过。

## 二 记录格式

```text
### W<n> YYYY-MM-DD 同步点 <S<n> 或 无>

- 出席：

- 同步点结论：

- 下周集成窗口：
- 资源占用：
```
