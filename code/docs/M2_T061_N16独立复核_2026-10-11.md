# T061 N16 独立事件到 PCM 候选复核

2026-10-11，M2 对 `0ca4515` / B2D N16 交付包做独立复核。结论为**独立功能 L2／数学 L3 限定通过**；不签生产16音、32音整链、冻结L整top逐时钟等价、物理40MHz或整机deadline。T061保持PARTIAL。

## 负例与边界

12个完整capture坏例按指定原因全部拒收，保留完整END和计数；包含A/F/L移沿、slot15 generation、路由source、高占用snapshot、PCM、bank context和late标志。两个编译成功行为反例：忽略generation compile0/sim1并报`B2B_STALE_GENERATION_ACCEPTED`；增益置零compile0/sim0后独立checker exit1并报`MATH_GAIN_PCM`。原40项单测exit0，stderr为`Ran 40 tests ... OK`。

## N8同身份新边界

发布期收到后继提交后，M2使用冻结 `33c8b70` 的原N8控制snapshot和真实B1 state bank，通过公开snapshot/config/control/read接口做短定向复现：活跃slot3与空slot7共用source/channel `f/f`时，空槽默认控制值覆盖活跃槽共享控制，compile0/sim1并报`N8_ACTIVE_IDENTITY_CONTROL_CLOBBER`，实际读到`02000000`。原N8长短capture通过结论有效但只覆盖原夹具，不能外推为一般N8无缺陷。

收到的后继控制snapshot只在N8仿真副本中验证三个身份场景、四次活跃读回通过；不等于完整N8后继、N16全量或生产采用。远端后续B2E/N32只记录为收到、未复核。

## 登记边界

本复核支持N16独立功能L2、独立数学L3限定签收；R64明确不准入。生产16音、32音整链、冻结L整top逐时钟等价、物理STA、整机deadline、上板和下载均未通过。新组合离线L5、T062模块L5与N16候选分开登记，不混用RAM版本或证据。T060/T061保持未关闭。
