# T005 PT8211 物理声道与末位对齐复核（2026-09-28）

范围：只读核对正式 `i2s_tx.sv`、T005/T007/T034 测试与约束，并新增独立的引脚级反例测试。**未修改正式发送器、顶层、CST、SDC 或冻结接口**。本轮只证明现行数字输出与手册所述物理声道极性不一致，以及按手册图示末位位置解释时的 1 位差异；**不是 DAC 模拟输出的 L6 测量，也没有验证修复后的完整项目时序**。

## 原始依据及现有覆盖

- 项目内官方手册 `code/docs/PT8211_V1.7_E_数据手册.pdf`，V1.7（2022-08）第 3 页的 PT8211-S 引脚表仅有 BCK、WS、DIN 三个数字输入，**没有 MCLK 引脚**；第 4 页 Function Description／Figure 1、Figure 2 写 BCK 上升沿采样、Japanese/LSBJ、WS 低送**右**输入寄存器、WS 高送**左**输入寄存器，LSB 在 WS 边界前。手册 SHA256 `3ceb112d58b95ce2af9478c531c9c54fe578e3b634ff18e11960ef8e5370d035`。
- `code/docs/模块接口规范.md` §5、`code/rtl/audio_out/i2s_tx.sv` 和 `code/tb/audio_out/tb_i2s_tx.sv` 一致使用**低=左、高=右**；TB 用同一约定解码，因而它的 19 项 PASS 不能独立证明 PT8211 的 LCH/RCH 正确对应。
- V0100 的 T005 模块 19 项、缓冲 17 项及 A,B,B,B,B,C 欠载序列，V0071 正式单声部 L5、V0106 T034 BCLK/LRCK/DIN 定向路径 L5，分别证明其陈述的数字行为与工具路径；**均未测 PT8211 上 LCH/RCH 或单喇叭的模拟幅度**。顶层固定音左右 PCM 相同，因此声道互换在单喇叭听感中可被掩盖；声像／不同左右内容仍受影响。
- 顶层真实 50 MHz 的 T007 testbench 有 3.072 MHz BCLK、48 kHz LRCLK、64:1 比例、复位与 `pa_en` 检查；T005 的 ACC_BITS=8/STEP=1 属加速仿真，不能代替真实参数的绝对频率证据。正式约束映射 Y17/AB17/AA16 到 BCK/WS/DIN，输出路径的工具模型不能替代板上逻辑分析仪及 DAC 测量。

## 最小独立反例

入口：仓库根目录运行 `./code/scripts/run_t005_pt8211_review.ps1`。它复制原始 RTL 和 `code/tb/audio_out/tb_pt8211_ws_polarity.sv` 到独立 ASCII 临时目录，使用 Icarus 编译、VVP 执行；原始版本故意返回非零，不接入绿色门禁。TB 以 50 MHz sys_clk、ACC_BITS=8、STEP=32（仅测试 WS/BCK 相位，**非真实 48 kHz 绝对频率用例**）输入左 `+8448`、右 `−12544`，独立按官方物理极性读每个 WS 半槽最后 16 个 BCK 上升沿：左应 `0x0021`，右应 `0xFFCF`。避开上电起始阶段后检查 6 个半槽及每槽 32 个 BCK 边沿。

- 正式 `i2s_tx.sv` SHA256 `e4d77a194e28ae133346d13f306ad0b07060a1dce68214e5d93ad1c3291d4577`；测试台 SHA256 `ed2e1feab3e2bc0bac20a58a004fdc3c3c7c4a06c7c7c1b059d1b26236f999de`。原样运行：WS=0 得 `0x0042`（左样本的两倍），WS=1 得 `0xFF9E`（右样本的两倍）；6/6 不符，**预期 FAIL，进程退出 1**。
- 只在系统临时目录对源文本作定位变体，不改仓库 RTL：① 只交换 `sample_left/right` 装载分支：WS=0 得 `0xFF9E`，WS=1 得 `0x0042`，仍失败；② 只将 `LOAD_SLOT` 的 `DAC_WIDTH−1` 改为 `DAC_WIDTH`：WS=0 得 `0x0021`，WS=1 得 `0xFFCF`，仍是物理声道反向；③ 两项同时变更：6 次物理声道检查 PASS、退出 0。这是定位试验，**不是正式修复验证**。

第 4 页文字另有「数据长度超过 16 位时只取先到的 16 位」表述；与项目现有的 32 位槽高半段填 0、低半段数据右对齐的组合关系，仍需用同版逻辑分析仪在 DAC BCK/WS/DIN 脚及 LCH/RCH 模拟输出处验证，不能仅凭本 TB 断言实际 DAC 一定输出二倍幅度。电源与模拟通路亦会影响单喇叭听感。

## 影响及后续处理

1. 单喇叭且左右内容相同的现有演示可以继续做功能展示，但不宜据听感声称立体声物理映射、16 位 DAC 幅度或音质已验证。
2. 由于 `模块接口规范.md` 属受控接口组，正式更改 LRCLK 极性与发送器前须完成群内事前说明和接口影响分析。同步更新 T005 既有 TB 的物理声道期望、接口说明和相应验证记录；复测 50 MHz 顶层频率、LSBJ 位相、PCM 24→16 舍入／饱和、复位、T055 欠载与完整 Gowin 50 MHz PnR。
3. 由 M3 在**断电接线、共地且确保逻辑分析仪量程适当**后，抓同版本 BCK/WS/DIN 与左右模拟输出，输入分别是左非零右零、右非零左零，确认实际接入扬声器的是 DAC 的哪个声道、末位相位和实际幅度。记录码流提交、工具版本、BCLK/LRCLK 实测比值、波形及功放路径。此步骤是待执行的 L6，**本报告没有做**。

验证等级：本轮是 **L2 定向反例仿真（现有物理接口期望失败）**与手册 L0 核对；历史单声部 L5、V0106 定向 STA 的范围如上，不可混写成这次新修复通过。按 D025 只有发现问题才需新增验证记录，编号须留到推送前最后 `git fetch` 后取；当前本地与远端分叉，尚未登记编号、提交或推送。
