# MIDI深流水与事件呈现候选（2026-10-05）

本轮按用户批准在隔离test目录推进，不修改生产parser/银行/top/约束。V0191原两候选原型扩大为前四候选，依据计算锁定间最多3次单槽更新。E捕获、E+1分组、E+2归并、E+3校正并锁payload；四旧候选+两记录更新+当前更新，保持最终锁定时的live RR和latest，不用全局epoch重试。新增输出呈现寄存器只复制FIFO头，只有真实输出handshake才pop，因此没有隐形增加FIFO深度；旧valid在backpressure保持，控制可服务且达到burst限制时不呈现下个离散head。

## 已执行的功能验证

- 实际Icarus burst1/depth1、burst8/depth8、burst16/depth8：13648/13739/13739拍，56752/57285/57286断言；每组105锁定、104控制消费，319/358/358离散，4次取消、13次inflight update、2次锁定同拍latest、1次真实满FIFO同拍pop/push。
- 真实50MHz使用50000clk间隔，100065拍400296检查，3控制消费；不缩短实际限速参数。
- 独立线性RR生成18592组前四snapshot，111552项断言，空/短向量拒收。
- 四个实际可编译错误RTL非零拒收：第八次后继续离散；撤回已呈现head；锁定漏最新值；只留两个候选导致无故重试。初始两候选变异会在下一轮补发而误绿，已补第一轮仍有livepending必须grant断言，保留原失败。
- 复用F真实31250 8N1双UART→32公共FIFO→原V0171真实四声部V1/CC64/PitchMod/ADSR流水→PCM：2486 commit/2484正常PCM/2301非零PCM/3734非零控制lane，103UART字节、8身份、17必需场景、7777274断言；697中心参考对照，1满FIFO同拍pop/push，56真实控制背压拍。逐样本独立FCW/相位/原ROM/Q15 floor混音检查全部PASS，reset取消1请求。空/截断capture及PCM一位错误实际拒收。
- 通用Yosys/slang结构检查无latch（482generic寄存bits含映射memory差异，不作Gowin面积数字）。

## 行为边界与失败保留

本候选不与旧parser逐拍等价：离散首次呈现及控制锁定增加空拍，满队列持续超高速合成输入下不能宣称overflow发生拍数和旧版完全相同。容量和每一次实际握手的FIFO顺序、计数、latest、去重、限速、有界服务有独立oracle，正常真实UART链通过。没有接入CC7面板候选/T027/T028，不外推为最新全部功能整机。

初编译声明先用后定义已纠正；压力fixture需12bitCC扩展值及准确E+3驱动，不冒称fixture为真实UART。最初重复全部50MHz场景300s超时，改真实限速专项后通过；原超时不作PASS。原PCM bank/router/ROM不改，只sim长include路径重绑定及原allocator通用lower以兼容Icarus。

## 有边界的物理筛选

输入固定V0171已完成组合47源，新项目仅parser替换+selector新增共48条，原audio+严格闪光/ROM/headers/CST/SDC全SHA固定。先综合，再以Logic增量<=256、FF<=512、DSP/BSRAM不增筛选是否进入一次1800秒PnR。最终要求所有域/CDC/引脚检查、Setup>=0.5ns且同条件改善>=0.1ns、Hold/Recovery/Removal不退步。超预算/超时/失败保留原版，不挑seed、不改时钟/约束、不烧录。

当前物理综合在运行，尚无新STA或可放行码流。实际结论待本轮原始报告。M3另DVI平台试布线不重复。
