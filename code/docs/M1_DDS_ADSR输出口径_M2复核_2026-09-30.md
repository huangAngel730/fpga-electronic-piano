## 附件实际复核

原始说明和ZIP来自用户2026-09-30转交；文档署名2026-09-28仅为交付内容，不能覆盖实际接收日期。ZIP的test_dds_adsr_output_spec.py在隔离目录退出0，但无assert、无失败判定，也未导入真实apply_envelope；它只是展示公式。

- 文本静态表把(-8192,32767)截断结果写成-8191，实际函数计算-8192。消息及Markdown表该值正确，脚本打印段错误。
- 备选round函数负数减16384再算术右移不是正确最近舍入：-8192*32767会输出-8193而非-8192；-32768*32767恰为整数-32767，却变成-32768。勿使用这份备选实现。
- RTL示例未显式把unsigned envelope正扩展为signed，混合有符号乘法和>>>可能变成无符号移位。正式实现必须显式声明乘积宽度和符号。
- 73210样本旧验收针对包络幅度，非DDS×ADSR最终PCM对照；不可据此宣布新增幅度公式已经RTL验收。
