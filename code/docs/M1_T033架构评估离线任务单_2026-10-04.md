## 必须比较的三个候选

A 全声部并行复制：独立DDS/ADSR/乘法与控制，平衡/流水混音；明确重复ROM/DSP和路由扇出成本，不使用N倍旧占位LUT作为已测数据。
B 混合：每声部独立状态，共享波表读取/部分乘法，其他运算并行；写清同步ROM端口、读延迟、地址与声部标签、回写冲突。
C 分时运算：独立相位/包络/身份/音色/PitchMod状态表，硬件调度共享计算；保持每采样完整计算所有声部，不能缩减采样率或改包络时间来节约周期。

每个候选先列N=4/8/16/32四档：
1. 波表、ADSR、Velocity、Pitch/Mod、增益、混音、状态回写需要多少真实访问/运算；逐项区分延迟latency与发起间隔II，不能把流水深度等同吞吐周期。哪些系数可缓存必须有失效规则与算法等价依据。
2. 最短实际帧1041个50MHz周期（帧间隔1041/1042），预算要扣接收/锁存、同步ROM、pipeline充排、有效结果/提交和取消保护。给可配置保护周期并说明只是提案；现30clk四声部测量仅限原候选，不能直接除出最大复音数。
3. 每slot保存什么状态、位宽/容量，特别是来源/通道/音符/身份代次、Release、CC64键保持；共享LFO要避免被逐声部调度多推进，参数快照/标签要避免抢占旧结果串入新身份。
4. 极端事件流和sample忙时的握手/调度；解释事件延迟增加、背压FIFO溢出风险，不能以增加缓存或改变公共ready掩盖。
5. 资源列表按实测/解析推算/待工具确认三栏；包括逻辑、FF、DSP、BSRAM端口/字宽和独立/共享ROM。不要假称厂商DSP映射或RAM总量已确认。
6. N路满幅会削波：至少32位有符号累加，讨论扩展档增益/headroom与舍入作为待批准方案，不自行变更现有单声部±8192/Q15/PCM24幅度口径。FFT谐波峰数不能冒充独立声部数。

## 模型自检

预算模型用标准库，输出可追溯表（配置/II/流水/访问数/帧成本/剩余周期）；覆盖4/8/16/32，II与latency区别、刚好够/超过预算、非法配置，故意把II漏算或少算声部的反例必须被拒绝。未知工具实现只能标unknown，不设为0。可承受档位结论分成数学周期可行、预计资源可行、实际综合/STA待验，不承诺任何N已满足最终50MHz。
