## 限定结论

三个相同 Note60/velocity1023 的实际 M1TD 实例：默认钢琴、Program1 三角、未再切换的三角参考；延迟效果关闭。128帧 PCM24 对照中两音色各127帧非零，128帧不同。第64帧后对第二实例送 Program0，持音继续与第三实例接下来的64帧逐样本相等。反例跳过 Program1 时三链输出同音色，判据 `TIMBRE_PCM_NOT_DISTINCT` 退出1。独立 router 回归已证明 MIDI Program 事件锁下一音；本次验证的是统一事件输入后的**真实音源到 PCM24**。两个独立 L2 不合并宣称同一次 UART→I2S/板级端到端通过。

实际等级仅隔离 RTL 仿真 L2；没有带延迟的立体声效果差异、正式整机帧缓冲串行比较、用户实体 MIDI PC 消息、音频录音或上板证明。`board_release_allowed=false`，基础四声仍待 M3 精确同版诊断；双音色板级验收仍须实物来源/PCM或录音与正式同版身份。M2 下一步只在收到 M1 发布精确 SHA 和 M3 实物/独立事件日历后按任务单 P0/P1 核验，不重做已签专项。无新增 Gowin、PnR、STA 或 `.fs`。
