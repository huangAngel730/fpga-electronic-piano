# M2 可视化模式与曲谱控制输入 CDC 独立试验（2026-09-28）

**结论：M2 的模式命令与 98 位曲谱入口在独立行为仿真及物理时序专项中通过；正式音画工程仍未通过。** 本阶段不改 M3 的 `code/rtl/input/visualizer/`，不改电子琴正式顶层、公共事件包、正式 CST/接口规范，不烧录任何试验码流，不冻结正式曲谱生成方案和输入方式。Gowin V1.9.11.03 Education，目标 GW5AT-LV60PG484AC1/I0。

## 接口与契约

M3 现有曲谱输入按 `note_id[15:0], note_number[6:0], hit_frame[31:0], duration_valid, duration_frames[31:0], velocity[9:0]` 拼为 **98 位**，高位到低位顺序固定。`visual_control_bridge.sv` 的源侧接系统时钟 `src_score_valid/ready` 与多位字段，目标侧输出像素域 `video_score_valid/ready` 与相同字段；一项命令只有在源侧 valid&&ready 时才成立，源必须持有 valid 和全部字段直到握手。源端被反压期间不得覆盖命令，也不能把单周期外部脉冲直接接 valid。**曲谱源与文件格式、秒转帧量化仍待 M1/M3 定案**，此模块只是可靠搬运已经量化成帧的命令。

模式请求为另一路独立的系统域 `src_mode_valid/ready`，搬运为视频域恰一个像素周期的 `video_mode_toggle_pulse`；不依赖曲谱 ready，M3 仍在其模块里等下一帧才切换显示模式。若真实按键的一拍脉冲来自系统域，上游必须保持/排队直到 `src_mode_ready`，否则可能丢按键。**两条通道与音频接受 ready 无逻辑连接，不反压声音。**

两通道均复用 M2 `visual_mailbox_cdc.sv` 单槽 request/ack toggle、首级双触发器同步、载荷锁存并持有到视频侧接受回传 ACK。`rst_n` 必须由统一的外部异步断言源（含视频 PLL lock）提供，不可只重置一个域；各自本域通过 `reset_sync` 同步释放。此模块独立声明数据结构，未修改公共事件接口；后续正式顶层接入仍需变更说明和接口组群内预告。

## 独立物理路径双模式证明（仅控制桥专项 L5）

```powershell
.\code\scripts\build_visual_control_probe.ps1 `
  -ReferenceRoot 'D:\Temp\Angel17\sipeed_mega60k_example_20260927' -Mode sentinel
.\code\scripts\build_visual_control_probe.ps1 `
  -ReferenceRoot 'D:\Temp\Angel17\sipeed_mega60k_example_20260927' -Mode bounded
```

该合成顶层 `visual_control_probe.sv` 使用 98 位**未绑定实物引脚**的外部激励和动态位索引串行观察输出，只为防止综合删除曲谱字段；不能下板。参考 50MHz，独立 PLLA 输出像素25/串行125MHz。曲谱/模式由两条握手桥分离；输入探针只是给工具造状态，并非正式曲谱生产者，其合成激励不遵守每笔源 valid/ready 保持契约，不能据此宣称完整功能。正式运行时必须由遵守握手契约的曲谱源驱动。

`visual_control_probe.sdc` 只对两条 request/ack 通道共4个同步器的**首级 D 端**设精准时序例外；八条二级 Setup/Hold 路径各有非负报告；曲谱的 98 位 `payload_hold→dst_data` 施加实验性 `set_max_delay 10ns`，不设整域异步/整条数据 false path。两个模式分别产出独立报告、不互相覆盖：

| 模式 | 用途 | 曲谱载荷端点 | Setup/Hold 违例 | 最差曲谱余量 | 资源 |
|---|---|---:|---:|---:|---|
| 1ps sentinel | 故意不可能满足，证明确有98条载荷路径被约束，**非PASS时序** | 98 唯一 | 98/0 | −5.293ns | Logic92/59904，FF336/60780，PLLA1 |
| 10ns bounded | 独立控制桥物理路径试验 | 98 唯一 | 0/0 | +4.706ns | 同上 |

建立/保持后级八条与恢复/移除均未报负余量，报告检查器对未知 broad false path、错时限、缺后级路径、缺一项 98端点等失效均应非零退出。本轮用4组故意篡改真实报告验证检查器 fail-closed。原始完整报告与生成工具日志、综合产物存于被忽略的 `code/output/visual_control_probe/sentinel/` 和 `bounded/`，不入库；9项来源/路径哈希及八条后级数值见 `code/docs/evidence/visual_control_probe_20260928.json`。两版仍有 `PR1014` 普通时钟布线警告；独立脚本执行 PnR 生成的 `.fs` **一律不可下载**。
