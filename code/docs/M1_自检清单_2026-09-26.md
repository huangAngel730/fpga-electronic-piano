## 关键修正点总结

### ADSR同拍读取问题
- **问题**：Note On同拍读velocity_gain_rom[velocity]和retrigger_level
- **修正**：分两拍处理
  - 第1拍：rom_addr <= velocity; 捕获start_level
  - 第2拍：target_gain <= rom_dout; 进入ATTACK
- **验证**：等待ROM稳定后再使用数据

### Release重触发平滑
- **问题**：从Release跳回0再Attack
- **修正**：Attack从start_level开始
  - Release状态：start_level = level（当前电平）
  - 其他状态：start_level = 0
- **验证**：跳变<138 LSB

### Release电平计算
- **问题**：Release使用错误的start_level（Attack的）
- **修正**：新增release_start变量
  - Note Off时：release_start <= level
  - Release中：level = release_start * (1 - progress)
- **验证**：Release曲线正确下降到0

### 声部分配Icarus兼容
- **问题**：`for (int i)`不兼容
- **修正**：`integer i`外部声明
- **验证**：Icarus Verilog可编译

### 来源/通道身份
- **问题**：缺少source_id
- **修正**：添加4位source_id输入
  - 槽位保存source
  - 匹配时比较note+source
- **验证**：同音不同源分配不同槽

### 时间戳回绕
- **问题**：16位时间戳回绕
- **修正**：有符号差值比较
  - `$signed(slots[i].timestamp - oldest_time) < 0`
- **验证**：回绕时仍正确
