## 五 判定规则

- 任一资源占用超过器件可用量的 70% 判为不安全档位，不得作为承诺规模。
- 时序未收敛的档位不得写入报告与答辩材料。
- 对外承诺的声部数取资源与实测同时成立的最大档位。
- 报告口径必须与实际冻结档位一致，目标值只能出现在展望部分。
- 预估阶段与实测阶段的口径要区分标注，预估结论不得写成已实测。

## 六 时间要求
