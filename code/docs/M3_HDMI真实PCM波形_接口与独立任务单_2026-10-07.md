## 2. 数据来源：实际帧装载，而不是提交或MIDI

原顶层`u_i2s_tx`输入clk=core_clk、rst_n=rst_sync_n、valid=1'b1，
pcm_left=buffered_left、pcm_right=buffered_right、frame_tick=i2s_frame_tick。
音频core为40MHz；buffered_*来自PCM帧缓冲的play_*，为空时保持旧样本，首次为0。
**M2观测支路在posedge core_clk、i2s_frame_tick为1的同一沿，寄存pre-NBA的buffered_*。**
这是发送器此沿所用的24位混音数据；不能延后一拍再读buffered_*，也不能只采
pcm_valid&&pcm_ready、sample_req/sample_tick或按MIDI重新生成波形。

音频域候选观测接口（M2在新副本中实施；以下为合同，不是已存在的端口）：

| 口 | 定义 |
|---|---|
| pcm_obs_clk | 原core_clk，40MHz |
| pcm_obs_rst_n | 原rst_sync_n，低有效异步拉低、上游core域同步释放；含原PLL失锁复位 |
| pcm_obs_valid | 寄存后的1个core周期脉冲，一次完整左右帧装载对应一次 |
| pcm_obs_left/right | signed24，脉冲同拍数据由上述pre-NBA值寄存 |
| pcm_obs_seq | u32观察帧序号，首个装载为0，每次装载+1，丢显示包也照常递增，模2^32 |

每个装载都观察：起始静音、有效零、欠载保持重复、欠载恢复；不得按值去重或抑制0。
pcm_obs_seq不是生产请求ID。观测的“一次装载”不等于“一帧物理串行已完成”：采集起止
可有首半帧或最后已装载但未完成帧。不能把5849类装载数强改为5848类完整解码帧数。
帧与物理S记录比较须沿用原已验相位/首半帧/尾帧关联，不能自己移一拍凑数量。

显示本阶段映射的是发送前signed24 PCM，不声称模拟DAC电压；发送器原24→16舍入/饱和
仍保留。若核对串行16位，参考`sat16((signed24+128)>>>8)`，不把显示映射反馈进声音。

## 3. M2 CDC、复位和M3单域入口

M2负责音频观测寄存及整包40→25MHz CDC，带序号的左右数据80bits必须一次原子传递。
使用独立观测异步FIFO或等价经审查方案，不逐位双触发器同步PCM、不直接跨域读多位总线。
FIFO容量/深度/厂商映射和复位握手由M2独立验证，不把准备设计当已通过CDC。

FIFO满时只丢观测包/记录显示侧丢包；**任何full/ready/绘图状态不得进入audio pcm_ready、
frame_tick、sample_req、pending_valid、发送器valid、PA_EN或音频reset路径。**
音频仍按原合同提交和发送。显示处理慢可以丢完整窗口，不能阻塞音频或更改它的计数。

M3的实际输入全部在pixel_clk=25MHz域（独立TB直接驱动此入口，不实现40→25CDC）：

| 口 | 方向/含义 |
|---|---|
| pixel_clk, pixel_rst_n | 输入；低有效本域复位，异步拉低/同步释放由M2提供 |
| sample_valid | 输入；一个pixel周期表示一包原子观测样本，不设ready输出 |
| sample_seq[31:0] | 输入；与该包左右样本绑定，判断序号连续性/丢包/正常回绕 |
| signed sample_left/right[23:0] | 输入；原signed24，不做左右平均，默认绘左声道 |
| stream_restart | 输入；本域1拍重新同步通知，清窗口元数据/连续性，优先于sample_valid |
| pixel_x/y[15:0], data_enable, frame_start | 输入；现有640x480有效区、800x525总扫描；不改扫描 |
| waveform_enable | 输入；M2提供本域帧边界稳定电平，本阶段不增加切换按钮/MIDI/公共模式 |
| waveform_mask, waveform_r/g/b[7:0] | 输出；矩形覆盖掩码及RGB，严格延迟2个pixel周期 |
| trace_valid | 输出；已发布完整当前流窗口，未热身/重同步不得读未初始化缓存作波形 |
| display_gap_count, window_drop_count[31:0] | 输出；显示侧饱和计数，本独立模块debug，不接现有STAT |

sample_valid允许背靠背为1（FIFO暂停后可能突发排空），不能假设两包之间必有48kHz空隙。
没有ready；写缓存忙时本模块可以只丢显示并计数。display_gap_count计不连续/重复序号事件
及本模块主动丢弃样本的事件次数，不当作缺失帧数量；正常模回绕不计。window_drop_count
计已完成完整窗口被丢弃/待发布窗口被新完整窗替换的次数，不把热身或未完成窗当完整窗。

定义render latency：posedge N采到的x/y/de/enable，结果在posedge N+2后有效；
TB按此口径逐拍比对，不能将绘图延迟冒写成0。M2最终把原动画RGB以及HS/VS/DE一起对齐
再合成/沿用原DVI发送寄存，不能只延迟RGB导致错列、边界/消隐漏色或错帧。

音频复位/PLL失锁时，M2使观测FIFO两侧重初始化，像素端失效旧窗口，完成双域握手后再发
sample_valid，并以stream_restart通知新流；不能旧epoch样本混进复位后的窗。
像素显示单独复位时只重同步观测支路，不拉音频复位。waveform CDC未就绪仅使波形无效，
不得额外门控原扫描/音频复位。M3 reset或stream_restart只清元数据/索引/有效标志，RAM
不必全清；第一包seq可非0（例如像素单独复位），之后按模2^32连续，否则重建当前采集窗。

## 4. 第一阶段固定布局、时间窗和绘图

采用**固定不透明覆盖窗口与原动画共存**，不改原动画内部状态和事件流。
有效区仍640x480；波形区域x=64..575（512列）、y=64..319（256行），其他像素保留原动画。
区域内覆盖原RGB是明确设计；不宣称原动画在这块区域仍完全可见。
waveform_enable=0时覆盖mask为0，整个画面退回原动画；本阶段开关仅供M2帧边界配置，
不占按键、不复用原display_mode语义，不新增物理或MIDI切换功能。

默认左声道，不由L+R另造混音；右声道仍保留在输入包供映射/立体声一致性测试。
固定采集窗2048个连续实际音频帧，约42.667ms（48kHz）。512列每列4个连续样本，
取原signed24的min/max绘垂直范围，保留尖峰；不能只每四个取一个点却声称保留全窗口。
这是显示压缩，没有改变声音或采样率。

振幅映射固定：`q = signed_pcm24 >>> 16`（-128..127），`y = 191-q`（319..64）。
0在y191，正幅向上、负幅向下，+8388607→64，-8388608→319。比较和移位都必须signed，
正负满量程、近0/LSB边界须自检。不乘FFT/AGC/自动量程；超出PCM24合法范围的测试输入
应由runner/checker非零拒收，不用截断隐藏错误。
区域背景深色、零轴灰色、波形青色，轨迹优先于零轴；边框如果增加应在此矩形内定义并
同步参考模型，不能扩大mask。未有完整窗时只画背景/零轴，不读随机RAM作非零曲线。

采集与当前显示窗口必须分离：双银行或等价完整快照，在frame_start才换前台窗口，
同一视频帧内前台读数据不变。允许三银行（front/pending/write）减少丢显示窗口；
若双银行写侧无空闲，只丢显示输入/窗口并计数，绝不能覆盖正在绘制或待发布银行。
优先小存储；mono每bank512*16bit min/max约1KiB，2/3银行逻辑2/3KiB，实际BSRAM/FF/DSP
归M2后续综合核实，不承诺映射/时序数值。丢序号时清当前未完成窗，不把断开的两段连成
假连续曲线；可保持上一完整前台窗直至新连续完整窗，在debug标记丢显示。
不新增触发、缩放菜单、李萨如/频谱或动态时间窗功能；如需另提任务。

## 6. M3独立验收与交付

首次真实数据从只读`code/tb/audio_out/m3_clock40_pcm_serial_acceptance/evidence/`的
normal_capture.b64（raw SHA23e823c4...dfe4，5849个A）及diagnostic_capture.b64
（raw SHAb212b560...06b，41个A）解码，先用raw_manifest验证完整原件SHA/长度。
A记录为`A time_ns adoption_index request_id left24 right24`，左右是十进制signed24，
sample_seq=adoption_index-1；不能把S十六进制串行位或request_id误读成显示PCM/序号。
已在准备证据记实际完整SHA与首尾A。正常原件足够形成完整窗口，诊断短流不足2048的情况
必须正确判无新完整窗口；不能重复/补0拼成“真实2048窗”，也不能拿MIDI重建当真实PCM。
纯数学极值/脉冲/随机向量另外标synthetic，用独立signed/min/max/坐标参考验证。

至少覆盖：真实正常全A流（包含静音）、真实诊断的不同左右/欠载重复/恢复，正负极值和0，
4点bin尖峰、2047/2048/2049与最后不足4样本边界、连续多个完整窗、seq丢失/重复/模回绕、
背靠背sample_valid/突发排空、采集/显示复位与stream_restart、采集结束无后续样本、关闭覆盖、视频帧中禁止换前台、
全扫DE/消隐边界/固定2周期延迟、故意阻塞发布时只丢显示/统计而输入无反压。
这些是单域显示合同测试，不能声称已验证跨时钟FIFO或真实音频不受扰动。

至少8个完整原800x525视频扫描帧，实际逐像素自检/独立参考比较（含mask区外、暖机和发布），
保留非零比较计数、窗口/银行/序号摘要；不能只比较预生成图片或不跑RTL的期望结果。
不需提交巨量逐像素文本，但完整原日志、捕获原字节SHA、自动比较计数/失败位置齐套。
至少两个可编译行为反例（例如错误signed幅度映射、前台银行视频帧中覆盖）必须compile0、
sim完成，再由独立checker因指定语义错误非零拒收；编译错/超时不是反例通过。
加空/截断/错误seq/错误END计数等损坏证据，fail-closed拒收，不以空数据得PASS。

runner用唯一新目录、拒绝覆盖旧结果；编译/仿真/判定分别收退出码，建议单子进程≤600s、
