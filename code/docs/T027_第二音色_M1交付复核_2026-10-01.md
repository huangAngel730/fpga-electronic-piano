## 待修正问题

1. **幅度与 v1.5/v1.6 不符。** t027_timbre_model.py 的 SAMPLE_MAX/SAMPLE_MIN 及两份 ROM 为 +32767/−32768，而正式 polyphonic_audio_core 使用 sine_1024_8192.mem、波形标称 ±8192。不能把近四倍幅度无补偿送入已冻结混音器，也不能在已有 ±8192 上重复乘 0.25。请以 ±8192 重新生成两表和断言；不改 ADSR 与 PCM 定标。
2. **数据与 sample_valid 错拍。** timbre_oscillator.sv 中地址经过 addr_d1、addr_d2、ROM 数据寄存器、sample_out 四级，而 valid_d1、valid_d2、sample_valid 只有三级；选择信号也未跟随 ROM 数据再寄存。连续输入地址 1 时，valid 对应期望正弦 201、实际 0；地址 2 期望 402、实际 201。应以同一地址/音色标签对齐 data/valid，并写清采样边沿与延迟；不可只把测试整体挪一拍掩盖错位。
3. **Note Off 截断振荡采样。** note_active 在 Note Off 后清零，相位推进和 valid_d1 都停止；当前 ADSR 则在 Note Off 后仍需持续波形完成 Release。实测流水线排空后 12 拍 valid 全 0。M2 不会直接用此门控替换正式 DDS；请让振荡器的工作周期服从声部整个生命周期，包含 Release，或移除不合适的 Note Off 门控。
4. **切换语义与实现不符。** 文档说新 Note On 使用当前选择、已有音符保持原音色；实际每拍采 timbre_select，没有每槽 Note On 锁存。测试当前相位 128，选择改变后输出从正弦 23170 变为三角 16384。请落实每声部锁存口径，或先提出有明确安全边界的另一方案，不以文档描述代替实现。
5. **重触发清相位违反离线任务要求。** Note On 分支将 phase_acc 清零；观测重触发前 0x03000000、后 0。固定 240 采样 ADSR 重触发并不保证该波形突变平滑。请保持连续相位；全局复位可以清零。不改已有 ADSR 曲线。
6. **缺少可配置 ROM 路径与真实自检。** 新 ROM 位置为 code/model/generated，RTL 却硬编码 cwd 的两个 hex 名，不能直接沿用既有构建器仅处理原表的路径逻辑。请给常量 ROM_FILE 参数/生成路径并验证加载完整无 X；补自动判定的 RTL TB、两音色最低/最高音测频、四实例独立切换和 Release。三项纯打印不计 PASS。
