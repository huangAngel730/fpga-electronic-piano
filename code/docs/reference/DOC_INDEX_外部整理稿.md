# Tang Mega 60K 硬件资料索引

## 范围与使用原则

- 本索引对应实物组合：Sipeed Tang Mega 60K 基础套装，30354 核心板 + 31005 Rev 1.4 NEO Dock 底板。
- 稳定资料基线为 4 个文件：1 个 Excel 引脚事实表、1 个官方 CST、2 个原理图 PDF。
- 按用户要求，不直接解析两个 PDF；原理图页码、网络、器件和连接器信息使用 Excel 中已经整理的结果。
- FPGA 物理球位、`IO_TYPE`、上下拉和驱动等工程约束优先采用官方 `tang_mega_60K_pins.cst`；Excel 用于解释球位对应的实际硬件网络、连接器和复用关系。
- `~$Tang_Mega_60K_30354_NEO_31005_引脚事实表.xlsx` 是 Excel 打开工作簿时产生的临时所有者/锁文件，不是硬件资料；它可能在工作簿关闭后自动消失。

## 读取顺序

1. 先读本索引，确认资料范围与版本。
2. 读 Excel 的 `资料与版本` 和 `电气与复用规则`，确认板卡组合、证据优先级和禁止事项。
3. 按实际功能读取 Excel `引脚事实表` 对应行，获得网络、BTB、物理球位、终点和复用关系。
4. 从官方 CST 复制或核对该功能的 `IO_LOC`/`IO_PORT`；不要根据 Bank 名称自行推导 IO 属性。
5. 查阅 `BOARD_CONTEXT.md` 的冲突和待确认章节；遇到冲突不得静默选边。
