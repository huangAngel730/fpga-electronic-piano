Dock p10：PT8211-S VDD-5为3V3A（U21稳压+FB6），LCH-6经U17低通/耦合到NS4263 INL-6，
RCH-8经U18低通/耦合到INRN-11；U20的VBUS_PA供电及J27/J28喇叭端、J25耳机端固定链路
明确。PA_EN=1关闭功放，=0打开；R131上拉100k、R132串联1k到SD。候选源码实际

不是CodeGraph HDL索引，不代表实物无爆音或模拟指标验收。

MIDI不是板上原生DIN接收器：候选接R17，板载USB-UART RX为V14（本候选没有使用V14作MIDI）。
现有资料只能追到PMOD/SDRAM连接器，不能证明外接光耦/适配器OUT的电压和FPGA侧共地。
