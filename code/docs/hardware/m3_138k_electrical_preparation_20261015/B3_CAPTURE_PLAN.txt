基础四复音同版实物取证计划——当前NOT_RUN，须先满足README双门槛

所有组共用同一正式.fs完整SHA、输入/工程/ROM/约束/工具身份及同一接线记录。
不得用其他码流、60K旧记录或离线重放拼成138K同版通过。

1. MIDI/声音与独立控制
   原始NoteOn/Off、力度及音高/和弦/触发记录；四音同时、逐键释放、第五音抢占、
   复位恢复。记录实际活跃数与模拟声音原件。两维各有实际控制及FPGA映射证据，
   外购键盘具备Velocity不是团队自研两维验收。缺第二维就标待验，不擅增接口。
2. 数字I2S与模拟音频
   保存BCLK/LRCLK/DIN原始逻辑采集及仪器设置，核48kHz、槽位、相位、左右、符号、
   缺样/恢复；保存PT8211左右模拟原件、负载、采样率、削波/直流观察。
   数字PASS不代替模拟发声，具体采集点/接地方法先核定，不盲接探头。
3. 端到端延迟
   原MIDI输入边沿与模拟起音使用同一时间基准双通道采集，明示起音阈值和测点。
   单音/和弦、轻重力度、复位恢复分别记录实际延迟与最大值；未实测不填≤10ms通过。
4. T052纯正弦与实数N
   仅对已接同版码流的N路独立、充分分开的纯正弦模式采原始音频、FFT配置与谱峰图，
   配合active_voice_count/clip_count及RTL实时合成证据。谐波不冒充独立声部。
   实报N、实际采样率和乘积；测试模式未接入则保持待验，不在M3目录改声音算法。
5. 封存
   每组保存输入/输出SHA、仪器/板型号、时间、命令/工具退出、原始波形/音频/视频，
   逐项PASS/FAIL/待核、达到的L等级、首个失败原件。工具限额/采集时长待精确方案，
   本文不追加执行许可。失败停止并报M2，不换码流或反复烧写。

不包含N32、C3/APK重建、T060 A/B重采、BLE实物扩展、自动播放或任何Flash写入。
