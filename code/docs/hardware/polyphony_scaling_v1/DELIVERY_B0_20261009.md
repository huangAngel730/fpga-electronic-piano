## 条件数值与不能推导的结论

21拍/voice 是未实现适配器的设计合同，不是实际 II/latency。
条件总拍数 `29+22N`：N4=117、N8=205、N16=381、N32=733。
32档条件余量100拍，但 dispatch／CC64扫描／backpressure 上界未知，**整体 UNKNOWN**。
连续 ADSR pipeline 与事件准备/跨槽虚拟 core-cycle 等价尚未建立；不能靠假设6拍等待宣称等价。
实际共享 engine II/latency、资源映射、ROM端口实现、N4音频等价及8/16/32声音均未验证。
70632bit 是五张 active piano ROM 单份逻辑 payload，不是 BSRAM 占用。
Logical storage分配也不是 FF计数；DSP等资源保持null。旧 L 工具容量与旧整机用量仅作来源参考。
