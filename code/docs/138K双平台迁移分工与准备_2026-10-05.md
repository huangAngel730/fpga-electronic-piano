1. 明确138K完整型号、B/C芯片和底板版本；C版报告不能外推到B版。
2. 核对核心板/底板兼容与供电、下载器识别、官方CST/原理图；保留原60K实物及回退文件。
3. 完整核对MIDI/UART/PT8211/HDMI/按键/复位的球位、Bank、电压、上拉和物理针号。
4. 使用已导入工具，所有source/include/ROM/PLL/SDC/CST冻结SHA，分别保留50/40配置，禁止只放宽SDC冒称降频。

7. 板级验证绑定.fs SHA、板版本、下载方式和测试操作；首轮SRAM、保留60K回退，不把旧L6搬到新板。
