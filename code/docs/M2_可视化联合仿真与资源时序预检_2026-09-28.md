## 具体风险与后续分工

1. 画面默认尺寸 640×480、49键、8+8槽下，`visual_scene_renderer.sv` 使用逐像素动态 `(px*NOTE_COUNT)/SCREEN_WIDTH`、`(lane*SCREEN_WIDTH)/NOTE_COUNT`、`note % 12` 与16槽循环；`visual_score_tracker.sv` 的 `remaining_frames*TRAVEL_Y/PREVIEW_FRAMES` 在每槽组合输出。按报告看最严重的是渲染器到 DVI/输出寄存器的长路径，但不能仅从静态语句推定每项 LUT/DSP 成本。**M3 在其目录按授权优化**：坐标范围用常量边界比较或小 ROM/预计算，局部流水线须连 RGB+DE+HS/VS+像素时间轴一起对齐；如改架构，更新 TB 的连续帧/消隐/边界像素断言。M2 不私自改渲染器。
2. 桥输入 Hold −0.656/−0.788ns 位于两级同步器的异步跨域路径，不能把未收敛路径简单标 false_path 便宣称 CDC 安全。M2 需另做 CDC 物理约束、toggle 同步器及64位 bundled-data 稳定期限核查，必要时换经 Gowin 验证的异步 FIFO；结果须在正式集成前通过独立 PnR 专项门禁。视频 PLL 失锁必须双域共同复位，不能只拉视频域。
3. M1 `visual_score_reference.py` 里 duration=None 在 hit 后默认停留 0.5s；当前 M3 `visual_score_tracker.sv` 无 duration 时 judged 且越过 HIT_WINDOW_FRAMES（默认6）就释放；59.5238Hz 时0.5s约30帧，不等于6帧。高亮只用 note_number 位图，同音不同 `(source_id,channel)` 的 Note Off 会清掉仍按住的音符。**由 M1/M3 确定时间边界和身份规则，M3 负责其画面模块修复**，M2 接入测试；修复前不能声称语义一致。
4. mode_toggle 若来自其他时钟域，须 toggle/握手；`score_valid` 连同 note id/音高/帧号/时长/力度为多位数据，须握手或异步 FIFO。此轮 score/mode 激励刻意在视频域直接提供，不构成 CDC 验证。正式集成仍需 S5 完成及接口组受控流程；不得把独立资源探针/联合行为 TB 当作正式音画共存。

## CDC 约束待办（M2，不以例外伪造收敛）
