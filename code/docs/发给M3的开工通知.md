## 五 首次上电检查

上电前按顺序执行：

1. 目视检查反接、短路、虚焊和金属异物；
2. 确认SOM与NEO Dock方向正确且完全插入；
3. 断电测量3.3 V、5 V和输入电源对地是否明显短路；
4. 确认电源规格、极性和接口；
5. 首次使用可调电源时设置合理限流；
6. 暂不连接未知外设、功放和无源扬声器；
7. 上电后先测关键电源轨，再允许M2连接JTAG；
8. 发现异常发热、异味或电流突升时立即断电。

不允许把5 V输出直接连接到3.3 V FPGA GPIO。DAC线路输出不直接驱动无源扬声器。

### 2026-09-20 第二硬节点

配合M2测量440 Hz固定音链路：

- BCLK应约3.072 MHz；
- LRCLK应约48 kHz；
- 检查 **LSBJ 右对齐相位**：每声道 16 位有效数据右对齐，**LSB 紧贴 LRCLK 跳变沿**（v1.1，D017；注意这**不是**标准 I2S 的一拍延迟，两者在 64 BCLK/帧下相差 15 个 BCLK）；
- 板载 DAC 为 **PT8211**（16 位，LSBJ），非 PCM5102A；
- 采集音频并测量基频；
- **实测 PA_EN 上电期间电平**，确认功放关闭无爆音；
- 记录实际验证等级，不把仿真写成上板通过。
