正常capture重算通过：5849次PCM握手、5849次帧采用和计数核对，5848个完整立体声串行帧、11696次声道比较、0欠载；四声部区间299帧，最后松键后的Release/归零尾段4967帧，24个UART字节和4次独立松键状态完整。

5849次握手与5848个完整串行帧不是丢帧。物理capture共有11698个完整半槽：开头同步后先出现1个未配对的WS高左半槽，中间形成5848组右低+左高完整立体声帧，结尾在第5849次采用后记录1个尚未等到下一左半槽的WS低右半槽；即`1 + 2*5848 + 1 = 11698`。检查器只登记左右均完整的帧，因此不把末尾半帧虚报为第5849个立体声帧。

诊断capture重算通过：40个完整立体声帧、80次声道比较、38次握手、41次采用；第14、15、16采用帧连续欠载并保持前一组左右样本，欠载计数恰增3，第17帧采用新数据恢复。15个正负、半LSB和饱和边界值全部出现，且左右声道存在不同值。

物理映射由两个独立层次共同约束：封存发送器定义WS低为右、WS高为左，32位半槽低16位有效；observer只在真实BCLK上升沿采DIN，按实际WS翻转封闭半槽。Python检查器保存WS低右样本，在下一WS高左样本到达后按`(left, right)`比较，因此没有通过读取DUT内部移位寄存器或交换左右声道获得结果。

PCM24→PCM16黄金公式为`clamp((signed_pcm24 + 128) // 256, -32768, 32767)`。Python向下整除与RTL有符号算术右移一致，等价于加半LSB后舍入，半LSB向正无穷取整；再对+32768上溢饱和到+32767，对范围下界保持-32768。诊断边界覆盖`127/128/129`、`-127/-128/-129`、正满量程附近和负满量程附近。

两个错误capture用同一入口均真实非零退出：

- `wrong_bit_capture.b64`：退出1，`LSBJ_PADDING_OR_TIMING`，拒收有效位提前一位。
- `wrong_buffer_capture.b64`：退出1，`BUFFER_ADOPTION frame=2 got=(0, 0) expected=(0, -128)`，拒收强制采用held旧帧。
