## 必须复用和注意事项

复用 code/rtl/audio/dds_oscillator.sv 的32位相位、1024点同步ROM。当前ROM参数默认32767幅度仅是历史独立DDS默认值；测试源必须显式指定包内 sine_1024_8192.mem，不能悄改默认值/旧ROM。单路波表标称±8192，PCM24使用有符号扩展后左移8；累加至少32位，24位饱和。局部安全测试衰减可以在新模块明确采用所有路相同的算术右移并同步黄金模型，不改正式幅度口径。复用 pcm_mixer_4voice；每个振荡器有独立相位/FCW，禁止软件PCM播放、整段预录ROM或谐波冒充声部。

旧 generate_test_mode_reference.py 及其既有WAV/HEX/频谱仅是软件参考，曾有缺少断言/检查模式与可复现性问题，不能当作本次实现或PASS证据。旧200/400/600/800Hz亦不强制沿用。建议先评估263/431/659/997Hz四个充分分离、非简单倍频的频点；这是任务建议，不是公共参数定案。M1给出实际频点、FCW、量化误差和选择依据。

## 局部事务接口与M2接入边界

新模块建议接口（仅隔离合同，不修改正式公共接口）：
输入 clk(50MHz)、rst_n(低有效异步拉低，调用者同步释放)、frame_tick、sample_req、sample_req_id[31:0]、enable、voice_enable_mask[3:0]。
输出 calc_ready、result_valid/result_ready握手、result_req_id[31:0]、voices_left/right[95:0]（每24位一声部）、active_voice_count[31:0]。
采用握手 sample_req && calc_ready 接受一次样本请求，锁存请求ID与enable/mask，独立DDS仅推进一次；计算完成后结果在背压下保持稳定。frame_tick优先取消旧代结果、禁止该边界接受新请求或消耗旧结果。已接受样本的相位推进不回滚，复位清相位/有效结果/计数。关闭或mask清位输出对应路0，活跃数为已锁存mask的置位数，不把瞬时零交叉计成不活跃。
这里 sample_req 是PCM帧链提出的逻辑采样请求，不能另生成第二套48kHz时钟；需要改变接口先提案。本轮M1仅例化测试源并在TB接已有polyphonic_pcm_commit；正式测试/演奏模式选择、安全切换静音、FPGA顶层、I2S、UART七字段及码流均由M2接入，M1不要自行改。

## 自检必须真实执行

1. 纯标准库黄金模型定义32位回绕、ROM读地址/采样对齐、PCM24定标、宽和与饱和，输出可重复向量；FFT可选numpy，缺依赖要明确报告，不能伪PASS。
2. 真实仿真逐样本比较各路波形、相位/FCW、混音PCM，至少4096个成功结果；模型生成WAV与FFT只是软件参考，不计硬件现场谱峰通过。
3. 覆盖mask全部16种、满四路同时非零、停顿/背压保持、请求ID与回绕、frame取消、复位后首帧、关闭再启用、满幅压力正负饱和和削波。
4. 使用现有polyphonic_pcm_commit在TB检查正常48kHz帧间隔（1041/1042个50MHz周期）、代次提交和零额外欠载；clip_count按成功提交计一次，背压不得重复累计。故障压力场景与正常测试分开统计。
5. 防假绿：至少两个可编译错误版本（共享/丢失一条DDS、相位或有效拍错位）必须被同一检查器拒绝；缺ROM、截断向量、空capture、超时非零退出。TB失败用$fatal(1)，runner检查成功标记与检查数量，不能只信ModelSim quit退出码。
6. 写清合成函数是否有除法、阵列资源预计成本；本轮M1只报实际执行等级。没有仿真器就交源码/模型并如实标未执行，M2运行真实仿真。无Gowin/PnR/板测不写通过，不重写已验DDS。
