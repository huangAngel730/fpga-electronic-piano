# T005 PT8211 声道与 LSBJ 末位对齐变更提案（2026-09-28）

**状态：待群内事前说明；本文件只是一份提案，不是接口版本发布，也不是 T005 修复完成记录。**

## 问题与证据

- PTC 官方 `PT8211 V1.7_E` 第 4 页 Figure 1/2 和 Function Description：WS 低把 DIN 送右声道 RCH，WS 高送左声道 LCH；DIN 在 BCK 上升沿采样，数据为二补码、MSB 先发、Japanese/LSBJ。第 3 页 PT8211-S 数字输入只有 BCK、WS、DIN，不要求 MCLK。本仓库已入库原 PDF `code/docs/PT8211_V1.7_E_数据手册.pdf`，SHA256 `3ceb112d58b95ce2af9478c531c9c54fe578e3b634ff18e11960ef8e5370d035`。
- 现行受控 `code/docs/模块接口规范.md` v1.3 第五节与 `code/rtl/audio_out/i2s_tx.sv` 都写 WS 低=左、高=右；原 T005 TB 也用同一逻辑极性自检，造成假绿。V0113 独立引脚级反例输入左 +8448（DAC16 `0x0021`）、右 −12544（`0xFFCF`），正式 RTL WS=0 解码 `0x0042`、WS=1 解码 `0xFF9E`，六次均错且退出 1。
- 仅在 Git 忽略目录 `code/output/t005_pt8211_fix_trial/i2s_tx.sv` 用同源 RTL 做隔离试验：①将 WS 低半帧装载右 PCM，WS 高半帧装载左 PCM；②将 `LOAD_SLOT` 从 `DAC_WIDTH-1` 改为 `DAC_WIDTH`。两项同时应用，V0113 同一物理声道 TB 6/6 PASS、退出 0；单改任一项仍失败。候选 SHA256 `f7d2ba59c2b7b43abc8c439e6215b278a7e1d75c4479f24cde362d7159cccc66`。隔离副本未改正式 RTL、工程、约束或板卡。
