## 身份及功能证据

原始 ZIP 解码后 3,251,543 字节，SHA256 `821ca69257bbc00f77680317729c714775f27cde3d95dafb9c7ad8e3adfc783a`，171 成员；CRC 修版 ZIP 7,359,474 字节，SHA256 `f09b647193801135aad32e6d468caca11306e215b4601bd0e7c7a9bf600e0e91`，275 成员。ZIP CRC 和各收到成员的原始 SHA 独立核对一致；02／03／04 的 `.db`／`.p` 在作者 manifest 明确列为不交付中间物，只核其声明，不称收到或验证其内容。原始载体保留，不回填日志。

M2 用冻结 T057 的公开协议 oracle 独立重放两份完整 capture，各 exit 0：731 场景、710 回复包、574 串行事件比较、1,240 公开事件比较、32 负事务、7 COMMIT ACK。两版完整 expected JSON、公开 oracle 字节及线上 RX/TX 内容相同；回复时间戳分别保留，未把新增内部等待误写成逐拍等价。原超时实测 199,999,649 拍，协议的 200,000,000 拍定义保持。M2 另造回复 CRC 错误、公开事件损坏和缺 END 三份完整 capture，均按指定诊断非零拒收。

运行时功能输入 SHA 与封存源一致。CRC 修版原真实 ModelSim 正例 compile 0／simulate 0，模拟 164.265 秒；`RAM_CHECKS` 公共读 89,083,006、并发读 89,081,766、同沿 COMMIT 旧银行读 4、invalid 44,088,176、COPY 96、VERIFY 4,576、UART 515，另实际检查 710 个回复 CRC。复位 TB 实际六处定向入口、18 次复位检查，覆盖 COPY、VERIFY_USE、READ_WAIT、发布前 VERIFY 末尾、CRC_FETCH、CRC_STEP；**没有把 CRC_FINISH 写成已命中的复位入口**。

RAM 读错、银行切错、回复 CRC 错三份 RTL 变异均原真实编译成功，被 `RAM_PUBLIC_DATA_OR_BANK` 或 `UART_REPLY_CRC_MISMATCH` Fatal 拒收，且没有 HARNESS COMPLETE。原 ModelSim 进程退出码为 0，runner 按 Fatal 与成功标志判定失败；不能把它冒称 simulator 非零退出。M2 新 capture 损坏例的 checker 非零退出为独立的软件检查证据。

## 物理结果与接入条件

01 号原真实 PnR 在 1.016 秒失败，原生 DPB read-before-write 模式不支持；02 号在 900.781 秒超时；03 号只具综合完成收据及后续进程不在场观察，没有终态退出码／原因；04 号综合 0／15.172 秒，PnR 1／1,800.594 秒、timed_out=true。04 只到 Routing 1，无最终 STA／fs。CPU 增长只能说明观察窗口内消耗 CPU，不能证明路由收敛或死锁。

05 号后台尝试终态证据尚未收到；本机对应 C／E 路径不存在，不能由此推断另一主机进程已停、仍在运行或失败。M2 本轮不启动、停止、延长或重试其进程，不从其它窗口的 authority 文本获取执行许可。

独立模块 SDC 只有 25 ns 时钟和虚拟 IO min/max=0；没有完整板级 CST、整机时钟/不确定度、外部设备 IO 口径。即使未来模块物理 STA 通过，也不能代替精确新整机的 40／25／125 MHz、Setup 不确定度 1 ns、Hold 不确定度 650 ps、Setup ≥+0.5 ns、Hold/Recovery/Removal/pulse 非负、违例及 TNS=0、CDC/reset/引脚/资源门禁。

M2 已准备单独 RAM 整机目录，62 输入／53 工程项；只替换既有接收实例模块绑定和源文件列表，保留旧 L-v3／60K／正式工程及全部 ROM／PLL／CST／SDC。**新精确工程尚未运行上传期间音频／波形等价、整机综合、PnR、STA**；公开读没有播放器消费者。下一阶段先补精确新 top 的相关功能／复位／CDC 回归，再以实际授权运行受控全工程构建，不能套旧 L5 或自动下载。
