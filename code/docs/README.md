# 项目文档索引

日常开工先看 `协作入口.md`，本文件用于按主题查找文档，不要求一次读完全部内容。

## 项目事实与架构

- `项目事实与范围.md`：已经冻结、阶段目标和尚未冻结的事项。
- `赛题要求对照表.md`：赛题原文逐条映射到任务编号，标出覆盖状态和差距清单。
- `官方讲解落实清单.md`：讲解截图中的指标、展示建议和当前项目任务映射。
- `模块接口规范.md`：演奏事件、PCM、时钟复位和状态接口。
- `交互与演奏维度方案.md`：电子钢琴主模式、X4 III 多维表情路线和实测验收边界。
- `MIDIPLUS_X4_III_硬件事实.md`：已购键盘的官方规格、卖家描述边界、FPGA 接入方式和到货必测清单。
- `技术决策记录.md`：带编号的架构与流程决策。
- `资源预算与复音规划.md`：器件资源预算和复音规模规划。
- `138K_40MHz系统降频影响与扩展注意事项.md`：50→40MHz的吞吐/采样预算、参数适配、共享PLL与增量功能注意事项。
- `抉择与并行开发顺序.md`：三条工作线和同步点。
- `板级硬件事实.md`：Tang Mega 60K 官方规格、外设、供电、电气安全和上板踩坑。
