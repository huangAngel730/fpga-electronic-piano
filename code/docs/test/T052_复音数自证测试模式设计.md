## 一、任务目标

根据赛题「核心评分规则与现场验证标准」第3条要求，实现测试模式用于现场验证复音数：

1. **输出N路已知且间隔充分的不同频率纯正弦波**
2. **接电脑声卡或示波器FFT后可数出N个独立谱峰**
3. **用RTL源码佐证纯硬件实时合成通路**（配合`active_voice_count`和`clip_count`）
4. **验证无预录音频播放行为**

其中N等于T016冻结的复音档位数。

---

## 二、核心约束

### 2.1 必须使用纯正弦波

**原因**：题目统计规则「单波表采样查表不计多谐波数量，仅计单个振荡器」

- ✅ **正确**：N个振荡器 → N个纯正弦 → FFT显示N个谱峰（1:1对应）
- ❌ **错误**：使用锯齿波/方波 → 每个振荡器产生多个谐波 → 谱峰数 > 振荡器数（虚报）
- ❌ **错误**：谐波重合 → 200Hz的2次谐波 = 400Hz → 谱峰数 < 振荡器数（自证失败）

### 2.2 频率间隔要求

为确保FFT谱峰清晰可辨，相邻频率至少间隔：
- **最小间隔**: 50 Hz（避免谱峰重叠）
- **推荐间隔**: 100-200 Hz（留出充分的分辨余量）

## 三、频率选择方案

### 方案A：等间隔频率（推荐）

**4复音示例**：
- 声部0: 200 Hz (MIDI约G3-7音分)
- 声部1: 400 Hz (MIDI约G4+4音分)
- 声部2: 600 Hz (MIDI约D5-14音分)  
- 声部3: 800 Hz (MIDI约G5+4音分)

**优点**：
- 频率简单易记，便于现场演示说明
- 间隔200Hz，FFT谱峰清晰分离
- 在人耳听觉范围内（不会太高或太低）

**Python验证代码**：
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

# 生成4路正弦波混音
fs = 48000
duration = 1.0  # 1秒
t = np.linspace(0, duration, int(fs * duration), endpoint=False)

freqs = [200, 400, 600, 800]
mixed = sum(np.sin(2 * np.pi * f * t) for f in freqs) / 4

# FFT分析
fft_result = np.fft.rfft(mixed)
fft_freq = np.fft.rfftfreq(len(mixed), 1/fs)
fft_mag = np.abs(fft_result)

# 绘制频谱图（0-1000Hz范围）
plt.figure(figsize=(12, 6))
mask = fft_freq <= 1000
plt.plot(fft_freq[mask], 20 * np.log10(fft_mag[mask] + 1e-10))
plt.xlabel('Frequency (Hz)')
plt.ylabel('Magnitude (dB)')
plt.title('4-Voice Test Mode Spectrum')
plt.grid(True)
for f in freqs:
    plt.axvline(f, color='r', linestyle='--', alpha=0.5)
plt.savefig('test_mode_spectrum_4voice.png')
print(f"应看到4个清晰的峰值，分别在: {freqs}")
```

## 四、测试模式触发方式

### 方案1：板载开关触发（推荐）

利用Tang Mega 60K板载开关（如果有拨码开关）：
- 某个拨码开关位置 = 测试模式使能
- 进入测试模式后：
  - 忽略所有按键/MIDI输入
  - 强制激活N个声部
  - 每个声部固定频率和满幅度
  - `active_voice_count` = N（常数）

### 方案2：特殊按键组合

同时按下特定按键组合（如key[0]+key[1]同时按住2秒）触发测试模式。

### 方案3：UART命令

通过UART发送特殊命令字符串进入/退出测试模式。

**当前建议**：方案1（如果有硬件开关）或方案3（通过UART，可与T025状态通道集成）

## 五、RTL实现接口

### 5.1 顶层新增信号

```systemverilog
// 测试模式控制
input  logic        test_mode_enable,  // 1=测试模式，0=正常演奏模式

// 测试模式下的固定FCW（由M1提供参数）
parameter logic [31:0] TEST_FCW_0 = 32'h????_????,  // 200 Hz
parameter logic [31:0] TEST_FCW_1 = 32'h????_????,  // 400 Hz
parameter logic [31:0] TEST_FCW_2 = 32'h????_????,  // 600 Hz
parameter logic [31:0] TEST_FCW_3 = 32'h????_????   // 800 Hz
```

### 5.2 行为说明

当 `test_mode_enable = 1` 时：
1. **声部强制激活**：N个声部全部进入Note On状态
2. **频率固定**：每个声部使用预设的FCW，不响应事件变化
3. **幅度固定**：包络固定为满幅（或ADSR的sustain level）
4. **输入屏蔽**：忽略按键、MIDI等所有外部事件输入
5. **状态稳定**：`active_voice_count = N`（常数），`clip_count`正常累计

当 `test_mode_enable = 0` 时：
- 恢复正常演奏模式

## 七、验收标准

### 7.1 频谱测试

**工具**：电脑声卡 + Audacity / SpectrumLab / MATLAB

**步骤**：
1. 板上使能测试模式
2. 3.5mm耳机口接电脑Line-in或USB声卡
3. 录制5-10秒音频
4. 做FFT分析（窗函数：Hanning，FFT大小：8192或更大）

**通过条件**：
- FFT图上可清晰识别出N个谱峰
- 每个峰的频率位置与预设频率误差 < 1 Hz
- 峰的数量 = 复音数N（不多不少）

### 7.2 RTL源码证据

**需要展示**：
1. 声部模块的例化数量 = N
2. 每个声部都在运行（`active_voice_count`读数为N）
3. 无预录音频：波表ROM可见、DDS相位累加逻辑可见
4. 混音器将N路输出求和

### 7.3 状态观测

通过UART状态通道（T025）或逻辑分析仪观测：
- `active_voice_count` = N（稳定不变）
- `clip_count` = 0（满幅正弦不应削波）
- `event_fifo_overflow` = 0
- `audio_underrun` = 0

## 九、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 板上无可用开关 | 触发方式受限 | 改用UART命令或按键组合 |
| 混音后削波 | 波形失真、谐波增加 | 每路幅度降为1/N，或实现限幅器 |
| FFT分辨率不足 | 峰值模糊 | 增加录音时长，使用更大FFT size |
| 声卡采样率不是48kHz | 频率读数偏移 | 软件中校正，或改用示波器FFT |
