## 一、算法定义（定点 bit-exact）

### 1.1 干湿混合

```
output_raw = ((input_pcm * dry_gain) >> 15) + ((delayed_pcm * wet_gain) >> 15)
output_pcm = saturate(output_raw, [-8388608, 8388607])
```

### 1.2 反馈缓存

```
fb_raw = input_pcm + ((delayed_pcm * feedback) >> 15)
buffer[wr_ptr] = saturate(fb_raw, [-8388608, 8388607])
wr_ptr = (wr_ptr + 1) % DEPTH
```

### 1.3 读指针

```
rd_ptr = (wr_ptr - delay_samples) % DEPTH
delayed_pcm = buffer[rd_ptr]
```

| 类型 | 格式 | 范围 | 说明 |
|---|---|---|---|

| Gain | Q0.15 unsigned | [0, 32767] | [0.0, 0.999969] |
| Feedback | Q0.15 unsigned | [0, 32767] | < 1.0（防发散）|

## 三、语义保证

### 3.1 舍入策略
**截断右移**（`>> 15`），不加舍入位。硬件右移自然行为。

### 3.2 饱和
**Signed 24-bit**，超限截断：
```
// M2 修正：25-bit 常量匹配 25-bit 变量（output_raw/fb_raw）
if (value > 25'sd8388607)  return 24'sd8388607;
if (value < -25'sd8388608) return -24'sd8388608;
```
原版错误使用 24-bit 常量导致 Icarus 比较失败。

### 3.3 旁路
- `dry_gain=32767, wet_gain=0`：近似旁路，误差 ≤ input/32768
- Q0.15 截断误差：对 PCM_MAX=8388607，误差 256 LSB (0.003%)
- **硬件可用专用旁路路径**（不经过乘法器）实现 0 LSB

### 3.4 复位
- **清空缓存**：`buffer[i] = 0` for all i
- **复位指针**：`wr_ptr = 0`
- **清空输出**：`pcm_out = 0`

### 3.5 参数切换
- **立即生效**，不要求平滑过渡（M2 负责）
- 支持运行时修改 `delay_samples, dry_gain, wet_gain, feedback`

### 3.6 延迟时间为 0
- `delay_samples=0`：rd_ptr = wr_ptr，但先读后写
- **实际效果**：读取到整个 DEPTH 圈前的历史数据（初始为 0）
- **不是真正的零延迟/旁路**：仍有 DEPTH 样本的隐含延迟
- 若需真正零延迟（0 样本延迟），需另行定义专用旁路路径

## 四、RTL 实现

### 4.1 结构
- **循环缓冲**：DEPTH 必须是 2 的幂（简化取模：`& (DEPTH-1)`）
- **3 级流水**：
  1. 读延迟样本 + 锁存参数
  2. 乘法（24×15 → 39-bit）
  3. 右移、加法、饱和 + 写缓存

### 4.2 时序
- `sample_enable`：1 脉冲 per 音频样本（48 kHz）
- `pcm_valid`：sample_enable 后 2 周期有效（流水延迟）
- **M2 负责**：多声部对齐、sample_enable 生成

### 4.3 缓存深度
- **小深度验证**：100/1024 样本（算法正确性）
- **最大规模**：交 M2 核预算（BSRAM 使用量）
- 500ms@48kHz = 24000 样本 × 24bit = 72KB
