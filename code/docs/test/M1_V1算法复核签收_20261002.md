# M1 对 V1 音色算法的复核签收（2026-10-02）

复核对象：`M1_V1音色算法复核包_97d5d64_20261001`（候选 3515c31 / 合并 97d5d64）。
复核人：M1。方法：**不复用包内 sqrt 力度模型**，直接对 RTL + 正式 `piano_band_4x256_8191.mem` 做位精确复现与独立数值核算。
manifest 内 10 个文件 SHA-256 **全部与 manifest 一致**。

## 一、总体结论

**签收：V1 谐波表/定标/相位对齐算法可保留，同意 M2 按原算法正式接入。**
算法层面无阻断项；发现 **1 项有界瞬态风险（NoteOn 即时换表）**，列为条件项，见第四节。

## 二、逐项复核结果（全部 PASS）

| 复核项 | 方法 | 结果 |
|---|---|---|
| 谐波表与 .mem 一致 | 用 `generate_wavetable.py` 重生成 1024 字，逐样本比对 | **完全一致**，峰值均为 ±8191/8192，谱系数与 `TABLES` 定义逐项吻合 |
| 音高不变 | 逐键 fcw 复算 | 32 位 FCW 与 48 kHz 语义未动，相位与频段选择**不改变基频** |
| 峰值定标 | 四表 peak/RMS | 四表 peak 均 8191，落在接口规范 4.3 节"标称 ±8192"口径内 |
| 力度亮度门槛 | 正式 `velocity_gain_rom.mem` + RTL 阈值 | ROM 1024 项**单调不减**；256/512/768 阈值对应 ROM 的 25%/40%/65%，分档合理 |
| 10/20/30 ms 起音窗 | 按 velocity 分支复算样本数 | 480/960/1440 采样 @48 kHz = 10/20/30 ms **精确** |
| 回绕切表相位对齐 | 全键盘 21..108 位精确仿真 | **88/88 键：切表步进 ≤ 沿用旧表的自然步进，额外跳变 0 LSB**，相位对齐有效 |
| 重触发不缩短新起音 | RTL `!note_on && sample_tick` 保护 | 同拍 note_on+sample_tick 时新起音不被扣减，逻辑正确 |

### 回绕切表机理（已实测确认）
四张表在**相位回绕点（下标 0）样值恒为精确 0**。RTL 在 `phase_wrap` 生效这一拍从"旧表高下标(~255)"切到"新表下标 0"，等价于沿旧表自然续走一次周期回绕，因此**不产生额外步进**。这是把 attack→body 切换推迟到回绕的**正确理由**。

## 三、需要记录的设计特性（非缺陷，不要求改）

1. **低音区亮度窗不足一个基频周期**：起音窗按采样数固定，不随音高缩放。
   - A0(27.5 Hz) 30 ms 窗 = 0.82 个周期；20 ms = 0.55；10 ms = 0.27。
   - C8(4186 Hz) 30 ms 窗 = 125 个周期。
   即"10/20/30 ms 明亮起音"在 A0–A#2 区实际不足一整周期，听感更接近**一次高次谐波瞬态**而非持续音色段；高音区则是长音色段。属设计取向，M3 A/B 时按此预期评估。
2. **起音到音体切换的额外延迟**：计数器到期后需等下一次回绕才切表，低音区最多再等约 1 个周期（A0 ≤36 ms），高音区 <0.3 ms。已含在实测切表点里（如 MIDI28 实际 48.5 ms）。
3. **表间 RMS 台阶**：等峰值定标下，谐波越少 RMS 越高，attack→body 切换瞬间有 +0.41/+0.67/+1.06 dB 响度台阶（低/中/高音区）。量级很小，且发生在短窗内，判定可接受。

## 四、条件项：NoteOn 即时换表的抢占/重触发瞬态（唯一真实风险）

**机理**：`note_on` 时 `active_table <= attack_table` **立即生效**，但 `phase_acc` 不复位。若该声部此前正在发别的声音（**声部抢占**）或重触发，会在**任意相位**发生换表，产生单样本波形跳变。

**实测跳变幅度**（同相位下标相减）：

| 场景 | 最大跳变 | 均值 |
|---|---|---|
| rich8→med5（低音区内） | 20.5% FS | 586 LSB |
| med5→lite3 | 24.1% FS | 958 LSB |
| med5→sine1（低音抢占到 >6 kHz） | **51.9% FS** | 2702 LSB |
| rich8→lite3（跨区抢占） | 40.2% FS | 1475 LSB |
| rich8→sine1（最坏跨区） | **63.3% FS** | 3024 LSB |

- **基线（单一正弦 ROM）本身无此跳变**（相位连续 + 同表 ⇒ 抢占零步进）。故这是 V1 引入的新瞬态源。
- **A1/V1 实测同版对照**里 root 是正弦，若 V1 走谐波表链，此瞬态会出现在**跨音区抢占**的样点上。
- 是**单样本、宽带**事件 ⇒ 听感为轻"咔哒"。**是否可闻取决于**：(a) 抢占是否高频发生；(b) 该声部包络是否非零——本 ADSR 在 note_on 时 `start_q16 <= level_q16`（**不平滑到 0**），故包络不重新起振，**不会掩盖点击**；(c) 与抢占/起音自身瞬态的心理声学掩蔽（起音本身即瞬态，可能部分掩盖）。

**判定**：潜在大（最坏 63% FS）但触发条件窄（须抢占且跨音区且相位非零）。
**建议**：先按原算法接入，把此场景列入 M3 A/B 必测项；**若 A/B 听到可闻点击，再上下面的最小修正**。

### 最小修正（仅在本项被 A/B 判定可闻时启用；不改顶层/接口/包络）

**把 note_on 的换表也走已有的 `table_change_pending` + 回绕机制**，即在 `if (note_on)` 分支把
```systemverilog
active_table <= attack_table;      // 立即
```
改为
```systemverilog
pending_table <= attack_table;     // 等下一次相位回绕，下标 0 处切表
table_change_pending <= 1'b1;
```
并在 pending 于回绕点生效时再装载 `attack_samples_left`（保证明亮窗整长）。

- **优点**：四张表在回绕点均为 0 ⇒ 所有换表（含抢占）都变成零步进，彻底消除该项瞬态；复用现有寄存器，不改端口。
- **代价**：明亮起音最多延迟 1 个基频周期（A0 ≤36 ms，C8 ≈0.24 ms）。**对刚分配的空白声部（包络为 0）其实无点击，却也被延迟**——故仅在 A/B 确认可闻时才值得付出这个延迟。
- **不建议**在 note_on 复位 `phase_acc`：那会让新样本落到 0，而旧样本非零，步进反而更大（可达 100% FS），且破坏相位连续性。

**替代（M2 侧，若能接受）**：声部重用前做几毫秒快速释放/静音再发新 note_on，即可在不动振荡器的前提下掩蔽该瞬态。但**这属于包络行为，M1 定案**，需与我确认。

## 五、不能签收/不在此次范围

- **不签收模型层的量化结论**（"邻近音支配度降 26.3%""重/轻 RMS 比 2.332"等）：`validate_prototype.py` 的 `q15_velocity` 用 **sqrt 近似**，与正式 ROM 偏差很大（vel=200 时 14488 vs 正式 7555，差 21%）。这些数值**不能**当作正式 DDS×ADSR 链逐样本金标准。M2 已自行标注此限制，我认可其标注。
- **不含实物听感**：真实"拍频"仍存在（两基频俱在，物理上必然），V1 目标是降低单一基频对的听感支配度，**不承诺拍频为 0**。
- **时序/资源**：留给 M2 重跑 Gowin 全量 syn/PnR/STA，不沿用旧报告。
- **琴槌噪声/真实采样/更复杂动态滤波**：不在本算法内，属新增范围，需另批。
