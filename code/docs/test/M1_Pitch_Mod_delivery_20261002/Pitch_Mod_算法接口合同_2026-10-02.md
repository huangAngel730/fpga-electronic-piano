# Pitch / Mod 算法接口合同（M1 定案，2026-10-02）

对应 `code/rtl/audio/pitch_mod_fcw.sv` 与 `code/model/pitch_mod_model.py`。
本文件是 M2 接线所需的**输入/输出、时序与 latency 合同**；M2 按此接口接线，
不要求本模块为 `performance_control_state` 改写数学。

---

## 1. 输入 / 输出

| 端口 | 方向 | 位宽 | 语义 |
|---|---|---|---|
| `sys_clk` | in | 1 | 系统 50 MHz |
| `sys_rst_n` | in | 1 | 异步断言、低有效；由调用者同步释放 |
| `sample_enable` | in | 1 | **每个音频采样一个脉冲（48 kHz）**，见第 3 节 |
| `note_on` | in | 1 | 一个脉冲；重启颤音 LFO，见第 5 节 |
| `bend` | in | signed 12 | 冻结口径，中心 0，−2048..2047（`CTRL_PITCH_BEND=0`） |
| `modulation` | in | unsigned 12 | 0..4095（`CTRL_MODULATION=1`） |
| `pitch_range` | in | 5 | 半音 0..24，默认 2（`CTRL_PITCH_RANGE=4`） |
| `base_fcw` | in | 32 | 音符查表得到的基准 FCW（**不含**任何 Pitch/Mod） |
| `fcw_out` | out | 32 | 送给 DDS 的最终 FCW；**相位累加器不变，故音高变化天然相位连续** |
| `fcw_valid` | out | 1 | 与 `fcw_out` 同拍，`sample_enable` 延迟 1 个 `sys_clk` |

`base_fcw` 由既有 `note_pitch` 表给出，本模块不重复音高查表，也不碰 MIDI 解析。
`bend / modulation / pitch_range` 由 M2 的 `performance_control_state` 快照按槽提供
（`slot_pitch_bend / slot_modulation / slot_pitch_range`）；身份 source/channel 的
绑定由 M2 负责，本模块只吃四个槽的标量。

---

## 2. 定点公式与舍入（逐条可复现）

分辨率 **Q10 半音**：1 LSB = 1/1024 半音 ≈ 0.098 音分。

```
semi_q10  = (bend * range) >>> 1                     # floor，保留符号
depth_q10 = (mod * 512 + 2048) >>> 12                # 四舍五入（mod=4095 时精确取满）
vib_q10   = (lfo_sine_q15 * depth_q10) >>> 15        # floor
total_q10 = semi_q10 + vib_q10                       # 范围 ±25088，不会溢出
q = total_q10 >>> 10 ; r = total_q10[9:0]
factor_q16 = (OCT[q+25] * SUB[r]) >> 16              # 截断
fcw = saturate( (base_fcw * factor_q16 + 32768) >> 16 , 0, FCW_MAX )
```

- `OCT`：50 项 `2**(q/12)`，q∈[−25,24]，Q16，20 位。
- `SUB`：1024 项 `2**((r/1024)/12)`，Q16，20 位。
- `LFO`：1024 点正弦，±32767（Q15），16 位有符号。
- 两级 LUT 把 `2**(total/12288)` 拆成整数半音 + 分数半音，避免单一 12288 项大表。
- **单次舍入**：OCT/SUB 生成时各舍入一次；中间乘积**截断**；只有最后一步显式
  四舍五入。模型与 RTL 因此逐位一致（已用 62273 条向量全量比对，0 mismatch）。

## 3. sample_enable / ready / latency 合同（M2 重点关注项）

- **`sample_enable` 必须是每音频采样一个脉冲，LFO 每脉冲只推进一次。**
  **绝对不能**接 `snapshot_valid`：它是**保持电平**，不是脉冲（M2 文档已明确）。
  若误接，LFO 会按 50 MHz 推进，颤音频率会偏 ~1042 倍。
- **`ready`：本模块不需要，也不产生。** 它是纯前馈（组合 + 1 级寄存器），
  不阻塞、不退压。因此下游 `ready` 不可能重复推进 LFO——这是结构保证，不是约定。
- **latency**：`base_fcw/bend/...` 在 `sample_enable` 上升沿那一拍被采样，
  `fcw_out/fcw_valid` 在**下一个 `sys_clk` 上升沿**有效。
  从音频采样请求到 FCW 可用 = **1 个 `sys_clk`（20 ns @50 MHz）**。
  相对 48 kHz 帧（~1042 拍）可忽略；M2 的按代次管线只须多打一拍。
- 本模块**无内部状态跨采样累积**，除 LFO 相位寄存器一个 32 位寄存器。

## 4. 精确旁路（合同硬约束）

以下三条**由算术结构保证**，不是特例分支，因此不会出现 ±1 LSB 漂移：

| 条件 | 结果 |
|---|---|
| `bend == 0`（任意 range、任意 mod） | `fcw_out == base_fcw`，**逐位相等** |
| `range == 0`（任意 bend） | `fcw_out == base_fcw`，**逐位相等** |
| `modulation == 0` | 纯 Pitch 路径，`fcw_out` 与无 Mod 时逐位相等 |

推导：`total_q10==0 → q=0, r=0 → factor=factor_q16(OCT[25])=0x10000` →
`(base*65536+32768)>>16 == base`。已在 128 个音符 × 多组 bend/range 上实测 0 偏移。

## 5. 同拍重触发行为（M2 重点关注项）

- `note_on` 与 `sample_enable` **同拍**时：`note_on` 优先。
  本周期的 LFO 相位**按 0 读取**（`sine[0]==0 → vib=0`），相位寄存器置 `LFO_INC`，
  即**新音符从精确 base 音高起振，本拍只推进一次**，不会多推也不会漏推。
- 这使 `bend==0/range==0/mod==0` 时新音符**逐位等于 base_fcw**，包络/Algno 不引入拍频。
- 若**不同拍**给 `note_on`，行为同上，只是相位在本拍被读 0、下拍起按 `LFO_INC` 推进。
- 已验证：先跑 100 拍使 LFO 偏离 0，再 `note_on`，输出**精确回到 base**；
  对照不置 `note_on` 的同一调用则**不等于 base**，证明该标志真实起作用。

## 6. 需要 M1 定的常量（**提案，非用户冻结**）

| 常量 | 值 | 说明 |
|---|---|---|
| `MOD_DEPTH_MAX_Q10` | 512 | mod=4095 时颤音峰值 **±50 音分**（±0.5 半音） |
| `MOD_LFO_HZ` | 5.0 | 颤音频率；`LFO_INC = 447392`（`round(5*2³²/48000)`） |
| 深度单位 | 音分 | 线性映射 mod 0..4095 → 0..50 音分 |

这些是**M1 的提案**，**未经用户冻结**；M2 接线时按现值接即可，若用户改频率/深度，
只改 `LFO_INC` 与 `MOD_DEPTH_MAX_Q10` 两个参数，其余不变。

## 7. 饱和与边界策略（Nyquist）

- `FCW_MAX = 2³¹` = 24 kHz @48 kHz，即 DDS 奈奎斯特。**超限饱和不回绕**。
- 最高合法音 C8(4186 Hz) 在 bend=2047、range=24、mod=4095 下
  peak fcw = 0x1653490C × 4.0 × ~1.03 ≈ 0x5D...，**被饱和到 FCW_MAX**，
  输出恒正、不外泄负 FCW。已验证不出现 NaN/负值/回绕。
- 低端 A0 无下溢风险（`factor ≥ 2**(−25/12) > 0`），FCW 始终 ≥0。

## 8. 误差预算（实测）

| 指标 | 实测 | 阈值 | 依据 |
|---|---|---|---|
| 全网格（6 音符 × range{0,1,2,7,12,24} × bend −2048..2047）最坏误差 | **0.137 音分** | <0.2 | Q10 量化地板 0.098 音分 + LUT 截断 |
| 单调性反转 | **0** | 0 | 规格要求 |
| 精确旁路最大偏移 | **0 LSB** | 0 | 合同 |
| mod=4095 峰值 | **+50.0 音分** | ±0.5 | 提案深度 |
| r∈[0,24] 全 range 最坏 | **0.074 音分** | <0.1 | 24 半音跨 4 倍频 |

0.137 音分约为可闻阈值（5–10 音分）的 **1/40**，与接口规范 V0006 的结论一致。

## 9. 资源与接入提示（给 M2）

- 三张 LUT 共 50+1024+1024 = 2098 项：OCT/SUB 各 20 位、LFO 16 位。
  Gowin 上优先用 **BSRAM**（各表独立单口读），预计 **≤3 个 BSRAM 块**，
  0 DSP（乘法是常数/窄位）；**待 M2 实测**，本包不含综合报告。
- 只有 **1 个 32 位状态寄存器**（LFO 相位），无 FIFO、无 CDC。
- 因为不需要 ready 且纯前馈，**M2 不必为本模块做串行读口/流水**：
  四路各一份即可，或用 M2 既有的按槽展开结构。这一点与 M2 文档里
  "四路全身份读取代价大"针对的是 `performance_control_state` 的读口，不是本模块。
- 若 M2 想省 LUT 口：四路共享 OCT/SUB、LFO 也可共享（只相位寄存器分四份），
  因为读地址在组合路径上、单拍可完成。属 M2 实施选择，不影响本合同。
