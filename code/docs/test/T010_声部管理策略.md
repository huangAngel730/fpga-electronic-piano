## 二、声部分配策略（M1定义）

### 2.1 策略选择：最旧声部偷取（Oldest Voice Stealing）

**原理**：新音符到达时，若所有声部已用，停止最早触发的声部。

**优点**：
- 简单，无需优先级判断
- 保留最近按下的音符（用户意图）
- 适合旋律演奏

### 2.2 算法

```python
class VoiceAllocator:
    def __init__(self, num_voices=4):
        self.voices = [None] * num_voices  # None表示空闲
        self.timestamps = [0] * num_voices
        self.time = 0
    
    def note_on(self, note_number):
        self.time += 1
        
        # 1. 查找空闲声部
        for i, v in enumerate(self.voices):
            if v is None:
                self.voices[i] = note_number
                self.timestamps[i] = self.time
                return i
        
        # 2. 无空闲，偷取最旧的
        oldest = min(range(4), key=lambda i: self.timestamps[i])
        self.voices[oldest] = note_number
        self.timestamps[oldest] = self.time
        return oldest
    
    def note_off(self, note_number):
        for i, v in enumerate(self.voices):
            if v == note_number:
                self.voices[i] = None
                return i
        return -1  # 未找到
```

## 三、特殊情况处理

### 3.1 同音重复

**问题**：按A后再按A，是重新触发还是忽略？

**方案**：重新触发（偷取旧的A，启动新的A）

**理由**：允许快速重复演奏同一音符

### 3.2 All Notes Off

收到All Notes Off事件时，立即释放所有声部。
