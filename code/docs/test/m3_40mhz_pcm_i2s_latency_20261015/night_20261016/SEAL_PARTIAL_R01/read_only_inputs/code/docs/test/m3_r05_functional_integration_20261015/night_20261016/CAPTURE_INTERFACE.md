# A to C capture contract (2026-10-16)

Producer: night task 2. Consumer: night task 3. All paths below are relative to this directory. `CAPTURE_READY.json` is published atomically only after a successful real ModelSim run, complete capture validation and source/tool identity checks. Until then no real-chain claim is available.

- Main output: `REAL_CAPTURE.jsonl`, schema `M3_R05_PUBLIC_PRE_NBA_V1` (unchanged original contract).
- Header: `{ "kind":"HEADER", "schema":"M3_R05_PUBLIC_PRE_NBA_V1", "clock_hz":40000000, "first_valid_observable":false }`.
- TICK: one row at EVERY 40 MHz positive edge, sampled in the active region before NBA, starting cycle 1 with no gaps, including reset. Fields: `kind,cycle,epoch,rst_n,frame_tick,request_accept,request_id,commit,committed_id,left,right,clipped,pending,play_left,play_right,clip_count,underflow,bclk,ws,din,first_valid`. Bits and counters are decimal integers; PCM is signed PCM24; `first_valid` is always JSON null. Nonbinary/X/Z signals invalidate the trace.
- Asynchronous reset assertion: `{ "kind":"RESET", "epoch":N, "cycle":last_tick_cycle, "time_ns":T }`, epoch starts at 0 and increments for each observed assertion. Time zero initial reset is epoch 0; no fabricated transition. Internal synchronized reset assertion is observed, not inferred from testbench input.
- Terminal row: `{ "kind":"END", "cycle":last_tick_cycle, "epoch":last_epoch }`, unique and after all ticks.
- `bclk,ws,din` are public PT8211 transmitter pins, 16-bit right/left words in 32-slot half frames (64 BCLK rising edges per stereo frame). PCM24 is rounded with +128 then arithmetic >>8 and saturated to signed PCM16. WS low denotes right. C must independently inspect the frozen transmitter for exact phase/order, including startup partial words. No generic Philips-I2S phase assumption.
- `request_accept` is the frame-core public output, distinct from accepted performance/MIDI events. Request/commit IDs and PCM come from public frame-core output ports; play PCM comes from the same ports that drive transmitter inputs. No internal arithmetic registers are read.
- Companion `REAL_INPUTS.jsonl`: `HEADER` (schema `M3_R05_INPUT_PRE_NBA_V1`), then `INITIAL_INPUTS` with `time_ns:0,midi_rx,sys_rst_n` after a zero-time inactive-region settle; the header always precedes initial state. Every same positive edge is recorded as `TICK` with `cycle,time_ns,rst_n,midi_rx,event_valid,event_ready,event_data_hex,config_valid,config_ready,active_voice_count`; plus asynchronous raw `MIDI_EDGE` / `RAW_RESET_EDGE` records with `time_ns,value` only after time zero, and unique `END`. Initial values are states, not fabricated transitions. Event data is a 16-digit hexadecimal string. Event/config/status observations are existing module public port wires in a copied board graph. Raw MIDI edge phase is stimulus time; UART input is asynchronous to the 40 MHz core. No claimed input-to-analog measurement. This instrumentation has only static checks in this batch, not executed RTL validation.
- Source: exact frozen R05 package plus read-only previously validated 7 ms watchdog TB. Isolated copied board instrumentation and extra observation/drain TB edits are fully diffed and hashed; algorithms/ROM unchanged. Baseline TB legacy assertions are retained; NEW capture never uses hierarchical internal registers.
- Main trace covers startup, real UART MIDI note/program events, four overlapping voices, fifth-note stealing, a final complete frame fence and asynchronous reset. Idle boundary drain is observation-only stimulus extension. Reset cancels any remaining outstanding request. First-valid and analog latency remain UNKNOWN.
