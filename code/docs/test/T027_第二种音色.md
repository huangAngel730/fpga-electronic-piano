# T027 第二种音色设计

**任务**: T027 第二种音色  
**负责人**: M1  
**周次**: W5  
**验收**: 频谱可区分且实时切换  

---

## 一、音色选择

### 方案：锯齿波（Sawtooth）

**理由**：
- 富含谐波（基频+全部整数倍谐波）
- 与正弦波频谱明显不同（易区分）
- 已有波表生成（wavetable_gen.py）

**频谱特征**：
- 正弦波：单峰
- 锯齿波：多峰（1f, 2f, 3f, ...）

---

## 二、实现

波表已生成：`code/model/generated/wt_saw_1024x16.hex`

RTL集成（M2）：
```systemverilog
// 音色选择（来自CTRL_VOICE_SELECT事件）
logic [1:0] voice_select;  // 0=sine, 1=saw

// 查表切换
case (voice_select)
    0: wt_sample = sine_table[addr];
    1: wt_sample = saw_table[addr];
endcase
```
