2. E1 的正式 accepted_event 复制点、mode 和 score 生产者、98 位 score 的时间原点/epoch，以及 40→25MHz 帧号跨域合同。显示 ready 不得进入音频接受路径。旧闪光 FAIL 继续保留，本轮不签完整命中交互。

4. E3 正式 UART pin/Bank/电压/CST、采用的协议候选精确版本及与正式消费者绑定的 committed metadata。存储和 READ 通过不构成自动演奏或 PCM 通过。任何新候选合同修复只修改新目录，旧源码和失败记录保留。

## M1 需要决定的精确算法事项

E4 继承冻结 piano ROM/ADSR/定点混音可证明不同槽的独立相位、FCW、包络及数字贡献；该 ROM 含谐波，不构成纯正弦模式或32个独立可闻谱峰。若完整验收要求新增纯音测试模式，需先冻结 phase→sine ROM、各槽增益、混音与 clipped 定义及与原 piano 模式的隔离方式。不得从 DUT 捕获反推黄金或擅自替换冻结 ROM。
