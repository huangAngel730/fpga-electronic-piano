# M1-R6-3：四声基础的测量与计算判据

这是无实物条件下的算法判据；没有收到本轮Pro同版板采，不生成或宣称任何实测PASS。M3负责原始采集与共同时间基准，M1解释数学，M2签同版和最终等级。

| 检查项 | 必要原件和计算 | 结论边界 |
| --- | --- | --- |
| 四个独立音高 | 同版source/ROM/码流与MIDI原输入、每路真实FCW/推进语义、四次独奏及四音持续片段。频率依据 `f=FCW*实际lane推进率/2^32`；每个音高先在独奏片段确认，再检查合奏中的对应基频。 | 谐波峰不能当额外声部。缺逐路身份或实际推进率时不以总FFT峰数签四声部。 |
| 逐放 | 对齐NoteOff实际应用、Release尾音、真实退休、后续仍占用槽的generation和音高。保持片段应和同输入黄金逐样本对照，模拟侧比较相应基频及包络趋势。 | NoteOff不等立即静音；Release期间保槽及实际尾长按R6-1源规则计算，不套toy立即释放。 |
| 力度 | 保持音符、音色、采样/增益及录音增益一致，记录原7bit及扩展10bit velocity、冻结增益ROM和包络阶段；按黄金比较同一阶段PCM幅度或能量。 | 不能把“velocity翻倍”等同PCM必然翻倍，不能把自动增益或不同ADSR时刻当算法差异。 |
| 削波 | 数字侧比较逐样本饱和前加和、上游clip、FX输出clip及最终左右clip，严格越界才置位。模拟侧仅另报波形削顶/设备过载。 | feedback内部饱和与最终输出clip分开；声卡/功放削顶不能归为FPGA的数字clip计数。 |
| 数字采样率 | 取同一真实时间基准下的连续LRCLK/FRAME边沿，注明频率计/逻分时基误差和覆盖窗口；分别计数周期/抖动/漏帧。 | WAV头部采样率是声卡采样率，不是FPGA的48kHz证明；833/834拍设计序列不等于实测。 |
| 起音与恢复 | 保存输入物理边沿、事件接受/应用、数字首个非零PCM和模拟输出共同时间轴，注明噪声基线、触发阈值、设备延迟和测量不确定度；reset前后绑定同一码流。 | 数字内部延迟不能代替输入至模拟输出≤10ms；跨设备无共同时间轴则该项UNKNOWN。 |

FFT应随原始未裁剪PCM、实际声卡采样率、窗口样本数、窗口函数、起止时刻、通道/增益、频率分辨率 `Δf=Fs/N` 一并保存。是否足以区分目标音高应看最邻近目标频差及窗口泄漏，不能只贴频谱截图或用预置PCM替代实时合成。基础四音结论采用真实采集输入绑定的音高，既有60/63/67/70合成向量与M3的60/64/67/72场景不能混签。

本轮没有M3-R6-8板采，R6-3实证状态为 `PENDING_REAL_INPUT`；不安排N32、声卡操作、板卡下载或新增HDL/EDA执行。
