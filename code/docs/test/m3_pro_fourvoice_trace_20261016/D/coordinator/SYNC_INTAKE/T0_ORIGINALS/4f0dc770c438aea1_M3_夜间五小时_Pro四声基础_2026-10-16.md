## D：48 kHz 数字期限、PT8211 串行与复位安全（最长 2 小时）

- 用身份明确的帧／lane／左右 PCM24 只读值建立独立边界向量，检查符号、位序、左右声道及 PT8211 **LSBJ** 边界和串行 ID。40 MHz 下 48 kHz 平均每帧约 833.33 拍；实际 833／834 拍分布应由真实 frame tick 和时钟合同确定，不能把每帧硬写 833 拍。真正期限需从请求、接受、完成到消费的**同一时基**逐笔计算，列 `lane_tick`、积压、超期与首差异；缺实际采样／公开 trace 时只交判据和夹具，数字真实期限标 UNKNOWN。
- 最小正例覆盖左右非同值、负值、边界值、复位前后首帧。负例至少拒收**左右交换、串行错一位／错声道边界、符号扩展错误、漏帧／超期、旧 epoch PCM 混入新帧、`PA_EN` 错极性或复位／未稳定即开启**；每个实际运行例留原始输入、输出、双流、退出码及首失败。Pro 高有效 `PA_EN` 只是数字候选规则，不能代替板上电平、功放安全或模拟输出实测。
- 无 M2 新 Pro 精确 source SHA／真实 PCM-ID trace 时，可以运行边界夹具的正反例，但不能声称 DUT 串行 ID、48 kHz 实际采样、833 拍实际服务期限或模拟输入→输出 ≤10 ms 已通过。D 若被真实帧字段阻断，封字段和波形需求；转回尚可独立完成的 C，二者均不可行动则停。
