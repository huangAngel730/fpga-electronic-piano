# 第二轮：保存被拒绝的原始沿

首轮三个正例和22个故障的功能判定均正确；只读自审也确认832/833拍清理边界闭合。但封存检查发现 fail() 在正常的逐沿写入之前退出，故障 CSV 缺少发生拒收的那一沿，只能从 stdout 看到首差异代码和周期。真实 Pro 后续接入需要该沿的原始公开端口值来定位问题。

最小修复：将同一行输出抽成 record_edge()，正常沿保持原写入位置，fail() 先保存故障沿再 flush/fatal；不改请求、截止、PA 或 PCM 判据。runner 对每个反例增加独立检查：CSV 周期连续，末行周期等于 FIRST_REJECT 周期。第二轮只验证此具体证据缺口和原25例，旧首轮完整保留；本包最多三轮，旧夜间额度未改变。

第二轮预启动曾被 runner 的“已有通过则停止”保护拒绝，stdout 为 `Prior success: stop`，外层退出1，没有创建ROUND_02、没有启动编译／仿真。将保护收窄为“已有通过且没有本轮具体修复说明则停止”；仍禁止无说明复跑及第四轮。该分支仅允许已记录的原始故障沿缺失修复，不扩大功能／工具／写集。
