# R7-B 覆盖发现与版本边界

R01新15项软件检查exit0；总控随后静态指出40MHz采样看不到87.5/112.5ns之间95–100ns PA/TMDS异值或X。该版不签完整外部行为，旧源及日志保留，不追加运行旧版误收。

R02仅新增4项事件流定向夹具，exit0/0.187秒。公共pins变化均写postponed同timestamp稳定快照；95ns差异与未知分别首拒收FIRST_EVENT_DIFF/EVENT_UNKNOWN。原15项未重跑。

自有只读子智能体在R02后指出窗尾time==stop_ps被<过滤。改为<=以包含末拍NBA后稳定差异；此最终两字符边界修订没有再运行，不能冒称已实际验过尾拍负例。R02源码快照与最终源码SHA分别保留，M2后续真实编译/定向核验须用最终版本；B预算已耗尽，不借R7-D测试它。

没有功能进程意外崩溃/超时；静态发现不是实际跑过的失败反例。DVI模拟stub常量data脚、原dds未列入、物理PLL等限制独立保留。
