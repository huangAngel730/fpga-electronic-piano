## 一、算法定义

### 基本延迟（Echo/Delay）

```
输出 = 原信号 × dry_gain + 延迟信号 × wet_gain
```

**参数**：
- `delay_time`: 延迟时间（样本数），如24000（500ms@48kHz）
- `dry_gain`: 原信号增益（0.7，Q0.15格式=22937）
- `wet_gain`: 延迟信号增益（0.3，Q0.15格式=9830）
- `feedback`: 反馈增益（0.5，实现多次回声）

---

## 二、实现结构

```python
class DelayEffect:
    def __init__(self, delay_samples, feedback=0.5):
        self.buffer = [0] * delay_samples
        self.pos = 0
        self.delay_samples = delay_samples
        self.feedback = feedback
    
    def process(self, input_pcm, dry_gain, wet_gain):
        # 读取延迟样本
        delayed = self.buffer[self.pos]
        
        # 混音
        output = int(input_pcm * dry_gain + delayed * wet_gain)
        
        # 写入新样本（含反馈）
        self.buffer[self.pos] = int(input_pcm + delayed * self.feedback)
        
        # 移动指针
        self.pos = (self.pos + 1) % self.delay_samples
        
        return output
```

## 三、RTL考虑（给M2）

### 延迟缓冲
- 500ms@48kHz = 24000样本 × 24bit = 72KB
- 使用BSRAM实现循环缓冲（Tang 60K有268KB）

### 读写指针
- 写指针：跟随输入
- 读指针：写指针 - delay_samples（模运算）

### 定点乘法
- 增益Q0.15 × PCM24bit → 右移15位

---

## 四、防爆音

- 限制反馈增益 < 1.0（防止无限增长）
- 输出饱和限幅
- 参数切换时平滑过渡
