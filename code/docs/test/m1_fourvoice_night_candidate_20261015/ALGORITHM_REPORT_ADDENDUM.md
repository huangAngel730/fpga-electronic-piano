# 算法报告必要增量：同源四音与待验边界（2026-10-16）

本稿补充既有双音色/延迟交付说明与基础四声部合同，作为近期演示/答辩算法段的可追溯增量；不重写正式Word、不生成录音或伪造实测图。本轮原件入口分别为M1-A `../m1_r05_pcm_oracle_20261016/README.md`、M1-B对应目录的合同与软件回执、`SOURCE_INTAKE.json`。

当前138K C/31005设计采用40MHz内核、48kHz设计采样率、四个独立相位/频率/包络槽。频率使用32位FCW，理论频率为 `FCW×48000/2^32`；60/63/67/70分别为261.62556、311.12698、391.99544、466.16376Hz。四路signed16波形与Q15包络逐样本相乘，负数算术右移向下取整，转PCM24后先宽位求和再饱和；不通过额外除4掩盖削波。每槽音色在成功起音/重触发时锁存，Program0 Piano V1/Program1 Triangle；第五音按原已签LRU身份算法替换，slot-generation区分旧代回包。

R06源与M3已签7ms候选89项inputs逐字节同版；本轮只核来源和新增软件参考，没有再次运行那次ModelSim。真实候选已签的观察仍是四槽活动、303提交/258非零和串行活动，不能由此声称四路逐样本正确。新软件参考区分Triangle推进前地址和Piano推进后地址，并保留ADSR准备寄存、效果输入接受/取消对历史的影响；数据可供M3建立独立日历映射，不能把软件目标值写成RTL输出。

R06板壳启用左右独立一采样延迟，dry=32767、wet=16384、feedback=0。两项Q15乘积各右移15后相加饱和，效果的样本序号按被接受事务而非仅成功commit计。接受后取消发布不回滚历史；因此图示/报告不能只拿最终commit序列作为全部效果输入。默认旁路只有enable0时才逐位保持PCM，不应将dry32767称为精确unity。

可直接写入现阶段报告的结果：精确源/ROM身份已核，四频条件数学参考及软件正反例已准备；视觉接入前后音频的比较软件与完整窗口合同已准备。所有软件数据均标合成，实际视觉前后流、四频同链PCM24和完整串行字仍待捕获。
