## 五 填写规则

1. 一条记录只对应一次连续使用，跨时段分开记录。
2. 时长以小时为单位，保留一位小数。
3. 任务号必须能在 `任务看板.md` 中找到，不允许写自定义编号。
4. 码流版本写提交前缀或标签，不允许写“最新版”。
5. 结果写实际达到的验证等级，例如 L2 或 L6，不允许只写“正常”。
6. 未登记的使用不参与下周配额，但需要在同步会上说明原因。
7. **不写板卡和分析仪编号**（编号已取消，见 D023 与 `板卡与仪器资源管理.md` 第二节）。「用途」列写 `正式验收` 或 `实验接线`；「板上接线状态」列写明有无临时飞线——**用于正式验收时必须写「无临时接线」**；「码流版本」列写提交前缀或标签，写不出回退版本的记录视为不合格。
