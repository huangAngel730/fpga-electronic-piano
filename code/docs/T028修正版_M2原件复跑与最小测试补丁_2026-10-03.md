- model.process与合同仍称delay_samples=0“实际无延迟效果”，但相同文字又承认读取上一圈旧值。实际环形缓冲语义是**delay0表示整DEPTH圈的旧缓存值**；不能同时称无延迟/旁路。修正文档为当前实现，若想真正零延迟/旁路应另外提出新语义，不在本轮改数学定义。
