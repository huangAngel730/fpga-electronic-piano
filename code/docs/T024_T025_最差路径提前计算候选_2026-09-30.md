# T024/T025 最差路径提前计算候选（M2，2026-09-30）

本地正式集成基线中，最差Setup为+0.037ns，路径从I2S帧计数逻辑经lane_tick进入ADSR reciprocal乘法的选择逻辑。本轮在忽略目录 `code/output/t024_adsr_precompute_20260930/`生成候选，未覆盖M1正式 `code/rtl/audio/adsr_piano_envelope.sv`；正式源码SHA仍d65566e839f1b51b39c670167d27498ad38acbf02ff1270d98a1e48db97a69b9。

## 唯一逻辑变更与原理

将组合预计算选择条件从 `state==ATTACK && sample_tick && elapsed==ATTACK_SAMPLES-1` 改为 `state==ATTACK`。Decay步长仍在Attack最后采样锁存；在其余Attack周期，提前算出的乘法值不写入任何包络状态。note_off与LOAD_2分支优先级、公式、乘积宽度、采样次数、状态编码及ROM值均不变。因此优化是移除组合计算上的多余使能，不是修改算法数学或缩短Release。

实际候选文件为上述逻辑加构建必要的ROM绝对路径替换。candidate_patch.diff保存去除路径映射后的最小差异；对照工程的全部其他File条目与现有staged_formal工程完全一致。
