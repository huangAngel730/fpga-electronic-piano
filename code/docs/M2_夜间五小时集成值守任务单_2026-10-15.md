# M2 夜间约五小时集成值守（2026-10-15）

本单配套 M1/M3 各约八小时夜间任务。**夜间用户无法干涉，三成员互相无法私信，也完全不能使用实物**：不触碰板卡、JTAG、接线、仪器、录音、烧录/下载或实物视频。仅依已发布的隔离权限做软件、静态核查和必要门禁。缺新许可、共享接口决定或工具/输入身份时封存原件，立即转下一个已授权任务；不等待任何人回复、不把夜间沉默当批准。次晨由用户分别转发消息，M2 再做最终复核/登记。N32暂停为最后条件拓展。

## 从开始时刻 T0 计约 5 小时

| 时段 | M2 独立动作 | 退出物／受阻转轨 |

**失败转轨**：R05真日志未到→核既有便携包/物理同源SHA；端点新STA未到或工具失败→旧报告限定审阅与软件坏例；M1数学未到→列 PCM/I2S 公开字段/48 kHz 帧节拍要求。均不得自填真值、代占他人一次额度或重做已签旧专项。M1/M3 在各自隔离目录可继续到约八小时，M2 不需全程在线配合。正式 top、共享接口、CST/SDC、码流、上板与任何实物结论不因五小时夜班自动获得签收，`board_release_allowed=false` 直到真实门槛闭合。
