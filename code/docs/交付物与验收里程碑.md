## 四 演示视频要求

- 内容至少覆盖：完整曲目演示、音色切换、延迟效果调参、实物与接线画面。
- 视频中的音频必须是 FPGA 实时输出，不得使用后期配音或预录素材冒充。
- 保留原始素材与录屏文件，便于答辩时展示未剪辑版本。
- 视频与码流必须对应同一个冻结版本，录制前确认码流已封板。

- 码流与源码标签一致，提交号记录在案。

- 视频可正常播放，音画同步。
- 答辩材料与报告口径一致。
- 演示曲目可复现，含故障备用方案。
- 全部材料做离线备份，不依赖单一存储。
