## 已核清的下游接线条件

本次仅静态源码对照：将模块名归一后，以下两份完整参数/端口头一致，不是编译或行为等价结论。

- pROM `m2_b2d_event_audio_prom.sv` SHA `4339784901857cab00ce856dc23ce993a59783398d37aca02648c3123b533e84`。
- `premixed_frame_adapter.sv` SHA `d7952a5f986eb8b609cbe657907e418cfe751c6492d6e49469b5e37c390bb56c`，本次未修改。

| 候选侧 | 帧适配侧／处理 |
|---|---|
| sample_valid/ready/id32 | candidate_sample_valid/ready/id；frame产生credit，实际接受另按valid&&ready计数 |
| result_valid/ready/id32 | candidate_result_valid/ready/id；成功握手才入hold及buffer，错代/重复不得补签commit |
| signed24 left/right、clipped | 原样连candidate_left/right/clipped；不二次混音，不以满幅值推断clipped，不用late替代 |
| cancel | 适配器candidate_cancel来自完整左右串行帧frame_tick；非每个WS/LRCLK沿 |
| READ及DRAIN占用 | ready变低时保存当前credit/ID；帧到期取消旧代，idle后再接受新代 |
| fault/aborted/abort_reason/late | 保留公开观测，不本轮添加panic、重试或替代音频语义；新组合验证须说明触发后发布与恢复边界 |

`pcm_result_hold`的request_window和ID比较关闭重复结果窗口，`pcm_frame_buffer`只在有效匹配握手计commit；clip_counter沿同一pcm_valid&&pcm_ready计数。新M3后继必须保持这些公开合同，M2接入不读取候选内部私有寄存器。

正式接入前另核40MHz音频域复位/完整帧节拍、观测CDC到25MHz像素域及真实播放样本来源。接口静态一致不能取代新组合功能或新STA；旧四音/60K/newRAM5e1d13c及旧源码/证据保持。完整T052/T060/T061仍PARTIAL。
