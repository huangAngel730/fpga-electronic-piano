## 一次现场会话：先最小安全检查，再立即听四音

1. **上电/下载前短核（不是另开仪器准备项目）**：拍板号和接线、记录 JTAG 识别的完整器件、供电和编程工具版本。断未知外部 MIDI/HDMI；无临时 5V 线。确认板上供电与现有接线正常；外接 MIDI 只在其 FPGA 侧电平与共地已确认后接入。选可控低音量的 J25 耳机或有源音箱，**J27 功放输出不接声卡 line-in**。身份、电平或供电异常即停；不做完整 Bank 测点巡检和模拟指标专项。
2. **仅一次 SRAM 下载**：在 M3 下载机复算ZIP和实际选中 `.fs` 的 SHA/长度，检查交接包 `DIAGNOSTIC_IDENTITY.json` 的 `SRAM-only/flash_write_allowed=false`。工具明确选 SRAM 模式和该完整器件；记录时间、argv/GUI选项、原始工具日志/退出码、下载前后当前SRAM状态及上电复位/静音。失败即停，留首个失败原件，不改约束/ROM/PLL、不可反复下载。
3. **有声输入条件**：顶层只有 EX_KEY.1/EX_KEY.2 两个演奏按键，四音同时激励必须用安全的独立 MIDI 来源；外接隔离适配器在 FPGA 侧的 3.3V 电平与共地必须有可靠确认；未知电平或 5V 输出不可接入。没有合规 MIDI 时只核按键/静音并写“四音未测”；不得拿双键或旧60K实测补缺。音频先低音量，出现异常大音量、功放发热、失锁或未知电平立即静音、断开外设并保留观察。
4. **最短四声曲线**：在当前同一 `.fs` 与接线下发送 MIDI Note On/Off 的**四个非整数倍频关系音高**，建议 note 60/64/67/71、同力度80；依次每次只开一音并各录约3–5s，随后四音同时保持约5–10s，再逐个 Note Off 保持其他音。重复一次完整和弦与复位后恢复；资源允许再用力度40/120及第五音观察抢占，但不可挤掉四音核心。保留 MIDI 发送字节/时间及四个独奏、四音同开、逐键释放、静音与复位的连续手机视频或原始录音；标明各声何时发出。用四段独奏对照合奏来区分四音，不要求当场做纯正弦 FFT。可读状态计数时一并留原始记录，不用计数代替现场发声。
5. **收口**：记录能否从板上的实际音频口连续听到单音、四音、逐放、复位恢复，有缺音/爆音/无声就保留原始现象并止损。专门的 BCLK/WS/DIN 时序、左右模拟参数及纯正弦 FFT **本轮不测、不阻挡这次现场诊断**；未测项目仍为 UNKNOWN，不能从“能听到四音”推断 48kHz精度、≤10ms延迟、完整数字接口或赛题现场频谱已通过。

## 基础实物测试补充清单

四复音试听之外，基础要求还需要以下现场证据；按优先级执行，时间不足时保留未测项，不用拓展项填补：

1. **两项独立演奏维度**：沿用已冻结的 60K 方案，以琴键音高/选音（含触发）和 Velocity 力度作为基础两个独立可控维度。现场最短验证为“同一音高轻/重弹，响度随力度变化”和“相近力度弹两个音高，音高随键位变化”；保留输入 MIDI Note/Velocity 值与声音记录。旧 60K 的轻重响应 V0130/V0137 仅属旧码流，新 138K 须在本次精确 `.fs` 下核一次。项目自研部分是 MIDI 接收、事件映射和实时合成；键盘内部力度传感器为外购，比赛对“自研交互方案”的认定仍有评审风险，不能凭键盘自带功能自称团队自制压力传感器。无需为本次测试临时增加第三种输入或改正式顶层。
2. **逐声部生命周期**：单音 Note On、力度变化、Note Off、Release/静音、同音重触发、四音同时保持、逐声部释放，检查无丢音、挂音、错误串音和释放时其他声部不中断。
3. **复位与异常恢复**：上电静音、复位期间静音、释放复位后恢复演奏；演奏中复位后用现场听音确认静音并能再次演奏；数字链内部状态未采集则写 UNKNOWN。出现失锁、欠载或异常大音量立即停止并保存首个现象。
4. **输入到声音的直观响应**：现场比较按下、松开与听到声音/停止声音的对应关系；本轮不做双通道时基定量延迟，未测的 ≤10ms 保持 UNKNOWN。
5. **短时稳定**：重复一遍四音和弦、逐个松开与复位恢复；有第五音可选补试声部抢占，不为凑满时长做长时间压力专项。

**本轮明确不做**：纯正弦四峰 FFT、PT8211 BCLK/WS/DIN 逐项测量及 LSBJ 波形判据、左右模拟偏置/削波/噪声/PA_EN 温升的详细量化。这些可留到需要证明相应赛题指标或定位现场失败时安排独立复核；本次只出诊断性四声部试听结果，不把未测项目写成通过。纯硬件逐样本属性由 RTL 和已有离线证据限定支持，不能用这次试听替代赛题现场频谱要求。

**分叉与停止**：下载/上电失败→原件封存，仅诊断电源→时钟/复位→引脚→I2S→PCM；安全MIDI缺失→两键/静音局部记录后停，不造四音结论；四音少一路→优先对照四个独奏、真实输入字节/音频/I2S/计数，停止继续拓展；四音通过→交M2当前音频/视频原件，不为补仪器指标延长本次会话或开始双滑块码流。实际现场记录只对测过的条件作限定L6候选，正式整机同版验收/码流发布保持 `board_release_allowed=false`，待 M2 根据实际缺口决定后续独立验收。先前 `c12636c` A隔离L2、B五对定向L5、C/D夹具L2都不能自动替代本测试。
