## 一次现场会话：先最小安全检查，再立即听四音

1. **上电/下载前短核（不是另开仪器准备项目）**：拍板号和接线、记录 JTAG 识别的完整器件、供电和编程工具版本。断未知外部 MIDI/HDMI；无临时 5V 线。按板级事实文件现有测点简量 Bank3/4/5 对地实际 VCCIO（TP21/TP22，VCCIO5的FB13侧；TP23先断电核导通），保留表计读数及测点照片；身份/供电/测点归属或电压不符即停止。选可控低音量的 J25 耳机/线路或有源采集负载，**绝不将 J27 功放输出直连声卡 line-in**。不要把 LVCMOS 声明当成电压实测。上述最短电气检查不可因赶时间省略。
2. **仅一次 SRAM 下载**：在 M3 下载机复算ZIP和实际选中 `.fs` 的 SHA/长度，检查交接包 `DIAGNOSTIC_IDENTITY.json` 的 `SRAM-only/flash_write_allowed=false`。工具明确选 SRAM 模式和该完整器件；记录时间、argv/GUI选项、原始工具日志/退出码、下载前后当前SRAM状态及上电复位/静音。失败即停，留首个失败原件，不改约束/ROM/PLL、不可反复下载。
3. **有声输入条件**：顶层只有 EX_KEY.1/EX_KEY.2 两个演奏按键，四音同时激励必须用安全的独立 MIDI 来源；外接隔离适配器先在 FPGA 侧量 VH/VL/共地并确认满足该 Bank 的实际电平与上升/过冲，不明或5V不可接入。没有合规 MIDI 时只核按键/静音并写“四音未测”；不得拿双键或旧60K实测补缺。音频先低音量，出现直流偏置、异常大音量、功放发热、失锁、未知电平立刻静音/断外设并保留观察。
4. **最短四声曲线**：在当前同一 `.fs` 与接线下发送 MIDI Note On/Off 的**四个非整数倍频关系音高**，建议 note 60/64/67/71、同力度80；依次每次只开一音并各录约3–5s，随后四音同时保持约5–10s，再逐个 Note Off 保持其他音。重复一次完整和弦与复位后恢复；资源允许再用力度40/120及第五音观察抢占，但不可挤掉四音核心。原始 MIDI 发送日志要给出字节/时间，保留每个独奏区间、四音同开、逐键释放、静音和复位音频原文件与视频，标注同一时基和输出负载。分别比较四段独奏的基音/包络及合奏区间，不把复杂音色的单音谐波或延迟回声当作四个独立声部；如可读 UART `active_voice_count`/underrun/clip，保存原始连续日志，不用自报计数替代真实听觉与频谱。
5. **同版数字/模拟最小证据**：若有逻辑分析仪，同次采 I2S BCLK/WS/DIN 与 sample rate（目标48kHz）、左右相位/数据；用 J25 正确低电平输出到声卡录双声道原文件，确认各单音与合奏期间均有声及缺音/削波。若同一时间基准双通道可同时抓输入事件边沿与模拟起音，再据原波形计算每次延迟及最大值；没有同一时基/阈值，不声明 ≤10ms。真实谱峰需带采样率、FFT窗口/幅度设置及逐声部独奏对照，正式 T052 N 路纯正弦测试模式若并非这份精确码流的一部分，则保持 UNKNOWN，不能由当前复杂波表/回声的四峰替代。

**分叉与停止**：下载/上电失败→原件封存，仅诊断电源→时钟/复位→引脚→I2S→PCM；安全MIDI缺失→两键/静音局部记录后停，不造四音结论；四音少一路→优先对照四个独奏、真实输入字节/音频/I2S/计数，停止继续拓展；四音通过→同一次会话量剩余数字/模拟指标，再交M2，不开始双滑块码流。实际量化只对测过的条件作限定L6候选，正式整机同版验收/码流发布保持 `board_release_allowed=false`，待 M2 将逐请求账本、真实R05逐样本PCM→I2S、完整STA/电气与板级原件合并后决定。先前 `c12636c` A隔离L2、B五对定向L5、C/D夹具L2都不能自动替代本测试。
