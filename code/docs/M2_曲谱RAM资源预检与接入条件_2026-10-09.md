## 当前预筛政策

默认score子树Register<=8192、LUT<=8192、至少有BSRAM、没有额外DSP。8192是M2保守集成预筛预算，不是138K器件容量或正式STA证明；候选资源方案可再审，但不能自行提高阈值求PASS。CLI阈值写入实际收据，正式采用时必须核政策一致。

模块总资源缺失/非整数/负值/直属大于总数、超root/模块重名或缺失、XML截断/实体声明、错误SHA均fail-closed。SSRAM不武断要求0，小buffer可使用分布式RAM；正文是否进入BSRAM必须另证明。即使RESOURCE_SCREEN_PASS，score_body_bsram_proven/ready_for_full_pnr/STA_passed/board_release_allowed仍为false。

真实综合XML只有模块BSRAM汇总不足以证明正文映射：需给出正文memory对应原生BSRAM实例、配置容量/宽度、bank/event地址、写enable及读端口关系；不能用把小buffer映入BSRAM的汇总值蒙混。
