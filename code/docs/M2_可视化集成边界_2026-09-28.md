## 可确认的现行事实

1. **M1 最新视觉模型的 `duration=None` 不是“永久显示”。** `code/model/visual_score_reference.py` 当前定义没有 Note Off，但*画面*在命中时刻 + `note_linger_time` 后消失，默认 linger 0.5s。M3 `visual_score_tracker.sv` 在 `score_duration_valid=0` 时，于 `judged` 后超过 `hit_frame+HIT_WINDOW_FRAMES` 才释放；默认窗6帧约0.1s。模型与 RTL 的停留时间不一致；曲谱画面消失不应偷偷合成一个演奏 Note Off。请 M1 明确正式视觉语义、duration=0/None 和到达、过窗、消失端点是否含当帧，然后 M3 在获授权目录修正。
2. 用户屏为 AOC Q27B35，当前**仅有独立视频诊断候选**：25MHz / 800×525 ≈ 59.5238095Hz，未出图、未冻结最终屏幕模式。按候选值，模型2s预告≈119.05帧、±100ms判定≈5.952帧、0.5s停留≈29.762帧；M3默认 `PREVIEW_FRAMES=120`、`HIT_WINDOW_FRAMES=6` 是近似，linger须独立换算，不能共用判定窗口。确切刷新率从最终真实 PLL/总像素决定，并由 M1确认秒→帧取整与端点规则；如该屏不锁定候选模式，所有参数重算。
3. 正式音频顶层已有按键+MIDI两个事件源，允许同音高同时按住；M3 `visual_live_state.sv` 的 `key_down[note_number]` 单布尔位会被其中一路 Note Off 提前清除。显示工作状态应跟踪 `(source_id,channel,note_number)` 的持有身份，再归并为每音高是否点亮。相同身份重触发不能当成两个持有实例直接累加；需要另外测试双源同音、先后松键、同身份重触发、ALL_NOTES_OFF及失步清空。演奏音符身份依据现行 `模块接口规范.md` §3.4；M3 内部如何用有限资源保存持有身份并处理满状态，应先给 M2评估并经用户私发跨岗授权，M2不自行改 `rtl/input/visualizer/`。

## M2 未来的接线方案（设计边界，非已执行）

- **音频旁路复制**：源域取 `shared_event_valid && shared_event_ready` 的“音频实际消费”沿、`shared_event_data` 同拍送 `visual_event_bridge.accepted_valid/data`；桥只复制已消费事件，视频背压不能拉低音频 event_ready。桥 `video_valid/data/ready/desync` 分别接 M3 `event_valid/data/ready/video_desync`；可视化丢包时应清理/标记显示键态，不误改音频。
- **复位**：视觉桥 `rst_n` 必须由外部公共视觉复位源异步断言（至少包含系统复位及视频PLL lock失效），并分别在 sys_clk/pixel_clk 域同步释放；不能拿桥自己输出的 `video_reset_done` 回接其 `rst_n`。M3 `video_rst_n` 接桥 `video_reset_done`，扫描模块复位也在 pixel_clk 域同口径；DVI串行侧另外在 serial_clk 域同步释放。视频锁相丢失不可只重置其中一域，否则跨域 toggle 握手可错位；视觉复位不应无故停音频合成。
- **模式切换与曲谱跨域**：若 `mode_toggle_pulse` 起于 sys_clk，使用 toggle/握手或等效保持事件机制送 pixel_clk，不直接跨域连接单拍脉冲；`score_valid + note_id/note_number/hit_frame/duration/velocity` 属多位总线，用握手或经 Gowin 验证的异步FIFO送像素域，数据稳定到成功接收。M3不自行碰 CDC 或正式顶层，M2负责确定物理约束。桥本身64位 bundled-data跨域载荷的物理到达时间必须在独立 PnR 报告中验证；不得把整条总线一概 false-path 后宣称已安全。若证明不了束缚，改厂商异步FIFO。
- **测试及资源**：先在 M2 的 `code/tb/board/` 新增 visual_event_bridge+video_scan_timing+m3_visualizer 联合 TB；模拟两个异步时钟、复位/失锁、事件唯一握手、两来源同音及松键、队满失步、帧切换模式、曲谱默认linger端点。再于独立 Gowin 工程合成/PnR渲染器，记录 Logic/FF/DSP/BSRAM 与 25MHz像素/125MHz串行/50MHz系统各关键路径。`visual_scene_renderer.sv` 内除法、取模、乘法及 score_tracker 多位计算可能形成面积/像素路径风险，必须用实际报告决定是否由 M3 优化常量查表或预计算；本次没有测量结果。
