## 恢复与剩余门禁

SRAM易失且本流程不修改Flash。异常时断电至少5秒后重新上电，即恢复到Flash中原有内容。
60K和138K器件不同，60K码流不得作为138K恢复文件；本项目继续保留独立60K板与工程作为
平台回退，不交叉下载。

实际访问JTAG前只剩简化确认：M3确认核心板为Tang Mega 138K、Dock/外部接线未变、没有
新增5V信号或临时飞线；用户明确授权SRAM-only下载。MIDI键盘和既有外设未变，不要求重新
逐项测量电压。确认前不运行`--scan`或`--program`。

精简证据见`code/docs/evidence/t056_138k_l_sram_release_preparation_20261006.json`。本阶段是
发布准备，不提高V0197的L5等级，不登记L6。
