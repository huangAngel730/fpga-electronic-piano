## 第一阶段：B2 电气与仪器准备，不下载新码流

- 核板上实际型号/底板版本、供电方式、断电状态、固定与临时接线，画连接表并拍清晰照片；对照 138K C/31005 原理图、引脚事实、候选 CST/报告。**断电确认测点导通和测量参考地**，上电后用万用表分别量 Dock `TP21(VCCO_3)`、`TP22(VCCO_4)`、核心 `FB13` 的 VCCIO5 一侧对 GND 的直流电压；`TP23` 先断电核与 VCCIO5 测点的导通关系。记录仪表型号、档位、测点/地夹、实测值、上电状态、时间、照片与板版本。CST 的 3.3 V 声明不能充当 Bank3/4/5 实测；读数异常、测点归属不明立即停，交 M2 核对，不自行改 Bank、CST 或电源。
- MIDI 先确认适配器来源及输出类型、外设供电、FPGA I/O Bank 容限。**接 FPGA 前**用示波器在拟接 FPGA 侧测空闲/高/低电平 `VH/VL`、上升下降沿与过冲/下冲，量 FPGA 侧 GND 到 Dock GND 的导通/参考地差，留原始示波器采集、量程/探头衰减/带宽与连接图。未知或 5 V 电平不得直连 FPGA；电平不符先停并给 M2 转换方案及接线影响，不能靠“之前能响”放行。
- 音频确认 PT8211/功放路径、`PA_EN` 有效极性和上电静音状态、左右声道与采集点。DAC 线路输出只接有源音箱/功放输入/音频采集卡，**不直接驱动无源扬声器**；初次测量低音量、限流/监看削波与直流偏置。记录真实负载阻抗或设备型号、连接与共地，示波器/声卡采样设置。若本次启用 HDMI，另实测 `DVI_DIR_SEL` 为 TX 的方向条件及 `+5VD`，核显示器与差分链路；不由电阻默认值推断，也不为仅音频基础验收强接 HDMI。任何改线先断电、列出涉及引脚/复用、电平与约束影响，交 M2 审核并同步引脚文档。
- 本阶段交 M2 一份测点表、照片、原始电压/波形文件、仪器配置和 PASS/FAIL/待核逐项清单。M3 只提供实物事实和约束一致性复核；M2 负责正式 CST、顶层、CDC/STA 和候选准入。缺任一必要电气事实就保留 `NO_BOARD_RELEASE`。

## 第二阶段：仅在同版放行与用户精确 SHA 许可后 B3 SRAM 上板

**下载双门槛**：先由 M1 在有工具的机器交同源真实 `vlog/vsim` 原日志与退出码，覆盖四音、第五音仍四槽、复位、帧期限 `max_processing_cycles < 834`；M2 核源码/ROM/顶层/CST/SDC/工具、物理网表音频端点及 40 MHz/48 kHz 与 `.fs` 的完整 SHA 对应，审查功能、PnR/STA 和本单电气记录，并书面说明同版放行。然后由**用户单独明确许可该精确 `.fs` SHA** 的 SRAM-only 下载。两项缺一不可；候选 SHA、旧 L 版许可或口头“可以测”均不得推定许可。无已验 138K golden/Flash 恢复事实，禁止 Flash 写入；下载前记录在板原状态/连接/电源，下载后记录所用文件完整 SHA、工具/命令、目标器件、方式、时间和退出码。失败保留原日志、停用该版本，不擅自更换码流或反复烧写。

获准后在**同一 `.fs` 与同一接线**上逐项实测：

1. 输入真实 MIDI Note On/Off、力度、音高/和弦/触发，四个独立可控声部同时可闻，逐键释放、第五音抢占与复位；记录事件、活跃数和声学结果。赛题至少两维必须分别有自研采集/映射链路及实际独立控制的证据，外购 MIDI 键盘自带 Velocity 不自动算作本项目自研两维；若第二维尚未落实，标“待验”，由 M3 给 M2/M1 列出接口和接线影响，不自行扩顶层。
2. 用逻辑分析仪量 I2S `BCLK/LRCLK/DIN` 比例、左右槽/数据相位和实际采样率；示波器/音频采集卡量 PT8211 左右模拟声道、失真/削波/静音及功放负载。记录探头位置、采样率、触发条件、原始轨迹和音频原件，确认 48 kHz，不能把数字输出代替模拟发声。
3. 输入事件边沿与**模拟输出起音**用同一时间基准双通道采集，至少覆盖轻/重力度、单音/和弦、不同输入场景及复位后恢复，记录每次端到端延迟和最大值；只有实测最大值 `≤10 ms` 才宣称赛题基础达标。若测点/起音阈值或时间基准不明确，保留原波形并列待核，不能用帧预算或软件回放替代。
4. T052 用当前正式采用的 N 路已知、充分分开的**纯正弦**测试频点采集同版原始模拟音频及 FFT 设置/谱峰截图，实数出 N 个独立峰，连同 `active_voice_count`、`clip_count` 和 RTL 无预录链路证据交 M1/M2 核；实际 N 与输出采样率乘积按实报。谐波峰不算独立振荡器；测试模式未接同版码流则 T052 实物保持待验。

各项写明同一码流 SHA、固件/工程输入 SHA、板/仪器型号、命令和原始双流/退出码、实际 PASS/FAIL、L0–L7 **实际达到**等级与未验项。上板声学/FFT 是实物层证据，离线 L5 不冒充 L6；出现 Bank/电平、时序、音频异常先停，按电源与时钟→复位→引脚约束→协议相位→PCM 格式→算法结果定位，保留首个失败原件。M2 核身份和准入，M1 核音频/纯正弦算法，M3 交原始采集与操作视频。

## 第三阶段：基础出口以后按序做最小拓展

以 B1–B3 基础同版通过、10-18 时间预算及 M2 对**每个新接入版本**的功能/完整 STA/电气/精确 SHA 重新放行为前提；新码流仍逐版取得用户对精确 SHA 的 SRAM 下载许可。任何拓展不能借基础版 `.fs`、60K L6 或旧候选报告升级等级。

1. **第一项：现有双滑块上飘/下落最小实屏。** M3 先用既有视觉 RTL/40 MHz 视频方案记录上飘按键长条、松键上移，下落音符连续移动与退出，模式切换与复位、同版音画共存及显示视频时序；拍连续实屏原件并交触发/同步轨迹。60K 旧上飘仅限定 L6，旧下落显示记录的**命中闪光时机/效果 FAIL** 原样保留；首轮**暂缓修命中闪光**，标“已知失败／本版未验”，不得称下落完整交互或双模式整机通过。M2 接入模式入口、CDC/完整 STA/下载门禁；M1 检查音频帧/欠载未退化。若入口需改公共接口先走受控变更，不在 M3 写集直接改。
2. **固定真实波形**：复用已有候选，仅冻结左声道、既定区域和窗口做一版实屏与声音共存原始证据；不增加菜单、缩放、双声道切换、频谱或李萨如。
3. **最小传谱**：一份真实来源文件经手机/有线链路送 FPGA，核原文件 SHA、来源/授权、传输命令/原日志、真实 ACK、RAM 完整逐条 READ 与至少一份错误拒收；成功只签存储与读回，不写“自动播放”或 BLE 已实物通过。网上 MIDI 缺件先补包再核，不把合成离线日志当实物。
4. **最高稳定 N**：N32 为单一主候选，8/16 是调试关卡；只对实际通过的同版功能、833 拍期限、资源/PnR/完整 STA 和 N 路纯正弦谱峰报最高稳定 N。达不到 32 如实写 N，保持 48 kHz，不开三套并行架构。
