# 音频算法岗位规则

负责人：M1 音频算法、验证与竞赛交付负责人。岗位定义见 `code/docs/角色分工.md`。

## 主责范围

- DDS、波表、音色合成。
- ADSR、实时变调和表情参数应用。
- 复音管理、声部状态、混音、限幅。
- 延迟、合唱等数字效果器。
- PCM 数据格式、位宽和舍入策略定义。
- Python 黄金模型与逐样本验证。

## 写入范围

- `code/rtl/audio/`
- `code/rtl/synth/`
- `code/rtl/voice/`
- `code/rtl/mixer/`
- `code/rtl/effects/`
- `code/model/`
- 对应的 `code/tb/` 和 `code/docs/test/` 文件

## 与 M2 的边界

- I2S 数字发送位于 `code/rtl/audio_out/`，归 M2 负责；M1 只提供 PCM 接口约定和位宽要求，并复核其数据相位与符号扩展是否符合模型。
- 数字效果器的跨采样率切换和跨时钟域部分由 M2 参与实现。

## 约束

- 不直接读取具体琴键或传感器信号，只接收统一演奏事件。
- 定点格式必须写入模块注释和接口文档。
- 不用低位截断替代饱和限幅。
- 音频核心修改必须通过 Python 逐样本比较。
- 修改公共事件、PCM、时钟或复位接口前停止并提案。
- 软件任务积压时按 D010 由 M2 分担实现，但算法数学定义和最终验收仍由 M1 负责。
