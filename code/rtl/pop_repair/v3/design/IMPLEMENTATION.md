# V3 隔离低音研究候选：实现交接

日期：2026-10-02；实现者：主对话3。源码只在 `v3/source`，研究输出只在 `v3/design`。
结论：**候选可供独立整链验证，但没有证明低音拍频修复成功，不满足听感验收。**
没有改旧版本、正式共享文件、引脚、时钟或电压；没有提交/推送、安装、下载 SRAM 或写 Flash。

## 基线与功能边界

构建基线是当前正式 V1，仓库 HEAD `427f3d33d6559e83b31e7e5347993db7dc4fa124`。
复制来源与 SHA 见 `input_manifest.json`。不是旧 `54774f1` 整机基线。
正式 V1 的四声部、当前 CC64 路由/分配器、力度平方律、ADSR、PCM24 混音、
PCM24→16 截位、LSBJ、复位和正常七字段 STAT 均不由本候选修改。
当前正式顶层没有 HDMI/DVI TX 实例；本 V3 不引入 HDMI，不能声称音画共存或 HDMI L6。
若另一项目含 HDMI，不能直接混用，需主控另行批准集成与基线。

V2 对照只移植旧 V2 的 10/7/5/1 分音 ROM、各 lane 符号和起音时长策略，
**使用同一当前正式 ADSR 参考**；不是旧 V2 整机 fs 的精确还原。
V2 起音时长已核实为 `max(0, base - lane*48)`，不是加号。
旧 V2 fs SHA：`b12120e53fcee5a2a48229245f4ea608ce3b7b5b96e0d5935b75fc7446cd1e8d`。
V1 历史 `083a07e` fs SHA `5944a031bc3d533c77ad801d4b63b1783c355e9874138db07278f11c2cf841c1`

## 原理与研究来源

[Julius O. Smith III, Piano Synthesis / Physical Audio Signal Processing](https://www.dsprelated.com/freebooks/pasp/Piano_Synthesis.html)
说明弦阻尼具有频率依赖性，较高频分量衰减较快，模型切换应渐变而不是突然切除。
[Bank 与 Sujbert, DAFx 2002, On the Nonlinear Commuted Synthesis of the Piano](https://www.dafx.de/paper-archive/2002/DAFX02_Bank_Sujbert_piano_synthesis.pdf)
提供钢琴物理/交换合成研究背景；**不是“消拍成功”的证据**。
本实现是受上述原则启发的低成本谐波信号模型，不是复现其完整物理模型。
系数未从实录钢琴拟合，不能称真实钢琴参数或已验证成功案例。

相邻等程律音的基频差不可因换音色而消失：C1/C#1 约 1.94Hz，C2/C#2 约 3.89Hz。
教材中的弦刚性非谐性有物理依据，但没有本项目实测弦参数，故本候选不擅自加入
失谐、随机相位、基频拉偏、立体声抵消、丢音或动态压低其中一个声部。

## 实际算法

- 研究键区：FCW ≤19685267，即不高于约 220Hz（MIDI 21..57 在钢琴范围内）。
  更高音严格走复制的正式 V1 振荡器，不采用探索图中的高音“改善”。
- 12 个**整数谐波**，基频仍是原 FCW；波形表为 1024×16 的 Q15 正弦。
  12 个当前系数与目标系数采用 Q16，额外亮度以移位减法自然衰减到各自底值；
  底值继续受原 ADSR 自然衰减和 Release 控制，没有替换 ADSR。
- 较高次分音额外衰减较快（额外分量时间常数约 0.085..5.46s）。这是设计值。
  力度仍经正式增益 ROM；额外亮度有 1/2、3/4、全量三个力度档。
- `amplitude += ceil((target-amplitude)/64)` 的双向平滑，等效约1.33ms。
  Note On 只重新激励目标，不重置当前系数或相位，避免重触发时立即切波形。
  不声称声部抢占或跨220Hz键区切换已无点击；这些需整链压力测试。
- 所有谐波 FCW 采用36位中间量并限制20kHz；基频与相位仍32位。
  相位求 k 倍用显式移位/加法。当前低音区最高设计分音为约2640Hz。
- 幅度不是随意减小来使拍动变轻。生成器枚举所有谐波 ROM 地址变化边界，
  对任意独立系数处于 floor..initial 的组合求严格上下界，再作峰值归一化。
  实际量化边界为 [-8192,8163]，还保留防御性限幅。
  相同峰值并不保证相同 RMS；低音候选仍比 V1 约低4dB，**不能据 raw 更轻判改善**。
  所有 A/B 有单独 RMS 匹配版；试听仍需人耳主观同响。

## RTL 调度与集成方法（主对话2）

保留主对话2的当前正式 V1 `build/baseline_reference` 整机副本；不要动原工程。
用 `source/rtl/polyphonic_envelope_bank.sv` 替换副本中的同名 bank（不要同时编译两个同名模块）。
新增 `source/rtl/piano_dds_oscillator_v3.sv`，保留原 `piano_dds_oscillator.sv`
作为 >220Hz 回退依赖；包括 `source/rtl` 搜索路径以读 `v3_constants.svh`。
正常合成文件列表**不要加入两个 tb 文件**，尤其 bank TB 内有同名 router 桩。

继续设置 `PIANO_TIMBRE_ENABLE=1`。`WAVE_ROM_FILE` **仍指向 V1 四表 ROM**，
不能改成 V3 正弦 ROM，否则高音回退读取错误。
新振荡器参数 `SINE_ROM_FILE` 默认 `source/rom/sine_v3_1024_32767.mem`；
必须在综合/仿真工作目录按此相对路径布置资源。可将资源复制到新构建目录中相同结构，
不得在冻结后改 source。原 ADSR、V1 和 sine-only 所需 ROM 按正式目录保持。
Icarus 自检从 V3 根执行，ADSR 通过 `+VELOCITY_ROM_PATH` 使用 baseline 中的副本。
Gowin 正式集成请核对其实际运行目录和 readmemh 成功，而非假设路径已生效。

新振荡器 tick 后37个 sys_clk 完成样本；bank 在 tick 后41拍快照。
新增40拍 cooldown；frame_tick 取消结果但不回滚 DDS 状态，后续请求在
WAIT_DISPATCH 等待 cooldown=0，防止尚未完成时再次触发。公共握手/端口未改。
正常1041/1042拍一帧，理论预算有余量；**不是50MHz综合/时序收敛证据**。

估算增量：每 lane 一份16Kbit sine ROM、一个16×17乘法器、24×32位系数寄存器，
四 lane 大约新增4份ROM、4个乘法器和约3.5K寄存器；映射取决于 Gowin。
原 V1 回退仍占资源。没有实测综合资源或 Fmax，不能用估算替代报告。

## 实际已执行的验证

Python运行时：本机 bundled Python；NumPy2.3.5；不依赖SciPy。
Icarus：现有 `D:/Gowin/oss-cad-suite`；环境仅加载到子进程。

1. 模型自检：88键 FCW 误差最大0.000468919cent；相位连续、系数区间、
   12分音量化全相位界限、重触发不跳当前系数通过。
2. 振荡器 RTL：MIDI21/24/36/48/57，每组2048样本，共10240个整数样本完全一致；
   每组包含1000样本处轻力度重触发及末尾复位。日志 `model_results/rtl_note*.log`。
3. bank RTL：128个精确提交波形，129次推进（1次取消）、请求ID、背压和复位通过。
   **router是明确的桩**，不是allocator/CC64/整机功能证明。日志 `bank_latency.log`。
4. 五组同包络模型WAV及RMS匹配版，见 `model_results/candidate_diagnostics.json`。
   它是静态lane、FLOAT正式ADSR参考、诊断PCM16模型，**不是完整PCM24整机黄金**。
