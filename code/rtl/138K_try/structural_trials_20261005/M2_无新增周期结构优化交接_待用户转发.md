## E 的核心结构

保留原优先树、最新值捕获、CC1 取消及轮询规则，把“授权后动态索引清位、当前解析动态索引置位/取消”的回写转成各固定槽位独立计算，再于原上升沿更新原有 `control_pending`。

```systemverilog
for (genvar slot = 0; slot < 32; slot++) begin : g_pending_next
    wire parsed_here = parsed_control && (parsed_control_index == 5'(slot));
    wire granted_here = grant_control && (selected_index == 5'(slot));
    assign control_pending_next[slot] =
        (parsed_here ? parsed_control_keep_pending : control_pending[slot]) &&
        !granted_here;
end
// 放进原来的 scheduler always_ff；不是新增一级寄存器。
// if (!rst_n) control_pending <= '0;
// else control_pending <= control_pending_next;
```

同时删除原来该 always_ff 内的动态索引 `control_pending[selected_index]` / `control_pending[parsed_control_index]` 写入，避免多驱动。其它 cooldown、锁定事件、pending_value、已接受值、RR 更新保持原逻辑。

优先级必须严格保持：当前字节覆盖旧 pending 状态；同槽位授权已捕获最新值时清除该槽；CC1 返回同项目锁定/已接受值时取消暂存变化，不改变不可变的锁定事件。

这个方法区别于先前 B：只改 pending 回写，不引入宽 one-hot 选择掩码、逆旋转或额外前馈状态。F 是另一个独立实验：绝对槽位后半/前半优先树替代桶形旋转和 RR+rank 加法，同样不加寄存器、不增加周期。
