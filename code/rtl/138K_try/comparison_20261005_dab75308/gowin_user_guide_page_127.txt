-route_maxfan   
Sets maximum fanout for routing. 
Syntax 
-route_maxfan <value> 
Usage 
Name 
Description  
< value> 
Sets maximum fanout for routing. 
Type 
Project 
Description  
Based on routing optimization, this option is used to set the maximum 
fanout for routing. The value should be an integer greater than 0 and less 
than or equal to 100. For GW1NZ-1/GW1N-2/GW1NR-2/GW1N-1P5 
devices, the default value of this option is 10, while for other devices, the 
default value is 23. 
Parameter 
<value>: Sets maximum fanout for routing. 
Example 
set_option -route_maxfan 60 
-correct_hold_violation  
Automatic hold violation fixing for routing. 
Syntax 
-correct_hold_violation <0|1> 
Usage 
Name 
Description  
<0|1> 
0: Do not automatically fix hold violations during routing. 
1: Automatically fix hold violations during routing. 
Type 
Project 
Description  
Enabling this option allows automatically fixing hold timing violations 
during routing. The default value is 1. 
Parameter 
<0|1>: Enable control for automatically fixing hold timing violations 
during routing
