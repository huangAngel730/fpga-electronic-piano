After selecting an Error or Warning message reported by PnR, 
right-click and select "Help" or press the shortcut key "F1", the "GOWIN 
Help" of this error or warning will pop up, and the help information of this 
error or message will be described in details in the document. Some 
common warnings or errors are shown in Table 3-1, and help documents 
can be viewed by clicking "Help > View Help", which supports Chinese and 
English versions.
