8.3.14 saveto 
Saves project data to a tcl script. 
Syntax 
saveto [-all_options] [-h/--help] <file> 
Usage 
Name 
Description  
[-all_options] 
Saves all option information 
[-h/--help] 
Displays help information 
<file> 
The file to be saved 
Type 
Project 
Description  
Saves the current project design data to a tcl script. For the file path 
format, see 8.3.1 add_file. 
Parameter 
 [-all_options]: By default, the saveto command only saves the modified 
options, i.e., those different from the default values. By using 
-all_options, all option information will be saved. 
 [-h/--help]: Displays help information. 
 <file>: The file to be saved.
