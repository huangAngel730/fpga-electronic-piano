6.4 Timing Report 
The timing report performs a thorough analysis of the timing model in 
the circuit netlist, calculates the timing path delays in the circuit, and 
determines whether they are met the requirements. The Timing report 
includes setup check, holdup check, restoring and removal time check, Min. 
clock pulse check, max. fanout path, Place & Route congestion report, etc. 
by default, and provides the Max. frequency report. 
Double-click "Timing Analysis Report" in the Process View to open the 
timing analysis report for the project, as shown in Figure 6-4. 
Note! 
For the details, see SUG940, Gowin Design Timing Constraints User Guide.

6.5 Power Analysis Report 
The Power Analysis Report mainly includes the power consumption 
estimation for your design. It is designed to help you evaluate the basic 
power consumption of your design.
