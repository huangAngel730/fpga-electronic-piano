8.3.11 rm_file 
Removes design files. 
Syntax 
rm_file [-h/--help ] <files> 
Usage 
Name 
Description  
<-files> 
Design files to be removed 
[-h/--help] 
Displays help information 
Type 
Project 
Description  
Removes design files; and for the file path format, see 8.3.1 add_file. 
Parameter 
 <-files> Specifies the design files to be removed. Multiple files can be 
specified, separated by spaces. 
 [-h/--help]: Displays help information. 
Example 
rm_file a.v 
rm_file a.v b.v c.v 
rm_file D:/gowin_project/top.v 
rm_file D:\\gowin_project\\top.v
