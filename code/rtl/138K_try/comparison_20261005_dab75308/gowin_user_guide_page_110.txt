8.3.18 set_csr 
Specifies the CSR file. 
Syntax 
set_csr [-h/--help ] <file> 
Usage 
Name 
Description  
<file> 
The CSR file to be specified. 
[-h/--help] 
Displays help information 
Type 
Project 
Description  
Specifies the CSR file. For the file path format, see 8.3.1 add_file. 
Parameter 
 <files>: Specifies the CSR file. 
 [-h/--help]: Displays help information. 
Example  
set_csr a.csr 
set_csr D:/gowin_project/a.csr 
set_csr D:\\gowin_project\\a.csr
