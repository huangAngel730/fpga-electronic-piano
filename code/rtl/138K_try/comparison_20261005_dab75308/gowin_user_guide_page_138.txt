9 Tcl Commands 
8.3 Command Description 
 
SUG100-4.4.2E 
127(145) 
 
Syntax 
-loading_rate <value> 
Usage 
Name 
Description  
<value> 
The loading speed of bitstream data from Flash to SRAM 
in AutoBoot and MSPI configuration modes. 
Type 
Project 
Description  
The loading speed of bitstream data from Flash to SRAM in AutoBoot 
and MSPI configuration modes, and the default value is 2.500MHz. 
Parameter 
<value>: The loading speed of bitstream data from Flash to SRAM. 
Example 
set_option -loading_rate 21.000MHz 
-seu_handler   
Enable Single Event Upset (SEU) handler. 
Syntax 
-seu_handler <0|1> 
Usage 
Name 
Description  
<0|1> 
0: Disables SEU handler. 
1: Enables SEU handler. 
Type 
Project 
Description  
Enables SEU handler, and the default is 0. 
Parameter 
<0|1>: Enable control for SEU handler. 
Example 
set_option -seu_handler 1 
-seu_handler_mode   
Selects the mode for booting or stopping the SEU Handler. 
Syntax
