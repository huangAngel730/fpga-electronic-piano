4 Gowin Software Usage 
Gowin Software supports interface mode and command line mode. 
For command line mode, please refer to 8 Tcl Commands.  
Take Gowin Software in Windows10 as an example to introduce how 
to use the software. 
4.1 Create a New Project 
1. From the File menu, choose "File> New…" to open the "New" dialog, 
as shown in Figure 4-1. 
Figure 4-1 Create a New Project 
 
Note!  
There are three ways to open a "New" dialog: 
 
Use the "Ctrl+N" shortcut. 
 
Click the "New File or Project" icon in the toolbar. 
 
Click "Quick Start > New Project" on the Start Page. 
2. Select "FPGA Design Project", and then click "OK" to open "Project 
Wizard", as shown in Figure 4-2.
