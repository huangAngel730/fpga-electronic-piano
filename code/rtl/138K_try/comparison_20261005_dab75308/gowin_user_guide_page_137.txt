9 Tcl Commands 
8.3 Command Description 
 
SUG100-4.4.2E 
126(145) 
 
-i2c_slave_addr  
Sets I2C device address. 
Syntax 
-i2c_slave_addr <value> 
Usage 
Name 
Description  
<value> 
Sets I2C device address. 
Type 
Project 
Description  
Sets the I2C device address, and the configurable range is from 00 to 
7F. The default is 00. 
Parameter 
<value>: I2C device address. 
Example 
set_option -i2c_slave_addr 2F 
-secure_mode   
Enables secure mode. 
Syntax 
-secure_mode <0|1> 
Usage 
Name 
Description  
<0|1> 
0: Disables secure mode. 
1: Enables secure mode. 
Type 
Project 
Description  
Enables secure mode, and at this time the JTAG pins are used as 
GPIOs; the bitstream file can only be programmed into the device once. 
The default is 0. 
Parameter 
<0|1>: Enables control for secure mode. 
Example 
set_option -secure_mode 1 
-loading_rate   
The loading speed of bitstream data from Flash to SRAM in AutoBoot 
and MSPI configuration modes.
