# M2 可视化槽位缩减与 PR1014 时钟布线评估（2026-09-28）

**结论：把 M3 原版画面封装的同时活动槽从 8+8 缩为 1+1，资源和最差路径明显改善，但 25 MHz 像素时钟仍不收敛。`PR1014` 未解除，不应为消除警告擅改 V22 时钟引脚。** 这是 M2 的独立合成探针实验，未改变 M3 RTL、正式电子琴工程、公共接口或任何正式 CST；两个探针 `.fs` 都不可下载。真实报告及输入 SHA-256 在 `code/docs/evidence/visual_slot_sweep_20260928.json`，Gowin V1.9.11.03 Education，GW5AT-LV60PG484AC1/I0。

## PR1014 核对

本机 `IDE/doc/EN/SUG937-1.1E_Gowin Software User Messages Reference.pdf` 中 PR1014 说明：Gowin Router 在时钟路由看到通用布线时会发出警告，可能增加时钟延迟/偏斜；其示例是把时钟放到了非时钟端口。本仓库的实际 Pinout 报告 `sys_clk` 为 V22/Bank 7、功能 `EMCCLK`、LVCMOS33/3.3 V；`code/docs/板级硬件事实.md` §3.3 证实板载 50 MHz 有源晶振连接 V22，不能为了消警告移走该引脚。蓝灰独立链路报告在相同时钟/引脚下 Setup/Hold/Recovery/Removal 为正，只证明**该小设计**的 STA；加入 M3 画面后 `PR1014` 仍在，但主要可视化失败为像素逻辑时序。当前也没有 PLL 实物锁定、时钟抖动或 HDMI 信号质量证据，警告继续标为**待实测/待工具约束论证**，不能宣称无害或已经消除。

工具中的 50/125/25 MHz 时钟必须保持真实频率，不能改 SDC 去获得假余量；也不能改正式时钟管脚/Bank 电压。后续若认为需要专用时钟资源，先依据本板原理图、Gowin 时钟指南与本机 Pinout 逐项论证，再通过独立实验与实屏验证；正式约束属于受控接口组。
