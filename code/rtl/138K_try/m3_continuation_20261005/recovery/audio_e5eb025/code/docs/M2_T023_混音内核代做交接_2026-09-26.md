## 文件与接口

- `code/rtl/mixer/pcm_mixer_4voice.sv`：两个输入各 96 位，`[24*i +: 24]` 是第 `i` 路（i=0..3）有符号 24 位 PCM；左右各 32 位有符号累加，输出 `mixed_left/right` 为饱和后的有符号 24 位 PCM，另输出 `clip_left/right` 与 `clip_any`。该模块**纯组合**，没有时钟、复位、`pcm_valid/ready`、流水线代次或状态计数器。
- `code/tb/mixer/generate_pcm_mixer_vectors.py`：按 M1 `code/model/mixer.py::mix_voices()` 生成 3008 组左右独立、逐样本参考向量，其中 8 组边界和 3000 组种子固定的随机压力用例。覆盖 0、单声部工作点 2097152 的 4 路正限幅（8388608→8388607）、四路负边界刚好 −8388608、不削波上下边界、负向溢出、左右削波不一致、正负抵消等。
- `code/tb/mixer/tb_pcm_mixer_4voice.sv`：逐帧比对 PCM 与三个削波标志，字段缺失或样本数非 3008 时自动 FAIL。
- `code/scripts/run_t023_mixer_sim.ps1`：在仓库根目录运行；将 RTL/TB 和生成向量置于 ASCII 临时目录，以 Gowin OSS CAD Suite iverilog/vvp 验证，任一步错误非零退出。
