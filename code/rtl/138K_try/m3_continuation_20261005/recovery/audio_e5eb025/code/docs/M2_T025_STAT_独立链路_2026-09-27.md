# M2 T025 合成四路 PCM 到七字段 STAT 独立链路（2026-09-27）

范围：M2 状态通道的独立黑盒集成自检，**不改电子琴正式顶层、M1 声部实现或上位机**。`STAT` 只在 testbench 中用已支持的 `uart_status_reporter.CLIP_COUNT_VALID=1` 输出，正式顶层仍是 `DIAG clip_count=0x--------`；此结果不能作为 T026 真串口 CSV 或 FPGA 板级完成证据。

## 可复现检查

仓库根目录执行 `.\code\scripts\run_t025_stat_chain_sim.ps1`。脚本把既有模块复制到 ASCII 临时目录，编译并运行：合成四路 PCM → `pcm_mixer_4voice` → `pcm_result_hold` → `pcm_frame_buffer` → `pcm_clip_counter` → 七字段 `uart_status_reporter` → 真实 `uart_rx` 字节解码。接收结果与两条固定 CRLF 行逐字节比较，同时断言提交数和削波数。

**本次结果**：`tb_t025_stat_chain` 两条完整 213 字节 `STAT`、15项检查 PASS（L2）；第一条快照 `clip_count=0x00000002`，报告发送途中追加第三组真实 PCM 提交后第二条 `clip_count=0x00000003`；左、右及同时双声道削波各按组计一次，PCM 提交数3，首行不会因发送途中变化而污染。UART速率为 TB 的 1MHz/100k 8N1 加速配置；正式 50MHz/115200 字节时间由已有 `tb_uart_status_baud` 单独覆盖。`event_fifo_*` 与 `active_voice_count` 在本TB是显式测试常量，`audio_underrun` 来自实际帧缓冲；没有模拟真正四声部事件、波表或 ADSR。
