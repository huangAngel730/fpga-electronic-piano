## 一、M2复核问题修正状态

### 1.1 ✅ Release重触发平滑过渡（已修正）

**问题**: Release中途重触发电平从6533跳变到54（跳变6479 LSB）

**修正**: `code/model/adsr_piano.py`
```python
def note_on(self, velocity: int = 1023):
    # Release重触发：保持当前电平作为Attack起点
    retrigger_start_level = self.level if self.state == 'RELEASE' else 0.0
    
    self.state = 'ATTACK'
    self.level = retrigger_start_level
    self.velocity_gain = velocity_to_gain(velocity)
    # 计算从当前电平到目标增益的步长
    self.attack_delta = self.velocity_gain - retrigger_start_level
```

**验收结果**:
- M2验收工具: `python code/tb/board/check_t009_envelope_transition.py`
- **PASS T009**: Note Off, retrigger and Release tail continuity
- Note Off平滑性: 13066→13063（3 LSB，< 4门槛）
- Release重触发: 6533→6560（27 LSB，< 138门槛）
- Release尾部: 归零且IDLE

**修正前后对比**:
| 项目 | 修正前 | 修正后 | 门槛 |
|------|--------|--------|------|
| Release重触发跳变 | 6479 LSB | 27 LSB | 138 LSB |
| Note Off跳变 | 3 LSB | 3 LSB | 4 LSB |
