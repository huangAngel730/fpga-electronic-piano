## 数学规则

- 波表源数据幅度先遵守D028：未调制的声部波形峰值±8192。当前DDS的32767波表不能直接当作8192波表；需要使用已核对的8192幅度参考表或经M1定义的映射，不能擅自将算术右移2位当成等价。
- 包络取0..32767整数Q15，以32768为分母，不进行32767归一化。
- 16位波形为有符号；包络零扩展到17位有符号正数；乘积显式使用33位有符号。
- 声部16位整数样本：`floor(wave_sample * envelope / 32768)`，等价于有符号乘积`>>>15`。
- PCM24：将上述整数样本左移8位；不保留该次乘法的小数低位。
- 满包络正波峰8192得到8191，PCM24为2096896；负波峰-8192得到-8192，PCM24为-2097152。
- 半包络16384：8192得到4096；包络0或波形0时输出0。
- 混音仍采用至少32位累加及24位饱和；DAC 24→16位的既定舍入/饱和不改。

## 冻结规范与测试影响

接口规范4.3需明确原2097152/8192描述的是未调制波表标称幅度；包络后正峰值允许损失一个16位LSB，负峰值不变。四路包络后正峰值8387584不再触发原“8388608超过正满幅1LSB”例子的削波，相关正常音色向量必须重算。削波模块仍接受完整PCM24输入，独立超限向量用来验证饱和和clip_count；不得为演示计数非0改动自然演奏增益。

不修改采样率、时钟、位宽、事件接口、顶层端口、CST引脚、电平或包络时间曲线。M1确认的<=138 LSB限制适用于Attack/重触发；不把它扩展到最终PCM跳变或认定爆音已经消除。
