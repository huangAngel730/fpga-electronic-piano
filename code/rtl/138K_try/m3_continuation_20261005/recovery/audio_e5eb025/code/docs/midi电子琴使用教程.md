# MIDIPLUS X4 III MIDI 键盘使用教程

更新日期：2026-09-22  
适用设备：MIDIPLUS X4 III（X 系列第三代，49 键）  
依据：[MIDIPLUS 官方《X 系列第三代用户手册》V1.0](https://file-web.midiplus.com/upload/202109/07/X%E7%B3%BB%E5%88%97%E7%AC%AC%E4%B8%89%E4%BB%A3%20%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8CV1.0_210906.pdf)。下面是按初学者的使用顺序整理的操作说明，不是说明书全文。

## 先弄清楚：它怎样发声？

X4 III 是 **MIDI 控制键盘**。按琴键时，它把“哪个音、按得多重、何时松开”等信息发给电脑、音源或你的 FPGA 电子琴系统；声音由接收设备产生。**只给 X4 III 通电、单独按琴键，不等于已经有声音。**

你现在的 5 针 MIDI 线和转换头尚未到，可以先用 USB 线把键盘连接电脑，熟悉按键和观察 MIDI 数据。之后再进行 FPGA 实物联调。

## 一、先认识接口和操作件

| 位置 | 名称 | 通俗理解 |
| --- | --- | --- |
| 后面板 | USB | 给键盘供电，同时向电脑传输 MIDI 数据。 |
| 后面板 | MIDI OUT（5 针） | 把 MIDI 信息送往外部设备的 MIDI IN；这是输出，不是音频口。 |
| 后面板 | 延音踏板接口 | 接延音踏板；不接也能弹琴。 |
| 后面板 | 表情踏板接口 | 接表情踏板；不接也能弹琴。 |
| 上面板 | X 旋钮和三位显示屏 | 转动、按下旋钮可选择和确认设置；显示屏会给出简短状态。 |
| 上面板 | ◀ / ▶ 八度键 | 整体提高或降低键盘发出的音区。 |
| 上面板 | TRANS | 配合 ◀ / ▶ 移调。 |
| 上面板 | Pitch / Mod 触控条 | 前者改变音高，后者发送调制控制；效果取决于接收端。 |
| 上面板 | K1～K4、B1～B6 | 可发送控制信息；B1～B6 也可控制录音软件的播放、停止等功能。 |

资料依据：官方手册第 1、2 节。

## 二、今天就能做：用 USB 连接电脑

1. 用 USB 线把 X4 III 连接到电脑的 USB 口。手册说明它由 USB 供电，属于免手动安装专用驱动的 USB 类兼容设备。
2. 等待电脑识别，再打开你使用的 MIDI 监视软件或带虚拟乐器的音乐软件，选择 X4 III 对应的 **MIDI 输入**。实际设备名称以电脑显示为准。
3. 按下一枚琴键，再松开。MIDI 监视软件应能看到相应的按下和松开信息；如果只想听到声音，还需要在音乐软件里加载虚拟乐器，并选好电脑的声音输出。
4. 同时按两个、三个琴键，观察是否出现多组音符事件。松开不同琴键时，也应分别出现对应的结束事件。

**例子：**按住左手一个低音，再按右手两个高音。如果软件能分别显示三个正在按下的音符，说明键盘输入已经工作。它能否发出三种声音，取决于电脑软件或之后的 FPGA 音源，不由 X4 III 单独决定。

**没声音时先分开判断：**如果 MIDI 监视软件能看到事件，但听不到声音，先检查虚拟乐器、音量和电脑音频输出；不要马上认定键盘坏了。

资料依据：官方手册第 2.1、2.7 节。

## 三、最常用的演奏操作

### 1. 换八度

在正常演奏状态，短按 **◀** 或 **▶** 改变整排琴键的音区；同时按 **◀ + ▶** 可快速重置八度设置。

**例子：**你按同一枚实体琴键，按一次 ▶ 后，接收端看到的音会升高一个八度。测试 FPGA 的音符编号时，先把八度重置，免得误以为译码错了。

### 2. 移调

按住 **TRANS**，再按 ◀ 或 ▶ 调整移调。短按 TRANS 可暂时关闭或恢复上一次的移调设置；长按 TRANS 可重置移调。灯亮表示移调已启用，半亮表示保留着移调记忆。

**例子：**若听到所有琴键都比预期高或低，先检查 TRANS 和八度键，再排查音源代码。

### 3. Pitch 和 Mod 触控条

滑动 Pitch 会发送弯音控制，放手后会回到中间；Mod 用于调制，放手后保持最后的位置。若当前音源没有实现这些控制，触控条有动作但听不出变化也可能是正常现象。

资料依据：官方手册第 2.3、2.4 节。

## 二手 X4 III 首次使用：先核对这些状态

**二手琴的当前设置不一定是出厂值。**下表是为了让第一次电脑/FPGA 音符测试有一个明确的起点；“建议值”是测试基线，**不是说我已经检查过你手上这台琴**。先只检查“必查”项，不需要一上来恢复出厂设置。

| 优先级 | 项目 | 首次测试建议值 | 怎么确认或设定 |
| --- | --- | --- | --- |
| 必查 | 设置模式 | **退出**，屏幕不再闪烁 `SEL` | 若正在闪 `SEL`，长按 X 旋钮约 0.5 秒退出。 |
| 必查 | 普通琴键的 `MIDI CHANNELS` | **通道 1** | 进入 `SEL` → 按 `MIDI CHANNELS` 下数字 `1` 对应的琴键；屏幕显示 `C01`，并自动退出。二手琴无法仅凭说明书默认值推断它当前就是 1。 |
| 必查 | `SCALE` 智能音阶 | **OFF** | 进入 `SEL` → 按 `SCALE` 对应琴键，看屏幕当前值；若不是 `OFF`，转 X 旋钮到 `OFF`，短按确认，再长按退出。否则按键与音符编号可能被重新映射。 |
| 必查 | `VEL.` 力度曲线 | **Normal（`nor`）** | 进入 `SEL` → 按 `VEL.` 对应琴键；若不是 `nor`，转 X 旋钮选 `nor`，短按确认，再长按退出。这样便于比较轻弹和重弹。 |
| 必查 | 八度偏移 | **归零** | 在正常演奏状态同时按 **◀ + ▶**；这是手册给出的八度快速重置方法。 |
| 必查 | `TRANS` 移调 | **归零** | 在正常演奏状态长按 **TRANS** 重置。重置后灯应表示移调未激活；不要只短按，因为短按只是暂时关闭或恢复此前的移调。 |
| 建议 | Pitch / Mod 触控条 | Pitch **回中间**；Mod **放到底部** | 放开 Pitch，它会自动回中；手指把 Mod 滑到最下端，因为 Mod 松手后会保持在上次触碰位置。它们是否影响声音仍取决于接收音源。 |
| 建议 | 延音、表情踏板 | **首次测试先不接** | 先用普通琴键验证按下/松开；以后接踏板时再单独测试其作用。 |

**最省事的执行顺序：**插 USB 供电 → 同时按 ◀ + ▶ → 长按 TRANS → 进入一次 `SEL`，依次确认 `VEL.=nor`、`SCALE=OFF` → 按 `MIDI CHANNELS` 下的数字 `1`（设定后自动退出）→ 按一个琴键再松开，观察接收端是否分别收到按下与松开。以后如果发现音高不对，先重新检查八度、移调和音阶。

### 只有准备使用旋钮、B 键或多音色时才核对

下面也是官方手册列出的**出厂值**，但对“先验证普通琴键的音符输入”不是前置条件。二手琴可能已被前主人改过；如果你暂时不用这些控制器，**不必为了凑齐默认值逐项修改**。

| 项目 | 手册列出的出厂值 | 何时需要核对 |
| --- | --- | --- |
| `X MODE` | `PC`（Program Change） | 要用 X 旋钮切换接收音源的音色时；若改为 `cC`，X 旋钮发送 CC7。 |
| `BTN MODE` | `MCU`（Mackie Control） | 要用 B1～B6 控制录音软件时；使用 CC 模式前还要确认接收软件的映射。 |
| `MSB`、`LSB` | 各为 `0` | 要按接收音源说明书选择音色库时；数字本身不对应固定音色。 |
| `ASSIGN CH` | 各控制器为 `00`，即跟随键盘通道 | 要让 K1～K4、B1～B6 或 Mod 单独发往别的通道时；`00` 不是“第 0 通道”。 |
| Mod 的 `ASSIGN CC` | `CC1` | 要用 Mod 触控条控制音源时。 |
| K1、K2、K3、K4 的 `ASSIGN CC` | 分别为 `CC93`、`CC91`、`CC71`、`CC74` | 要测试这四个旋钮时；音源是否响应由接收端决定。 |
| B1～B6 的 `ASSIGN CC` | 分别为 `CC25`～`CC30` | 只有 `BTN MODE` 设为 `CC` 且要测试 B 键控制消息时。 |

**需要分清两件事：**官方手册给出了这些默认值，但不能证明二手琴的当前值；同样，键盘设好也不能证明 FPGA 已实现对应的音色库、CC、弯音或多通道功能。若某项菜单读不懂或显示与表格不一致，先记录屏幕内容，不要盲目旋转保存。恢复出厂会清除前主人留下的全部自定义设置，操作见本教程“恢复出厂设置”一节，**不是首次测试的必做步骤**。

资料依据：[MIDIPLUS 官方《X 系列第三代用户手册》V1.0](https://website-d.midiplus.com/upload/202109/07/X%E7%B3%BB%E5%88%97%E7%AC%AC%E4%B8%89%E4%BB%A3%20%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8CV1.0_210906.pdf)第 2.3～2.7、3.1～3.9 节；以上列出的数值均为手册出厂说明或本教程明确标出的首次测试建议值。

## 四、设置模式：记住一个固定操作套路

长按 **X 旋钮约 0.5 秒**，显示屏闪烁 `SEL`，表示进入设置模式。接下来：

1. 按琴键上方印有目标功能名称的设置键；
2. 转动 X 旋钮选择数值或选项；
3. 短按 X 旋钮确认保存；
4. 长按 X 旋钮退出设置模式。

处于设置模式时，部分琴键暂时是“菜单键”，不是普通演奏键。若发现按键不按预期发音，先看屏幕是否在闪烁 `SEL`。

### 琴键上的设置功能名称有哪些？

找键盘上方印着下列英文名称的琴键；**进入 `SEL` 设置模式后**，按对应琴键才会打开该设置。这里说的是琴键上的功能丝印，不是让你去找一个单独的同名按钮。

| 琴上的丝印 | 作用 | 出厂状态或范围 |
| --- | --- | --- |
| `X MODE` | 选择 X 旋钮在正常演奏时发送音色切换（Program Change）还是 CC 控制信息。 | 默认 Program Change；另一选项为 CC。 |
| `BTN MODE` | 选择 B1～B6 走带按键的工作模式。 | 默认 Mackie Control（`MCU`）；也可选 `HUI`、`CC`。 |
| `VEL.` | 选择琴键对弹奏力度的响应方式。 | 默认 Normal；另有 Fixed、Light、Hard。 |
| `MSB` | 设定音色库编号的 Bank MSB 部分。 | 默认 0，可设 0～127。 |
| `LSB` | 设定音色库编号的 Bank LSB 部分。 | 默认 0，可设 0～127。 |
| `SCALE` | 开关、选择内置智能音阶。 | 默认 `OFF`；可选 16 种音阶。 |
| `ASSIGN CC` | 给 Mod 触控条、K1～K4 旋钮或 B1～B6（CC 模式）指定 CC 编号。 | 编号可设 0～127；需要再操作一下目标控制器，告诉键盘“要改哪一个”。 |
| `ASSIGN CH` | 给上述控制器指定它单独发送 MIDI 消息的通道。 | 可设 0～16；`0` 表示跟随键盘当前 MIDI 通道，不是 MIDI 的“第 0 通道”。 |
| `MIDI CHANNELS` 下的 `1～16` | 选择普通琴键发送音符时使用的 MIDI 通道。 | 默认通道 1；按标有相应数字的琴键选择，选完会自动退出设置模式。 |

#### 每一个功能的实际例子

下面的“发出消息”指键盘把 MIDI 信息送出；**是否真的改变声音，要看电脑软件或 FPGA 音源有没有接收并实现对应功能**。第一次测试 FPGA 时，不需要把九项都设置一遍。

1. **`X MODE`：决定转动大 X 旋钮是在“换音色”还是“调音量”。**例如选默认的 `PC` 模式，转动 X 旋钮会发送 Program Change；如果电脑音源支持，它可能从一种音色切换到另一种音色。改为 `cC` 模式后，旋钮发送 CC7；若接收端把 CC7 当作音量控制，转动时才会改变音量。只改 X4 III 的模式，不会给 FPGA 凭空增加音色或音量功能。
2. **`BTN MODE`：决定 B1～B6 是录音软件的“遥控按钮”还是普通可映射按钮。**例如在支持 Mackie Control 的录音软件里保持 `MCU`，可把这些按键用于播放、停止等走带操作；使用 Pro Tools 时，手册指导切到 `HUI`。如果改成 `CC`，还需要在软件中用 MIDI Learn 给某个 B 键指定动作；FPGA 若未处理这些控制消息，按 B 键可能没有可见效果。
3. **`VEL.`：决定轻弹和重弹怎样变成力度数值。**例如选 `nor`，轻轻按键与用力按键通常会发出不同力度，适合测试 FPGA 是否收到力度变化；选 `fix` 则是固定力度，便于比较音高，但不适合做力度差异测试。选 `lig` 或 `har` 会改变键盘对弹奏力度的响应感觉。
4. **`MSB`：选择“音色库地址”的第一部分。**例如某个电脑音源另有扩展音色库，可以把 MSB 从默认 `0` 改为该音源说明书要求的数值，再配合 LSB 和 Program Change 选音色。只把 MSB 改为 `1` 并不保证听到某种指定乐器；库编号由接收音源定义，当前 FPGA 未确认支持音色库时保持 `0` 即可。
5. **`LSB`：选择同一音色库地址的第二部分。**例如一个音源要求 `MSB=0、LSB=2` 才能选到它的某个扩展库，就分别设置这两个数字，再按该音源要求发送 Program Change。可以把 MSB、LSB 理解成音色库的“两段地址”；`LSB=2` 不等于“弦乐”或任何固定音色。
6. **`SCALE`：让琴键按某种音阶重新排列音符。**例如选择 `cn1`（中国五声宫调式）后，白键会按 C、D、E、G、A 等音阶音重新映射；你按相邻白键，收到的音符不一定再按普通半音关系排列。测试琴键与 MIDI 音符编号的对应关系时，先保持 `OFF`。
7. **`ASSIGN CC`：指定“这个旋钮/按钮发哪一种控制编号”。**例如在设置模式按 `ASSIGN CC`，转动一下 K1 表示要修改 K1，再用 X 旋钮把它设为 `CC7` 并确认；以后转动 K1，若电脑音源把 CC7 用作音量，就能调它的音量。这里改的是**控制编号**，不是让 K1 直接变成音频音量旋钮。
8. **`ASSIGN CH`：指定某个控制器单独把消息送给哪个通道。**例如普通琴键设为通道 1，单独把 K1 设为通道 2：弹琴仍发给通道 1，转 K1 的控制消息则发给通道 2。若把 K1 设为 `0`，它会跟随键盘通道；如果接收端只听通道 1，把 K1 单独设成 2 可能就“转了没反应”。
9. **`MIDI CHANNELS` 下的 `1～16`：决定普通琴键的消息写哪个通道号。**例如进入 `SEL` 后按数字 `2` 对应的琴键，显示 `C02`，之后弹键发送的是通道 2 的音符。若电脑音源把通道 2 分给弦乐，可能听到弦乐；若 FPGA 只接收通道 1，则可能不响。**通道号只是消息标签，不是固定音色，也不是复音数量。**

**例子：**想把力度改成 Light，长按 X 旋钮看到 `SEL` → 按 `VEL.` 对应琴键 → 转动 X 旋钮到 `lig` → 短按 X 旋钮确认 → 长按 X 旋钮退出。想设通道 2，则进入 `SEL` 后按 `MIDI CHANNELS` 下标着 `2` 的琴键，屏幕应显示 `C02`，随后自动退出。音色库、CC 和控制器通道属于进阶设置，第一次接 FPGA 可以先保持默认值。

资料依据：MIDIPLUS 官方《X 系列第三代用户手册》第 2.7 节“键盘”及第 3 节“设置模式”。

### 设置 MIDI 通道

键盘默认 MIDI 通道为 **1**。进入设置模式后，按 `MIDI CHANNELS` 标识下方的 1～16 中某一个琴键，即可选择相应通道；例如按“10”，屏幕显示 `C10`，并自动退出设置模式。

**给你的 FPGA 项目的建议：**首次联调先保持默认通道 1；如果以后接收端支持多通道，再按双方约定修改。不要仅凭键盘显示 `C10` 就假定 FPGA 当前代码已支持通道 10。

### MIDI 通道有什么用？换通道就会换音色吗？

**不会自动换。**可以把一条 MIDI 连接想成一条能同时送 16 类“带编号消息”的线路：通道 1～16 是消息的标签，接收端据此决定由谁来处理。琴键按下、松开、力度，以及部分旋钮控制消息都可以带通道号。通道本身**没有固定的钢琴、小提琴等音色含义**。

音色由接收端的设置决定。例如电脑音源或将来的 FPGA 音源**如果被设计成**“通道 1 用钢琴、通道 2 用弦乐”，那么 X4 III 切到通道 2 后，接收端才可能改用弦乐；如果接收端把所有通道都设成钢琴、只接收通道 1，或完全不区分通道，切换键盘通道就不会得到这个效果，甚至可能听不到声音。接收端若支持 `Program Change`（音色切换）和 `Bank Select`（音色库选择），还可以按其规则选择音色；**发出这些消息并不保证当前 FPGA 代码会处理它们**。

| 情况 | 可能看到的结果 |
| --- | --- |
| X4 III 发通道 1，音源只监听通道 1 | 按键会被音源接收。 |
| X4 III 改发通道 2，音源仍只监听通道 1 | 按键消息仍发出了，但该音源不响应。 |
| 音源分别把通道 1、2 分配给钢琴、弦乐 | 切换发送通道后，可听到对应音色；这是**音源的分配**，不是 MIDI 规定“通道 2=弦乐”。 |

**别把通道数当成复音数：**同一个通道可以同时发送多个音符，例如你在通道 1 同时按下 4 个键，这仍是“一个通道、4 个音符”。接收端能否同时发出 4 个声音，取决于它的复音实现；16 个 MIDI 通道不等于最多 16 个音。

**通道 10 的特别说明：**在兼容 General MIDI（GM）的音源中，通道 10 通常用于打击乐；这属于 GM 音源的规则，**不代表** X4 III 切到通道 10 就一定会发鼓声，也不代表你的 FPGA 必须把通道 10 做成鼓。第一次测试仍建议使用通道 1。

资料依据：[MIDI Association：MIDI 消息与 Program Change](https://midi.org/about-midi-part-3midi-messages)、[多音色音源与 MIDI 通道](https://midi.org/mixing-with-virtual-instruments-the-basics)、[GM Lite 通道 10 规则](https://midi.org/general-midi-lite)；X4 III 通道设置步骤见本教程上节及官方手册第 3.9 节。

### 设置力度响应

进入设置模式 → 按标有 `VEL.` 的琴键 → 转动 X 旋钮选择 `nor`（标准）、`fix`（固定）、`lig`（轻）或 `har`（重）→ 短按 X 旋钮确认。默认是 `nor`。

**例子：**想检验 FPGA 是否正确接收不同力度，先用 `nor`，轻弹、重弹各一次，观察接收端数值是否不同；`fix` 不适合做这一项测试。

### 智能音阶

进入设置模式 → 按 `SCALE` → 转动 X 旋钮选音阶 → 短按确认。默认是 `OFF`。开启后，键盘会重新映射白键的音符，黑键的行为也与普通键盘不同。**测试 FPGA 音符映射时先保持 `OFF`**，以免把智能音阶的结果误判为代码故障。

资料依据：官方手册第 2.7、3、3.3、3.6、3.9 节。

## 五、K1～K4 和 B1～B6 目前可以先不设置

K1～K4 默认发送不同的 MIDI CC 控制信息，例如混响、合唱等；B1～B6 默认是用于音乐制作软件的 Mackie Control（MCU）走带模式，还可以切换为 HUI 或 CC。它们**不是额外的音符琴键**。你眼下先熟悉普通琴键、八度和 MIDI 通道即可。

如果之后要切换 B1～B6 的模式：进入 `SEL` → 按 `BTN MODE` 标识的琴键 → 转动 X 旋钮选择 `MCU`、`hui` 或 `cC` → 短按确认。当前 FPGA 系统是否处理这些控制信息，需要以实际 RTL 功能和联调结果为准。

资料依据：官方手册第 2.5、2.6、3.2 节。

## 六、线材到货后：与 FPGA 电子琴联调

官方手册给出的外部 MIDI 连接方向是：**X4 III 的 MIDI OUT → 接收设备的 MIDI IN**。键盘仍需由 USB 供电；手册示例为连接 USB 5 V 电源，然后用 5 针 MIDI 线输出 MIDI 数据。

你的 FPGA 开发板不能因为存在 GPIO 就直接接 5 针 MIDI 插头。应先确认转换头、接收电路、方向与 FPGA 工程约束均与项目资料一致；未确认前不要尝试裸线直连，也不要猜测引脚或电压。

建议按以下顺序测，每一步通过再进入下一步：

1. 键盘通电，确认显示屏工作，并把八度重置、移调重置、智能音阶设为 `OFF`、MIDI 通道保持 1。
2. 检查接线方向：键盘 **MIDI OUT** 到项目接收电路 **MIDI IN**，不要 OUT 接 OUT。
3. 按一枚琴键再松开：先确认接收端看到了“按下”和“松开”，再检查是否发声。
4. 同时按两枚、四枚琴键：分别确认所有音符都被识别，并在松开后结束。
5. 轻弹与重弹同一琴键：检查力度信息是否到达；声音大小是否变化取决于 FPGA 音源有没有实现力度处理。

**例子：**按住三个不同的音，接收端若能看到三条独立的按下信息，之后逐个松开也能分别看到结束信息，说明这轮 MIDI 输入链路的基础测试通过。它不自动证明整套音频输出和 32 复音扩展均已通过。

## 七、常见问题速查

| 现象 | 先检查什么 |
| --- | --- |
| 显示屏不亮 | USB 线是否插稳、电脑或电源口是否供电；换一根已知能传数据的 USB 线试试。 |
| 电脑上能看到 MIDI 事件，却没声音 | 是否加载虚拟乐器、音频输出设备和音量是否正确。 |
| 听到的音区整体不对 | 先同时按 ◀ + ▶ 重置八度，再检查 TRANS 是否启用。 |
| 按琴键进入功能菜单 | 屏幕是否显示 `SEL`；长按 X 旋钮退出设置模式。 |
| FPGA 收不到音符 | 先检查 MIDI OUT→MIDI IN 方向、键盘供电和接收电路；再检查双方通道及 RTL。不要猜测电气连接。 |
| 能收到数据却不响 | 分开检查 MIDI 译码、复音分配、合成、DAC/功放和音量；接收数据成功不等于整条发声链路成功。 |

## 八、恢复出厂设置：仅在确有需要时使用

恢复出厂会清除你在键盘上做过的设置，不是一般故障的第一步。官方步骤是：拔掉 USB 使键盘断电 → 同时按住 **B1+B2** → 插上 USB 供电 → 屏幕闪烁 `RES` 数次后松开。执行前先记下自己修改过的 MIDI 通道、力度、CC 等设置。

资料依据：官方手册第 4 节。
