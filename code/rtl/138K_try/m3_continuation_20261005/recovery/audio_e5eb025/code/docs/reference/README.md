# 外部整理稿（只读参考）

本目录存放**由外部工具/他人整理、非本仓库编写**的板卡资料整理稿。
它们与 `code/docs/板级硬件事实.md` 是**两个独立来源**，不是同一份文档的两个副本。

## 为什么单列一个目录

`板级硬件事实.md` 是本项目的**板级事实单一来源**，由本项目自行核对官方 Wiki、原理图、
官方 CST 和引脚事实表后写成，受 `变更与决策流程.md` 管辖。

本目录的文件是**别人整理的衍生稿**。它们的价值在于把同一批原始资料
（`Tang_Mega_60K_30354_NEO_31005_引脚事实表.xlsx` + `tang_mega_60K_pins.cst`）
加工成了"建 RTL / 建约束时可直接查"的形式，省去逐行翻 Excel 的成本；
但**它们不构成本项目的决策依据**。两者结论冲突时，以 `板级硬件事实.md`
和 `技术决策记录.md` 的已冻结决策为准，并把冲突登记到 `风险登记表.md`。

## 已核对的差异（入库时逐条比对）

入库时按"只允许追加、不静默选边"的原则逐条比对了本目录文件与
`板级硬件事实.md` / `技术决策记录.md` / `constraints/electronic_piano.cst`。
**音频链路 4 个引脚完全一致**，是本目录文件最有价值的交叉印证：

| 信号 | 本目录文件 | 本仓库 CST | 结论 |
|---|---|---|---|
| `i2s_bclk` | Y17 / `LVCMOS33` / Bank 7 / J2-26 | Y17 | 一致 |
| `i2s_lrck` | AB17 / `LVCMOS33` / Bank 7 / J2-28 | AB17 | 一致 |
| `i2s_din` | AA16 / `LVCMOS33` / Bank 7 / J2-30 | AA16 | 一致 |
| `pa_en` | AB16 / `LVCMOS33` / Bank 7 / J2-36（低有效） | AB16 | 一致 |

`sys_clk`=V22、`sys_rst_n`=AA13、`uart_tx`=U15 亦一致。
**复位一节与 D018 更正完全吻合**：`sys_rst_n`=AA13 的真名是用户按键
`EX_KEY.0`，`RECONFIG`=N12 才是配置专用，二者不可混用。

### 差异一：`LEDs[0..7]` 的真身（重要，补正本仓库旧记录）

本目录文件明确记录：**官方 CST 的 `LEDs[0]`–`LEDs[7]` 不是底板的 8 颗板载 LED**，
而是官方示例给 PMOD0 八根信号用的顶层别名，相同物理线同时复用为
`SDRAM1_D[0..7]`。来源标注为"用户提供的核对截图"。

| CST 别名 | 60K 球位 | 31005 实际网络 | 同时复用 |
|---|---|---|---|
| `LEDs[0]` | T18 | `PMOD0_IO7` | `SDRAM1_D6` |
| `LEDs[1]` | R18 | `PMOD0_IO6` | `SDRAM1_D7` |
| `LEDs[2]` | R17 | `PMOD0_IO5` | `SDRAM1_D4` |
| `LEDs[3]` | P16 | `PMOD0_IO4` | `SDRAM1_D5` |
| `LEDs[4]` | U21 | `PMOD0_IO3` | `SDRAM1_D2` |
| `LEDs[5]` | T21 | `PMOD0_IO2` | `SDRAM1_D3` |
| `LEDs[6]` | R19 | `PMOD0_IO1` | `SDRAM1_D0` |
| `LEDs[7]` | P19 | `PMOD0_IO0` | `SDRAM1_D1` |

本仓库此前在 `风险登记表.md` 与 `electronic_piano.cst` 注释中把该组信号
描述为"板载 8 路 LED（与 PMOD0/SDRAM1 复用）"。**该描述不准确**：
不存在"板载 8 路离散 LED"这一资源，它是 PMOD0 座子的 8 根 IO。
已在 `板级硬件事实.md` 中更正并注明来源。这不影响本项目任何已定引脚——
本项目不使用这 8 根线。

### 差异二：封装写法 `PBG484A`（按 D018 保持待定）

本目录原文写"FPGA 工程器件已由用户确认：`GW5AT-LV60PG484AC1/I0`，
IDE 显示封装 `PBG484A`、Device Version B"，并在注记中说明
"原理图符号中的 `PG484A` 与 IDE 显示的 `PBG484A` 写法不同……不自行解释为
封装冲突或等价关系"。

但按用户 2026-09-12 的明确指示（D018 第 2 项），`PBG484A` vs `PG484A`
**暂缓核实、标为待定**，故入库时已把该处措辞降级为待核实，
与本仓库口径统一。**首次上板读器件 ID 是确认它的最直接手段。**
原始措辞与本次改动不影响任何引脚或电气属性。

## 使用约定

1. **只读**。不要修改本目录文件的正文；需要更正时，改本仓库自己的文档
   并按 `变更与决策流程.md` 登记，同时在本节追加差异说明。
2. **不作为约束依据**。写 `IO_LOC` / `IO_PORT` 时以
   `code/constraints/electronic_piano.cst` 和官方参考 CST 为准。
3. **不替代 `板级硬件事实.md`**。查板级事实先看后者；本目录文件用于
   补查第 9 节"端口约束总表"这类逐行明细。
4. **其"待用户确认"章节不等于本项目待办**。两份文件的第 12 节列了 12 条
   待确认项，其中与竞赛交付相关的部分已由本项目自行处理（如 I2S 采样率、
   位宽、对齐方式见 D017 与 `模块接口规范.md`），其余按本仓库
   `风险登记表.md` 与 `任务看板.md` 的实际状态跟踪。
