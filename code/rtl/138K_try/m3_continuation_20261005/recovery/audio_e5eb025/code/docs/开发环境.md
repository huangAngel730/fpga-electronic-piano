## 工程路径必须为纯 ASCII

Gowin 的 Tcl 解释器会把路径中的每一个非 ASCII 字符替换成 `?`，因此带中文
字符的工程路径不会被正确打开，而是被报告为"文件不存在"：

```text
project file D:/17/?????/?????????/???FPGA/code/build/... does not exist
```

这不是 gui 与命令行的差异，而是 `gw_sh` 内嵌 Tcl 的编码限制。综合、布局布线、
生成码流和 Programmer 都接收路径，所以必须从根上消除中文路径。

**仓库根目录已迁至 `D:\17\project_17\fpga_gowin`，路径全为 ASCII。**
此前用目录联接（junction）绕过的做法已废弃，不要再重建。

迁移脚本见 `code/scripts/move_repo_to_ascii.ps1`。

## 使用方法

在仓库根目录执行：

```powershell
. .\code\scripts\enter_fpga_env.ps1
.\code\scripts\check_fpga_env.ps1
```

第一条命令需要用点号调用，以便环境变量保留在当前 PowerShell 会话。
