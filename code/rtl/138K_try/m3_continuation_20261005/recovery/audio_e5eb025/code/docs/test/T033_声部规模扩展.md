## 一、扩展目标

---

## 二、算法调整（M1）

### 混音器位宽
- 4复音：26位累加器
- 8复音：27位累加器（+1位）

公式：`ceil(log2(N)) + 24`

### 余量计算
- 4复音：-12.04 dB
- 8复音：-18.06 dB
