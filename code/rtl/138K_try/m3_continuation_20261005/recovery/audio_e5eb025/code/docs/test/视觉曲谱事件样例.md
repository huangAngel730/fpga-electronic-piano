# 视觉曲谱事件样例

版本：v1.0  
日期：2026-09-27  
作者：M1  
任务：T0xx 双模式可视化 - 下落音符曲谱时间轴

## 一 概述

本文档定义钢琴滑块游戏式下落音符的曲谱格式与视觉事件样例，用于验收视觉系统实现。

### 1.1 系统架构

```
曲谱数据 ──→ 视觉参考模型 ──→ 视觉事件（预告/到达/消失）
                              ↓
真实演奏 ──→ FPGA 音频合成    命中判定（Hit/Miss）
```

**关键约束：**
- 曲谱**不触发音频**，只负责视觉预告
- 音频由 FPGA 根据真实演奏事件实时合成
- 视觉与音频独立，通过演奏事件桥接

### 1.2 核心参数（样例值）

| 参数 | 样例值 | 说明 |
|-----|--------|------|
| 预告时间 | 2.0 秒 | 音符提前出现的时间，不是最终规格 |
| 屏幕高度 | 400 像素 | 从顶部到判定线的距离（样例值） |
| 下落速度 | 200 像素/秒 | 由预告时间和屏幕高度计算 |
| 判定窗口 | ±100 ms | 命中判定的时间容差，样例值 |

**硬件环境：**
- 显示器：AOC Q27B35（27英寸 2K IPS）
- 分辨率：2560×1440（2K）
- 刷新率：120Hz
- 接口：HDMI/DP

**注意：** 
- 样例值中的 400 像素仅用于模型验证，不代表最终实现
- 实际屏幕为 2560×1440，判定线位置和下落区域由 M3 根据实际渲染需求确定
- 模型优先保存时间，位置由时间计算，与具体分辨率解耦

## 二 曲谱音符定义

### 2.1 ScoreNote 数据结构

```python
@dataclass
class ScoreNote:
    note_id: int            # 音符唯一标识（用于区分同音重复）
    note_number: int        # MIDI 音符号 (0-127)
    hit_time: float         # 预定演奏时刻（秒），到达判定线的时间
    duration: Optional[float]  # 持续时间（秒），None 表示无 Note Off
    velocity: int           # 力度 (0-1023)，10位线性强度
```

### 2.2 字段说明

- **note_id**: 唯一标识符，即使同音高同时刻也要分配不同 ID（用于和弦、同音重复）
- **note_number**: 遵循 MIDI 标准，60=C4，69=A4(440Hz)，72=C5
- **hit_time**: 音符**应该**到达判定线的时间（秒），是曲谱预定值
- **duration**: 
  - `None`: 只有 Note On，无对应 Note Off（短促音符）
  - `浮点数`: 持续时间（秒），音符将在 `hit_time + duration` 时消失
- **velocity**: 与 `audio_defs_pkg.sv` 中 `performance_event_t` 的 velocity 字段对齐（10位）

## 三 视觉事件类型

### 3.1 VisualEvent 数据结构

```python
@dataclass
class VisualEvent:
    event_type: str         # 'appear', 'arrive', 'disappear'
    time: float             # 事件发生时刻（秒，相对于曲目起点）
    note_id: int            # 关联的音符ID
    note_number: int        # MIDI 音符号
    y_position: float       # 相对判定线的位置（像素），判定线=0，向上为正
```

### 3.2 事件类型

| 事件类型 | 触发时刻 | Y 坐标 | 说明 |
|---------|---------|--------|------|
| `appear` | `hit_time - preview_time` | `screen_height` | 音符出现在屏幕顶部 |
| `arrive` | `hit_time` | `0` | 音符到达判定线 |
| `disappear` | `hit_time + duration` 或 `hit_time + note_linger_time` | `0` | 音符消失 |

**disappear 规则：**
- 有 `duration`：在 `hit_time + duration` 时消失（对应 Note Off）
- 无 `duration` (None)：在 `hit_time + note_linger_time` 时消失（默认 0.5 秒）

**重要：** 曲谱 Note Off 只控制视觉消失，**不向音频核心发送 Note Off 事件**。音频由 FPGA 根据真实演奏控制。

### 3.3 坐标系定义

- **Y=0**: 判定线位置（固定）
- **Y>0**: 判定线上方（音符下落区域）
- **Y<0**: 判定线下方（已错过）

**位置计算公式：**
```
y_position = (hit_time - current_time) × fall_speed
```

## 四 命中判定

### 4.1 HitJudgement 数据结构

```python
@dataclass
class HitJudgement:
    note_id: int            # 音符ID
    note_number: int        # MIDI 音符号
    expected_time: float    # 预期命中时间（秒，绝对时间）
    actual_time: float      # 实际按键时间（秒，绝对时间），漏按为 NaN
    time_error: float       # 时间误差（毫秒），正值=晚了，负值=早了
    is_hit: bool            # 是否命中（在时间窗口内）
```

### 4.2 判定规则

```
time_error = (actual_time - expected_time) × 1000  # 转为毫秒
is_hit = |time_error| ≤ hit_window_ms
```

### 4.3 一对一匹配规则

**核心原则：**
- 一次真实 Note On **最多命中一个**曲谱音符
- 同一曲谱音符**不能被重复命中**
- 窗口内最接近的匹配优先
- 未按音符在 `hit_time + hit_window` 后转为 Miss
- 窗口外的按键记录为 `extra_presses`（误按）

**匹配流程：**
1. 遍历每个曲谱音符
2. 在未使用的演奏事件中查找同音高且在时间窗口内的最接近匹配
3. 找到匹配：标记为 Hit，演奏事件标记为已使用
4. 未找到匹配：标记为 Miss（`actual_time = NaN`）
5. 未被匹配的演奏事件记录为误按

### 4.4 第一版输出

- **Hit**: `is_hit = True`，记录 `time_error`
- **Miss**: `is_hit = False`
  - 超出时间窗口：窗口内无匹配的演奏事件
  - 完全漏按：`actual_time = NaN`, `time_error = inf`
- **Extra Press**: 窗口外或曲谱中不存在的按键

**扩展（第一版不作为交付条件）：**
- Perfect/Good/Bad 分级
- 连击统计
- 准确率计算

## 五 测试样例

### 5.1 样例1：单音符

**曲谱定义：**
```python
model.add_note(note_id=1, note_number=72, hit_time=5.0)
```

**视觉事件：**
| 时间 | 事件类型 | 音符ID | 音高 | Y坐标 |
|-----|---------|--------|------|-------|
| 3.0 | appear  | 1      | C5   | 400.0 |
| 5.0 | arrive  | 1      | C5   | 0.0   |

**中间时刻（4.0秒）：**
- Y坐标 = (5.0 - 4.0) × 200 = 200.0 像素

### 5.2 样例2：同音重复

**曲谱定义：**
```python
model.add_note(note_id=1, note_number=60, hit_time=3.0)
model.add_note(note_id=2, note_number=60, hit_time=4.0)
```

**关键点：**
- 两个音符有**不同的 note_id**（1 和 2）
- 音高相同（60 = C4）
- 到达时间不同（3.0秒 vs 4.0秒）

**视觉事件：**
| 时间 | 事件类型 | 音符ID | 音高 | Y坐标 |
|-----|---------|--------|------|-------|
| 1.0 | appear  | 1      | C4   | 400.0 |
| 2.0 | appear  | 2      | C4   | 400.0 |
| 3.0 | arrive  | 1      | C4   | 0.0   |
| 4.0 | arrive  | 2      | C4   | 0.0   |

### 5.3 样例3：和弦（C大三和弦）

**曲谱定义：**
```python
model.add_note(note_id=1, note_number=60, hit_time=5.0)  # C4
model.add_note(note_id=2, note_number=64, hit_time=5.0)  # E4
model.add_note(note_id=3, note_number=67, hit_time=5.0)  # G4
```

**关键点：**
- 三个音符有**不同的 note_id**
- 音高不同
- **同时到达判定线**（hit_time 相同）

**视觉事件：**
| 时间 | 事件类型 | 音符ID | 音高 | Y坐标 |
|-----|---------|--------|------|-------|
| 3.0 | appear  | 1      | C4   | 400.0 |
| 3.0 | appear  | 2      | E4   | 400.0 |
| 3.0 | appear  | 3      | G4   | 400.0 |
| 5.0 | arrive  | 1      | C4   | 0.0   |
| 5.0 | arrive  | 2      | E4   | 0.0   |
| 5.0 | arrive  | 3      | G4   | 0.0   |

### 5.4 样例4：休止

**曲谱定义：**
```python
model.add_note(note_id=1, note_number=60, hit_time=3.0)
model.add_note(note_id=2, note_number=62, hit_time=6.0)  # 3秒间隔
```

**关键点：**
- 两个音符之间间隔 3 秒
- 在 4.0 秒时，音符1已到达，音符2刚出现

**时间线：**
- 1.0s: 音符1 出现
- 3.0s: 音符1 到达判定线
- 4.0s: 音符2 刚出现（在屏幕顶部）
- 6.0s: 音符2 到达判定线

### 5.5 样例5：Note Off（持续时间）

**曲谱定义：**
```python
model.add_note(note_id=1, note_number=60, hit_time=5.0, duration=2.0)
```

**视觉事件：**
| 时间 | 事件类型 | 音符ID | 音高 | Y坐标 |
|-----|---------|--------|------|-------|
| 3.0 | appear  | 1      | C4   | 400.0 |
| 5.0 | arrive  | 1      | C4   | 0.0   |
| 7.0 | disappear | 1    | C4   | 0.0   |

**关键点：**
- 音符在 5.0 秒到达判定线后**保持激活**
- 在 7.0 秒时消失（5.0 + 2.0）
- 6.0 秒时查询：音符可见且 `is_active = True`
- 8.0 秒时查询：音符已消失，不可见

### 5.6 样例6：命中判定

**曲谱：**
```python
model.add_note(note_id=1, note_number=60, hit_time=3.0)
model.add_note(note_id=2, note_number=64, hit_time=3.0)
model.add_note(note_id=3, note_number=67, hit_time=4.0)
```

**演奏：**
```python
performance = [
    (60, 2.98),   # 提前 20ms
    (64, 3.05),   # 延迟 50ms
    (67, 4.12),   # 延迟 120ms
]
```

**判定结果（hit_window_ms=100）：**
| 音符ID | 音高 | 预期时间 | 实际时间 | 误差(ms) | 结果 |
|--------|------|---------|---------|---------|------|
| 1      | C4   | 3.00    | 2.98    | -20     | Hit  |
| 2      | E4   | 3.00    | 3.05    | +50     | Hit  |
| 3      | G4   | 4.00    | 4.12    | +120    | Miss |

## 八 实现注意事项

### 8.1 音符ID的重要性

**必须为每个音符分配唯一ID**，即使：
- 同音高同时到达（和弦）
- 同音高不同时到达（同音重复）

**原因：**
- 命中判定需要区分具体是哪个音符被按下
- 视觉系统需要独立跟踪每个音符的状态

### 8.2 时间精度

- 所有时间单位为**秒**（浮点数）
- 判定误差单位为**毫秒**（方便人类理解）
- 转换公式：`time_error_ms = time_error_s × 1000`

### 8.3 坐标系

- 模型内部使用**相对坐标**（相对于判定线）
- 判定线永远是 Y=0
- 屏幕映射由渲染层负责

### 8.4 与 FPGA 的接口

**曲谱侧（视觉）：**
- 管理音符的预定时间（`hit_time`）
- 生成视觉事件（预告、到达）
- 计算命中判定

**FPGA 侧（音频）：**
- 接收真实演奏事件（`performance_event_t`）
- 实时合成音频
- 不依赖曲谱数据

**桥接：**
- 真实按键 → `performance_event_t` → FPGA 音频合成
- 真实按键 + 曲谱 → 命中判定 → 视觉反馈
