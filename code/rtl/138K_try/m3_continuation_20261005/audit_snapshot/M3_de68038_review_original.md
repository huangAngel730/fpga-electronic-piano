## Hold/Recovery结论边界

本轮没有修改M2的Hold或Recovery RTL。仅更换parser后的新映射/布局/布线让旧违例消失，这是物理实现整体变化，不能声称两处分别做了逻辑修复。
Hold0.000是四舍五入显示的边界值；不宣称严格正guardband，也不将V0161别的布线的回代值套到本版。
Setup+0.017小于+0.5ns工程目标，任何新源码/效果器/接口变化都需要重新整机STA。
