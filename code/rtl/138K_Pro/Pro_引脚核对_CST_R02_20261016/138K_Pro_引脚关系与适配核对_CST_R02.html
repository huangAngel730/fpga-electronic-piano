音频路径与现场位置

FPGA E22/F24/G24 → 底板 U6 PT8211-S → LMV321 低通/缓冲 → U32 XPT4809 → J29 耳机口。H17 控制 U32/5，高电平工作、低电平关闭。J25 是 DC 电源接口。

PT8211 的接口是 16 位 LSBJ 右对齐。正常48 kHz/64 BCLK时，U6/1应见3.072 MHz，U6/2应见48 kHz；该预期以新的正确Pro工程运行作为前提。
