# 准备资料入口

本目录保存竞赛原始资料、方案报告和生成脚本，不放正式 RTL 或构建产物。

## 目录

- `选题/`：主办方和厂商发布的原始赛题 PDF，只作为需求依据，原则上不修改。
- `官方讲解/`：高云选题二讲解截图及按权威级别整理的摘要，入口见 `官方讲解/README.md`。
- `赛事FAQ/`：赛事流程与评审导向的第三方搬运资料，**非官方发布**，证据级别低于赛题原文，入口见 `赛事FAQ/2026高云杯常见问题汇总.md`。
- `文档/`：面向队员阅读和交付的 Word 文档，完整清单见 `文档/00_README.txt`。
- `脚本/`：生成或更新 Word 报告的 Python 脚本。

## 根目录 Word 文件

`准备/` 根目录中的 Word 文件是早期原稿或生成源对应的原始版本。兼容版和编号交付稿统一从 `文档/` 获取。不要只手工修改 `文档/` 中的生成型 Word；应先修改对应脚本，再重新生成。

## 常用入口

- 主方案：`高云选题二模块化主方案.docx`
- 分工与资源方案：`文档/06 三人分工与软硬件资源管理方案.docx`
- 官方高云赛题：`选题/2026_FPGA创新设计赛道选题指南_高云半导体.pdf`
- 官方讲解截图摘要：`官方讲解/README.md`
- 赛事常见问题（第三方搬运）：`赛事FAQ/2026高云杯常见问题汇总.md`
- 文档生成说明：`脚本/README.md`
