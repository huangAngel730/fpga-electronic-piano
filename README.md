# FPGA实时多音色电子乐器

本仓库用于2026年全国大学生嵌入式芯片与系统设计竞赛FPGA创新设计赛道准备与开发，当前方向为高云选题二“基于FPGA的实时多音色合成电子乐器引擎”。

## 当前平台与目标

- 开发板：Sipeed Tang Mega 60K + NEO Dock
- FPGA：`GW5AT-LV60PG484AC1/I0`
- 基础音频路线：DDS + 单周期波表 + 独立ADSR
- 目标输出：I2S，48 kHz暂定
- 阶段目标：先完成单声部和4复音，再逐步扩展至32个独立活跃振荡器
- 交互方案：通过统一演奏事件接口解耦，具体琴键和传感器后续实验确定

## 已有八键原型

仓库根目录下的 `rtl/`、`tb/`、`constraints/` 和 `docs/` 来自项目早期的厂商无关Verilog电子琴原型，当前功能包括：

- C4至C5八个低有效琴键
- 两级输入同步和按键去抖
- 多键时高音优先
- 相位累加音调生成
- 一位方波音频输出
- 自检仿真Testbench

该原型用于验证基础按键、相位累加和测试流程，不代表最终Tang Mega 60K多音色架构。后续正式代码按照 `代码/` 下的模块化规范逐步迁移和扩展。

## 目录

- `准备/`：官方题目、方案分析、采购和团队协作文档。
- `代码/docs/`：项目事实、接口、决策、任务和验收规则。
- `代码/rtl/`：后续Tang Mega 60K正式可综合RTL。
- `代码/model/`：Python黄金参考模型。
- `代码/scripts/`：环境、构建、烧录和自动测试脚本。
- `rtl/`、`tb/`：已有八键方波电子琴原型及其自检仿真。

## 原型仿真

已有原型顶层为 `electronic_piano_top`，自检Testbench位于 `tb/tb_electronic_piano.v`。在正式复用前，应先按照当前环境运行仿真并确认PASS；不能仅依据远程仓库说明将其视为已经在Tang Mega 60K上验证。

## 电气安全

不要将8欧无源扬声器直接连接FPGA引脚。数字音频应经板载音频链路或I2S DAC转换后，再连接有源音箱或功放输入。详见 `docs/hardware.md`。
