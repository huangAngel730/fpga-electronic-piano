# FPGA实时多音色电子乐器

本仓库用于2026年全国大学生嵌入式芯片与系统设计竞赛FPGA创新设计赛道准备与开发，当前方向为高云选题二“基于FPGA的实时多音色合成电子乐器引擎”。

## 当前平台与目标

- 开发板：Sipeed Tang Mega 60K + NEO Dock
- FPGA：`GW5AT-LV60PG484AC1/I0`
- 基础音频路线：DDS + 单周期波表 + 独立ADSR
- 目标输出：I2S，48 kHz暂定
- 阶段目标：先完成单声部和4复音，再逐步扩展至32个独立活跃振荡器
- 交互方案：通过统一演奏事件接口解耦，具体琴键和传感器后续实验确定

## 三人分工

| 岗位 | 定位 | 所有权核心 |
|---|---|---|
| M1 | 音频算法、验证与竞赛交付负责人 | 算法定义、Python黄金模型、算法RTL行为、逐样本验证、报告与答辩材料 |
| M2 | FPGA技术与系统集成负责人 | 时钟、PLL、复位、sample_tick、CDC、FIFO、I2S、UART、顶层、Gowin工程、CST与SDC、综合与时序收敛、稳定码流 |
| M3 | 实体硬件、交互与上板验证负责人 | 供电、电平、接线、传感器、ADC、DAC、功放、PCB、焊接、机械结构、仪器测量、串口与仪器自动化软件 |

FPGA内的DDS、波表、ADSR、复音、混音和数字效果算法按软件工作管理，由M1负责；软件任务积压时按D010由M2和M3分担实现工作，算法数学定义和最终验收始终由M1负责。

完整的岗位定义、决策权和复核关系见 `代码/docs/角色分工.md`，日常流程见 `代码/docs/三人协作执行手册.md`。

两套Tang Mega 60K和两台逻辑分析仪均为实验室共享资源，配额是预约基准而不是个人所有权。

| 编号 | 名称 | 定位 | 默认配套 |
|---|---|---|---|
| BD-01 | Tang Mega 60K + NEO Dock | 稳定集成板 | LA-01 |
| BD-02 | Tang Mega 60K + NEO Dock | 实验开发板 | LA-02 |

两块开发板合计每周40小时配额：M1六小时、M2十四小时、M3十小时、共同集成十小时。两台逻辑分析仪合计每周40小时配额：M1四小时、M2十四小时、M3十二小时、共同集成十小时。规则见 `代码/docs/板卡与仪器资源管理.md`，实际占用登记在 `代码/docs/资源使用记录.md`。

## 已有八键原型

仓库根目录下的 `rtl/`、`tb/`、`constraints/` 和 `docs/` 来自项目早期的厂商无关Verilog电子琴原型，当前功能包括：

- C4至C5八个低有效琴键
- 两级输入同步和按键去抖
- 多键时高音优先
- 相位累加音调生成
- 一位方波音频输出
- 自检仿真Testbench

该原型已通过Icarus自检仿真，验证等级L2，用于验证基础按键、相位累加和测试流程，不代表最终Tang Mega 60K多音色架构。后续正式代码按照 `代码/` 下的模块化规范逐步迁移和扩展。

## 原型仿真

已有原型顶层为 `electronic_piano_top`，自检Testbench位于 `tb/tb_electronic_piano.v`。运行方法见 `代码/docs/开发环境.md`。在正式复用前，应先按照当前环境运行仿真并确认PASS；不能仅依据远程仓库说明将其视为已经在Tang Mega 60K上验证。

`.github/workflows/rtl-smoke.yml` 会在推送和合并请求时自动编译并运行该原型仿真。

## 电气安全

不要将8欧无源扬声器直接连接FPGA引脚。数字音频应经板载音频链路或I2S DAC转换后，再连接有源音箱或功放输入。5 V信号接入3.3 V FPGA GPIO前必须确认分压或电平转换。详见 `docs/hardware.md`。
